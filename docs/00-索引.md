# 00 · 按任务查找权威文档

本文件只负责“做什么任务，应读哪份权威文档”。直属文件与子目录清单由各层 README 自动维护，从 [docs/README](README.md)开始。当前状态只看 [STATUS](STATUS.md)，历史不指导当前操作。

## 阅读顺序

每次读 AGENTS 和 `pnpm agent:brief`；任务目录 README → 本索引 → 专题规则 → 必要实现。只有追溯理由才读历史。项目介绍见根 README，架构见技术方案，规则修改方式与 PDF 同步见[文档维护规范](ops/文档维护规范.md)。
