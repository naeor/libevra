# 00 · 文档索引与阅读顺序

> **先看 [`STATUS.md`](STATUS.md) 知道"现在在哪"；再按下面的顺序按需读。**
> 本文件只管"有哪些文档、先读哪份"，**不重复内容、不写状态**。

## 二、AI 在哪读

1. 根目录 [`../AGENTS.md`](../AGENTS.md)（规则与边界，自动加载）。
2. `pnpm agent:brief` → 简报。
3. **[`STATUS.md`](STATUS.md)** → 状态。
4. 再做 §3 的"按任务必读"：改哪一块，就读 `specs/` / `ops/` 里对应的那一份。

> **不要**把 `archive/`、`changelog/`、`阅读版/` 当默认上下文。
