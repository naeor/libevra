# docs/ops · 阅读入口

开发、文档维护与运维操作规范；历史操作不能替代当前流程。

优先阅读[任务索引](../00-%E7%B4%A2%E5%BC%95.md)定位权威规则，再按下表进入实现或子目录。目录清单不证明功能已验收。

复杂或反复失败的问题可从[开发与验收规范的 Diagnostic Mode](开发与验收规范.md#diagnostic-mode专项-bug-诊断模式)进入专项诊断；该模式提供可选方法，验收等级仍按实际风险决定。规范的同路径阅读版位于 `docs/阅读版/ops/开发与验收规范.pdf`，同步方式见[文档维护规范](文档维护规范.md)。
