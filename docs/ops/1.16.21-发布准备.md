## 生产发布步骤

1. `ssh libevra`；`cd /srv/libevra`；`sudo docker ps` 确认 `deploy-api-1`/`deploy-web-1` 健康（1.16.19）。
2. `sudo ./deploy/backup.sh --keep 7`；核对 `deploy/backups/last-local.json`（`restoreOk: true`、`localOk: true`）。
3. 打回滚镜像 tag：`libevra-api:rollback-1.16.19-20261026` / `libevra-web:rollback-1.16.19-20261026`（**已在准备阶段完成**）。
4. 记录发布前状态（`.last-deployed`、`.deployed-commit`、`/api/v1/health`、镜像、迁移 58）到 `/srv/libevra-release-1.16.21-20261026/`（**已在准备阶段完成**）。
5. 上传源码归档并校验 `sha256sum`（本地与服务器一致）。
6. `tar -xzf` 解包到 `/srv/libevra`（保留 `.env`、`deploy/backups`、运行数据）；确认 `deploy/docker-compose.release-1.16.21.yml` 就位。
7. `sudo docker compose -f deploy/docker-compose.prod.yml -f deploy/docker-compose.release-1.16.21.yml build api web`，记录新镜像 ID。
8. `sudo docker compose -f deploy/docker-compose.prod.yml -f deploy/docker-compose.release-1.16.21.yml run --rm migrate`：期望 `59 migrations found` 并应用 `20261026120000_fx_public_rates`。
9. `sudo docker compose -f deploy/docker-compose.prod.yml -f deploy/docker-compose.release-1.16.21.yml up -d --no-deps api web`；`sudo docker ps` 确认健康，db/relay 未重建。
10. 更新 `/srv/libevra/.last-deployed`=`1.16.21`、`.deployed-commit`=`<发布提交>`；写入 `/srv/libevra-release-1.16.21-20261026/health-after.json`、容器/镜像/迁移清单。
11. 生产验证：`/api/v1/health` 版本 1.16.21/database up、`/healthz` 200、首页 200、静态资源 `1.16.21`、i18n 资源含新公告标题（中英）、汇率接口 `GET /api/v1/fx/rates?date=2026-10-23` 返回 available、迁移 59、`book_messages` 既有数据可读；回滚 tag 就绪。

## 回滚

- 应用回滚：`deploy/docker-compose.release-1.16.21.yml` 指回 `rollback-1.16.19-20261026` 镜像（或直接使用 `libevra-rc-api:1.16.19-20261026` / `libevra-rc-web:1.16.19-20261026`）→ `up -d --no-deps api web` → 验证 `/api/v1/health` 1.16.19。
- 数据库回滚：**不需要**。迁移 59 只新增表，1.16.19 代码不会读写这些表；保留 59 表不影响旧版本运行。
- 极端情况下用发布前 dump 恢复（`deploy/backups/libevra_prod-20261026-140211.dump`，restoreOk 已验证）；恢复会回到发布前数据，需所有者知情。

## 风险与边界

- 汇率模式默认关闭，升级后界面与数据不变；开启后分析新增综合视图，原分币种视图保留。
- 折算只影响显示与统计，不写回原始金额；导出与共享成员数据保持原币。
- 缺汇率/离线时统计标注"不完整"，失败账目可定位；不会静默把缺汇率当作 0。
- 迁移 59 为增量新建表；生产回滚 1.16.19 与 59 库兼容。
- 真机/PWA/Safari 未验收（桌面 Chrome 已验）；上线后如需可用预览站点做设备抽查。
