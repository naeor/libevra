# Libevra · 中国大陆互联网备案与发行准备

> 最后修改：2026-11-09 15:36（UTC+08:00）

部署证据与办理口径核对至 2026-11-09。接入区域、主办者、用户范围、功能或发行渠道变化时，按本页流程重新核对。

## 1. 当前判断与行动顺序

- **网站 ICP 备案：按目前核实到的香港接入，暂不办理。** 生产域名直连记录所载的腾讯云香港实例，未发现中国大陆网站接入节点。腾讯云将香港托管列为无需办理网站 ICP 的场景。若以后改用大陆源站、反代或境内 CDN，启用前按实际接入商与属地通信管理局要求办理。大陆接入场景下，免费、测试或邀请制均不能直接作为免备案依据。依据见[国家行政法规库《互联网信息服务管理办法》](https://xzfg.moj.gov.cn/mobile/law/detail?LawID=1756)、[工信部备案管理办法](https://wap.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html)、[腾讯云适用场景](https://cloud.tencent.com/document/product/243/19630)。
- **公安联网备案：今天联系主办者所在地公安网安部门。** 国务院公布的修订文本第十二条列的是互联单位、接入单位及联网的法人和其他组织，使用网络正式联通作为起算事件。地方网站办理实务也受理个人主办者。腾讯云、深圳公安的通用网站流程从取得 ICP 备案号后的开通讲起，阿里云现行指引另列非大陆托管但向大陆提供服务的情形。香港托管和未开放注册均不足以排除公安备案。现有证据支持把本项目视为可能已触发备案的受控运行网站，个人主办、香港接入、无网站 ICP 号的具体受理方式及起算日由属地网安确认。依据见[国家行政法规库第十二条](https://xzfg.moj.gov.cn/mobile/law/detail?LawID=1198)、[北京政务个人申办示例](https://banshi.beijing.gov.cn/pubtask/task/1/110116000000/6d1d07c6-a640-40a4-8922-aeee16b868cd_app.html)、[深圳公安新办网站指引](https://ga.sz.gov.cn/ZT/HLWSYSQ/)、[腾讯云办理指引](https://cloud.tencent.com/document/product/243/19142)、[阿里云境外接入说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/the-public-security-network-for-record-and-cancellation)。
- **是否正式开通：技术可达与产品公开发行分别判断。** 10 月 16 日已有有效 HTTPS 及公网网站，随后存在非演示账号和账本活动。当前是公网可访问的私人生产部署，账号创建由邀请码控制，尚无产品公开发行的证据。仅在个人设备或隔离环境中验证、公开送达 Web 页面及本机游客功能、经邀请在公网使用远端账号和同步，是三个不同的服务事实。哪一个事实触发本案公安网站备案，请属地网安结合运营地点、实际用户与首次使用判定。
- **办理顺序。** 先由所有者核对主办者省市区、最早真实用户及其所在地，同时向属地网安确认义务、起算日、无 ICP 号的入口及能否按期受理。确认需办即按指导提交并保存回执。另在官方平台核查是否已有记录。原生 App 备案随 S23 / S24 准备，在相应 S26 发行前完成。

## 4. 办理入口与最少操作路径

### 公安联网备案

1. 向**实际主办者所在地**网安部门咨询。可直接使用下述事实摘要，方括号由所有者核实后补齐。
   > 本人拟以个人主办者身份运营免费个人记账工具 Libevra，主域名 libevra.com，使用腾讯云香港轻量实例，目前尚未查得 ICP 备案号。2026-10-16 有公网 HTTPS 访问记录。任何人可以打开网页并在本机体验，云端账号须凭邀请码注册，实际运营地和受邀用户范围为［据实填写］，首次实际使用为［日期或尚在核实］。请确认是否需要公安联网备案、应以哪天起算、个人香港站点无 ICP 号如何申报、30 日内以哪个环节为准，以及应选择哪一服务分类。
2. 在[公安公共查询](https://beian.mps.gov.cn/#/query/webSearch)按域名核对既有记录。如需办理，由本人进入[全国互联网安全管理服务平台](https://beian.mps.gov.cn/)，按指引登录或实名，复用已有主体或新增个人主体，再新增网站。备好域名证明、身份证明、接入资料、联系人、网站功能及开通时间。如要求说明交互属性，分别描述邀请共享账本和公开发表能力，请属地给出分类。若系统要求 ICP 号而本案没有，使用网安指定的人工或其他入口。
3. 保存提交时间、回执、审核及整改记录。审核通过后按平台指引放置真实公安备案号、标识及查验链接，后续发布按实际受理结果安排。

### 网站 ICP 备案（将来有大陆接入等触发情形时）

1. 先向实际接入商核验可备案云资源、域名及拟申报主体。工信部规则要求核对域名持有者及有资质的境内域名注册服务机构。确认现有域名资格后再决定是否转入。当地的材料、实名、住址和命名要求按[腾讯云各省规则入口](https://cloud.tencent.com/document/product/243/3474)找到辖区并与通信管理局核对。依据见[工信部域名通知](https://tjca.miit.gov.cn/zwgk/zcwj/wjfb/art/2020/art_b9bbca535c9b42c283879be216796fcd.html)。
2. 通过实际接入商发起首次备案或相应的新增服务、接入备案。本人填写主体、网站、域名、接入资料，完成身份核验、短信验证及所需承诺。身份证明、域名及补充件按[腾讯云材料清单](https://cloud.tencent.com/document/product/243/18914)和辖区要求准备。省通信管理局收到齐全材料后的办理口径为 **20 个工作日内**，接入商初审、补正和验证另计。
3. 先完成备案再开通相应大陆互联网服务。按要求在网站首页底部展示号码并链接[工信部备案管理系统](https://beian.miit.gov.cn/)。官方系统也可用于查询网站和 App 备案。

## 5. S23、S24 与 S26 的 App 备案

当前交付形态为 Web / PWA。未找到已向中国大陆发行的 Android 或 iOS 原生 App，因此本次无需为尚未发行的原生客户端提交申请。今后若经平台将 PWA 封装或分发为 App，重新确认适用口径。

工信部信管〔2023〕105 号要求在中国境内开展 App 互联网信息服务前完成 App 备案，由接入商或分发平台向主办者住所所在地省通信管理局提交。材料齐全准确后，省通信管理局办理口径为 **20 个工作日内**。取得号码后在 App 显著位置展示并按要求链接查询。App 记录与网站记录分开，已有网站备案的主体信息可复用。若发行纯离线构建，按实际联网行为和渠道规则向管局及平台确认，尤其核对可选自部署连接、官方云、联网 SDK 和分发要求。香港托管条件、大陆 App 服务义务和商店上架要求分别核对。依据见[工信部 App 备案通知](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html)。
