## 4. 发布步骤（生产）

1. 推送 `release/s16-1.16.05` 与 `main`。
2. 生成源码归档（`git archive HEAD`，附 SHA-256），上传到 `/srv/libevra-1.16.16-release.tar.gz`，服务器复核 SHA-256。
3. 快照当前源码 `/srv/libevra.pre-1.16.16-20261025`。
4. 生产备份：`./backup.sh --keep 7`，核对 `last-local.json` 的 `restoreOk=true`。
5. 记录回滚镜像：把当前 `deploy-api`/`deploy-web` 容器镜像分别打 tag `libevra-api:rollback-1.16.15-20261025`、`libevra-web:rollback-1.16.15-20261025`。
6. 解包归档到 `/srv/libevra`（保留 `deploy/.env`），构建 `libevra-rc-api/web:1.16.16-20261025`。
7. 无迁移，跳过 migrate。
8. `docker compose -f docker-compose.prod.yml -f docker-compose.release-1.16.16.yml up -d --no-deps api web`。
9. 记录 `.last-deployed=1.16.16`、`.deployed-commit=<commit>`。
