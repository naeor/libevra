# S13-E 当前账本卡片响应式微调记录（1.13.08 补丁）

> 2026-10-18。**本轮只改当前账本卡片 UI。** 所有者已确认按 `1.13.08` 补丁版本发布。
> 修改基于 `1.13.07` 的当前账本卡片；未改切换、详情、成员管理、数据或离线逻辑。

## 1. 修改前的行为

`BookCardSplit` 用 **viewport** 的 `sm:flex-row` 决定布局：

```text
flex flex-col sm:flex-row
右侧切换区：min-h-24，sm:min-h-32 sm:w-40 sm:border-l
```

在 390px iPhone 上：

- 单人卡片宽约 **342px**，但仍因 viewport < 640 而采用上下布局 → 卡片约 **176px 高**；
- 协作双卡的左卡宽约 **165px**，同样上下布局 → 切换区约 96px 高，接近卡片一半。

## 2. 修改方式（未新增第二套组件）

同一个 `BookCardSplit` 同时服务单人和协作状态，只把布局切换从 viewport media query 改为
**CSS Container Query**：

- 根 `.book-card`：`container-type: inline-size`；
- `.book-card-body`：默认纵向，窄容器为「详情 + 底部横向切换栏」，宽容器为左右分区；
- `.book-card-switch`：窄卡片下横向、`min-height: 2.75rem`（44px），图标 24px、文字在右；
- 宽卡片下切换区宽 104px、纵向排列、图标 36px、文字在下；
- 两个区域仍是两个独立的 `<Link>`，整块可点击，href 保持 `/books/:id` 与 `/start`。

新增文件：`apps/web/src/book-card.css`，在 `index.css` 中 import。
组件修改：`apps/web/src/pages/LedgerPage.tsx` 的 `BookCardSplit`。

### 断点依据

宽布局需要：左侧至少约 160px（名称/编号/查看详情）+ 右侧 104px（图标/文字/内边距），
合计 **264px = 16.5rem**。因此容器查询断点为 `min-width: 16.5rem`：

- 单人卡片在 iPhone 390/375/320 上宽 342/327/272px → **左右布局**；
- 协作卡片宽 165/130/194px → **紧凑上下布局**；
- 300px 视口下单人卡片仅 252px，低于 16.5rem → 退化为紧凑栏，避免挤压。

## 3. 真实浏览器测量（本地 E2E：web 5175 / API 3100，Edge headless CDP）

“行/列”指 `.book-card-body` 的 `flex-direction`；切换高度为整个 `<Link>` 的
`getBoundingClientRect().height`。

| 场景 | 卡片宽×高 | 布局 | 切换区 | 图标 |
|---|---|---|---|---|
| 单人 390 | 342×124 | row | 104×122 | 36px |
| 单人 375 | 327×124 | row | 104×122 | 36px |
| 单人 320 | 272×124 | row | 104×122 | 36px |
| 单人 300 | 252×168 | column | 250×44 | 24px |
| 单人 430 / 507 / 834 / 1440 | 382–400×124 | row | 104×122 | 36px |
| 协作 390 | 165×192 | column | 163×44 | 24px |
| 协作 320 | 130×216 | column | 128×44 | 24px |
| 协作 300 | 120×240 | column | 118×44 | 24px |
| 协作 507 / 834 / 1440 | 194×192 | column | 192×44 | 24px |

所有测试宽度下：

- 文档、卡片、body、切换区均无横向溢出；
- 切换区与详情区高度均 ≥44px；
- 协作卡片与成员卡片高度一致（例如 390：192/192；320：216/216）；
- 切换栏占卡片高度约 **23%（390）/20%（320）**，不再接近一半；
- 图标/文字位置：宽卡文字在图标下，窄卡文字在图标右；
- 书名著称改为**换行展示、不再省略**；极长名称会让共享行变高，但不会截断或被裁切；
- 行为：切换链接 → `/start`，详情链接 → `/books/<id>`，均实际点击验证通过。
