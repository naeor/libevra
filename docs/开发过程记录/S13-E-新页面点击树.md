```

├─ 标题：选择账本
```

```
分类管理（/books/:bookId/settings/categories）
├─ 返回 → /books/:bookId/settings
├─ 副标题：正在管理「名称（编号）」+ 归档提示

│           ├─ 描述：有 N 笔记账正在使用（N 来自只读影响计数接口）
│           ├─ 后果：账目不变 / 改用所选分类 / 不可恢复 / 共享账本影响协作者
│           ├─ 替换下拉：使用「暂无分类」（推荐）或同类型其他分类

├─ 同结构；永久删除替换下拉为「改为未指定」或另一支付方式

    ├─ 后果 + 共享账本提醒
    └─ 取消 / 确认删除
```

> 目标账本模式所有读写都带 URL 的 `bookId`，**不调用 `useLedger`**。

## 4. 权限与状态矩阵（受影响部分）

| 场景 | owner | editor | viewer | 非成员 |
|---|---|---|---|---|
| 查看账本详情 / 设置 | ✅ | ✅ | ✅ | ❌（明确错误，不回落） |
| 重命名账本 | ✅ | ✅ | ❌（只读） | ❌ |
| 分类/标签/支付方式 创建/改名/归档 | ✅ | ✅ | ❌（服务端 403） | ❌ |
| 永久删除 + 历史重关联 | ✅ | ✅ | ❌（服务端 403） | ❌ |
| 导出/导入 | ✅ | ✅ | 按接口现状（读/写强度） | ❌ |
| 弃置账本 | ✅（仅创建者） | ❌ | ❌ | ❌ |
| 退出账本 | ❌（创建者不能退出） | ✅ | ✅ | — |
| 切换"查看/管理目标" | ✅ | ✅ | ✅ | ❌ |
| **共享账本离线新建/修改/删除** | **拒绝** | **拒绝** | **拒绝** | — |
| **个人账本离线新建/修改/删除** | ✅ | — | — | — |

**共享账本离线只读的落点**：

- 判定：当前账本 `memberCount ≥ 2` + 合并离线信号（`useAccountOffline`）。
- 写入层：`offline/write.ts` 在 `upsertEntry` / `setMark` 之前抛
  `SharedLedgerOfflineReadOnlyError`；**不产生新标记、不产生永远不会成功的红行**。
- UI：离线横幅改为"共享账本暂时只能查看"；新记账页禁用保存并提示；详情页隐藏修改、禁用删除。
- 存量待同步标记：**原样保留，不自动丢弃**；恢复网络后仍由现有 sync 链路处理。
  冲突链（409 → ConflictScreen）本轮未改写，列为真机验收项。
