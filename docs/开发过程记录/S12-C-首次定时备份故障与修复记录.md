### 2.3 根因

`libevra-backup.service` 的 `ExecStart` 外层已经调用：

```bash
/usr/bin/flock -n /srv/libevra/deploy/.backup.lock /srv/libevra/deploy/backup-all.sh
```

而 `backup-all.sh` 内部又有：

```bash
exec 9> "$LOCK_FILE"
if ! flock -n 9; then
  echo "❌ 已经有一次备份在运行（$LOCK_FILE 被占用）。本次退出。" >&2
  exit 0
fi
```

Linux `flock` 的锁属于独立 open file description：外层持锁后，脚本用新 fd 再次请求同一文件会被判为冲突。  
**内层把外层当成了“另一个备份”，脚本 `exit 0`，systemd 记录 SUCCESS，但备份从未开始，也没有心跳。**  
这不是 COS 故障，也不是 COS 上传失败。

```ini

# 修改后
ExecStart=/srv/libevra/deploy/backup-all.sh
```
