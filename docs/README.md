# 文档阅读入口

> 最后修改：2026-11-08 23:28（UTC+08:00）

本目录分为现行规则、历史记录与导航。当前进度读 [STATUS](STATUS.md)，按任务定位权威规则读 [00 索引](00-索引.md)；本页只管理直属内容，不复制专题规则。

所有者优先阅读本机 `docs/阅读版/` 的同路径 PDF；Markdown 是唯一源，PDF 不入库。正文改变后自动同步已有阅读版，命令和验证见[文档维护规范](ops/文档维护规范.md)，工具从 [tools/README](../tools/README.md)进入。

规划入口仍是 `01-规划.md`，技术方案仍负责当前架构。旧设计、试验和否决理由从各现行文档末尾的历史依据进入；归档中的“当前”仅属于当时语境。

项目从起点走到今天的阶段成果与完成日期，保留在[规划正文的 S0–S16 阶段历程](01-规划.md#s0s16-阶段历程已交付成果与完成日期)。已完成阶段仍是规划的一部分，详细过程归档不替代正文中的发展历程。

技术选型与架构演进从 [02 §8](02-技术方案.md#8-原始目标与架构演进)阅读，接手时的重要工程成果从 [04 §5](04-交接.md#5-接手时应保留的工程成果与经验)阅读；设计专题正文保留成果与取舍摘要。S15-D / S16 的长期使用接受决定及原验收目标见[关闭记录](specs/product/S16-剩余验收清单-20261025.md)，阶段状态只在 STATUS 维护。

查旧规划中的未决事项、专项验收和研究依据，先看 [01 的专项入口](01-规划.md#仍需可检索的专项材料)；发布决策编号从[任务目录 §8](specs/product/S16-S17-开发路线图.md#8-产品决策编号与现行去向)定位。审查报告保留证据与建议的职责，不替代现行规格，也不因文档重整自动关闭其中的问题。
