# S16-B2 · 绿色深色视觉 R2

> 最后核对: 本地 commit `style(theme): finalize neutral dark card surfaces` / 2026-10-24。本文定义 R2 设计规则，不构成发布或视觉验收；最终默认中性卡片采用方案 A（`canvas #17181A` / `surface #2C2C2C`）。项目状态仅见 [STATUS](../../STATUS.md)。

## 1. 推荐与对照

推荐 **R2-A：中性系统深色**。炭灰画布贯穿明细页头与正文；统计卡、列表、表单和浮层使用同一层中性表面。结构依靠明度、原有间距、圆角与边界建立。精确品牌绿 `#55997a` 留给主操作、加号、选中状态；链接使用可读的品牌前景。这样明细从头部到列表是同一个阅读环境，长时间查看不必持续面对大片绿色。

**R2-B：轻微品牌倾向**共用 A 的全部基础 Token，但改变头部的角色分配：普通品牌页头与明细头部混合 12% 品牌色，现有统计表面混合 14% 品牌色，明细品牌标题使用品牌前景；明细头部下缘以一段简单透明度无关的颜色过渡回到中性画布。正文、列表、设置、表单、导航与浮层仍是 A 的中性值。这是局部品牌氛围与统一阅读面的对照，不另做一套泛绿的基础灰阶。

## 2. 50 个角色的分工

| 角色组 | 个数 | R2 规则 |
|---|---:|---|
| canvas / surface / ink / muted / line / line-strong | 6 | 只属于明暗轴；中性灰，不嵌入当前色盘色相 |
| brand 三项 / category-ink / accent-ink / chart-rule | 6 | 强调与可读前景分开；坐标文字和网格保持中性 |
| danger / warn 各三项 | 6 | 业务含义固定，正文、浅底与实心按钮分别配对 |
| on-brand / on-danger / on-warn / on-ink / on-heat / on-tag / control-knob / focus-ring | 8 | 按实际承载表面设计前景；焦点有清晰实体边界 |
| data-expense / data-income / data-transfer | 3 | 红、绿、蓝分别保留财务语义，不跟主题色旋转 |
| chart-1…8 | 8 | 多分类柔和色；图例名称、金额和标记形状保留 |
| chart-heat-0…4 | 5 | 无记录为中性；1–4 保留递增业务色阶；0–2 灰白字，3–4 深字 |
| ocean-1…4 / on-ocean | 5 | 品牌展示可以更绿；文字位于最深海浪面上 |
| glass-highlight / overlay-soft / overlay | 3 | 保留光效与遮罩职责；不依靠发光建立层级 |

所有值唯一实现于 `apps/web/src/index.css`。完整 50 项浅色 / R1 / R2 新旧表及逐项消费者由 审计表（仅本机材料：`preview-artifacts/r2-token-table.md`） 与 使用和对比度审计（仅本机材料：`preview-artifacts/r2-color-audit.json`）生成。`on-warn` 仍是 B0 已预留、尚无实心警告按钮消费的角色；没有为本轮增加重复 Token。阴影沿用既有 shadow 角色，降低存在感。

## 4. 真实页面的分配

- 明细：A 页头使用 canvas，现有币种卡使用 surface；收入/支出开关和列表沿用既有结构。普通页头的 `on-brand` 局部解析为 ink，主按钮自身仍使用深色 on-brand。没有改头部高度、滚动、手势、动画进度或插值。
- 分析：卡片、坐标与说明中性；收入/支出与分类色独立；保留图例形状和数字。热力第 0–2 档使用 ink，第 3–4 档使用 on-heat。
- 记账与设置：中性画布 / 表面；输入边界使用 line-strong，占位字使用 muted。已有金额组合框保留外层焦点指示，不再给内部输入重复画第二圈。
- 导航：沿用原有 surface 与分隔线，选中项为品牌前景；加号保留品牌绿。没有改变底栏占位或展开记账入口动画。
- 弹窗与操作板：surface 承载阅读，canvas 承载嵌套提示；遮罩为中性黑透明叠加；危险操作仍为红色。
- 用户标签：原始保存色不改。纯展示函数选择最大对比的黑 / 白，写入局部前景变量；仅 R2 深色消费，R1 与浅色仍沿用其原前景。未新增主题状态或 DOM 观察器。
- 开始页面：四层海浪单独保留品牌气氛，最深层承载标题，后三层有清晰明度递进。浅色海浪、四层几何、动画参数与手势逻辑不变。

## 5. 对比度与边界

R2-A：正文 / surface **12.50:1**，次级文字 / surface **7.20:1**，链接 / surface **8.36:1**；主按钮 **5.15:1**，危险按钮 **7.74:1**，警告填充预留 **8.92:1**；输入边界 / surface **4.07:1**，焦点 / surface **8.36:1**；热力五档数字最低 **5.98:1**。海浪品牌文字 / ocean-1 **10.30:1**。B 的两种混合表面也分别检查正文与次级文字。

关键非文本控件检查 3:1，普通文字检查 4.5:1；装饰线与低存在感网格不按正文标准强行提亮。任意标签最大黑白前景最低约 4.58:1。图表仍需文字与形状，不能仅依赖颜色。实际渲染审计与局限见 [本地验收](../../archive/releases/S16-B2-深色视觉优化-本地验收-20261024.md)。

浅色已知品牌白字、旧浅焦点及热力数字债务没有在本轮改动，以遵守浅色视觉保持要求。R1 作为历史对照保留其既有债务。不能据此声称所有主题、所有状态或真机环境已经全面符合 WCAG。

## 6. 技术与后续验收

默认本地候选深色映射为 A；`data-design-variant="r1|r2b"` 只供独立预览选择设计分支，不进入 `libevra.theme`，不加入正式外观设置。原 `mode × palette`、prepaint、系统监听与持久化保持原样。其他六色仍隐藏，没有临时色盘。

先验收明细 A / B 的头部与正文关系，再决定是否保留 B 的品牌氛围。随后再审海浪亮度、危险按钮的视觉权重、表单焦点和图表密度。尚未批准任何视觉候选，也没有扩大到其他色盘、生产或业务结构。
