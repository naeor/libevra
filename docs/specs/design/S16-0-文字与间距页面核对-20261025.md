## 1. 方法

用真实浏览器采样，不靠人工逐页翻：

- 脚本：`tools/e2e/type-spacing-audit.mjs`（复用 `tools/e2e/cdp.mjs`，无新增依赖）
- 环境：Chrome headless（CDP 9236，可用 `LIBEVRA_CDP_PORT` 覆盖）、390×844、已登录夹具账号
- 路由：`/`、`/ledger`、`/stats`、`/me`、`/settings`、`/profile`、`/profile/avatar`
- 采样：所有**直接带文字**元素的 computed `font-size / line-height / letter-spacing`（不重复计父级容器）、
  字重、所有可见元素 `border-radius`、页面容器与一级区块 `padding`、`document.scrollWidth`
- 结果：`_backups/type-spacing-audit-20261025/results.json`

复现：`node tools/e2e/type-spacing-audit.mjs`（需 5173 与 API 3000 在跑）。

## 2. 结论

- **S16-0-02 文字**：实测只出现 9 种字号/行高组合与 3 种字重（400/500/600），全部命中 §13.1 token；
  另有 2 处属于规范 §13.3/§13.8 明确保留的白名单项。核对中发现并修正 **7 处 12/19.5px 行高漂移**
  （`text-xs leading-relaxed` → `text-helper-relaxed`，§13.4 已授权把 19.5px 取整到 20px）。
- **S16-0-03 间距/圆角**：普通页面左右基准 **24px 无例外**（InnerPage `<main>` 为 `4px 24px 40px 24px`；
  TabPage 页面由各 Section 的 `px-6` 保证，滚动容器本身 padding 为 0，属设计）。圆角为
  `field 14 / card 20 / sheet 24（仅上两角）/ full` 四档；本轮修正 **3 处底部面板圆角错档**
  （`rounded-t-card`/`rounded-t-3xl` → `rounded-t-sheet`），全仓已无 `rounded-t-card`、`rounded-t-3xl`
  与 `rounded-t-[20px]` 残留。

## 6. 未纳入本轮 / 需后续处理

1. **16px 品牌强调块**：规范 §15.7 只把 `rounded-2xl` 登记给「底部导航中键」。实际另有 4 处
   图标/logo/横幅块使用同档圆角（见 §5），属既有品牌形状。本轮**只登记不改**，建议后续在
   §15.7 增补一行例外，避免下次审计再次报警。
2. **§13.5 遗留的 `text-base`(16px) 硬编码出现**（明细月切换、空状态标题、账本名等）：规范已把
   16px 定为「金额/强调」档，但未给文字 token；按 §13 结论保留，留待单独一轮收敛。
3. **卡片内边距 P2 债**（列表行 16/20/21px 三种体系，见布局规范 §15.7）：属卡片内层级，
   不在 0-03「页面间距」范围，未动。
4. **覆盖面**：只覆盖 7 条已登录路由的静态首屏；登录/注册页、弹层打开态、图表 tooltip
   由既有 E2E（`layout-overflow-verify.mjs`、`theme-matrix-verify.mjs`）与截图证据兜底。
