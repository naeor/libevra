## 1. 现状

### 1.1 移动端分析页：用户现在能改什么

| 层 | 能改什么 |
|---|---|
| 整个工作台 | 放哪些卡片（系统推荐 / 全部分析 / 我的自定义，按分类浏览、搜索）；复制、删除；拖动换位或「放到第 N 格」；调宽 × 高；列数自动或手动，每种列数可以有自己的专属排列；向上紧凑；三种布局容器（横向滑动抽屉 2–6 张、分割卡片组 2–4 格、留白），容器可收缩成 1×1；撤销 / 重做；恢复默认。上限 40 个对象、12 个卡片组 |
| 单张卡片 | 83 项指标 × 38 种展示形式；组合卡片 1–8 个槽位（数字 ≤ 6、图表 ≤ 4），8 种内容模板 T1–T8；名称；时间（跟随顶部筛选 / 6 种「最近一段」/ 固定区间） |
| 顶部筛选 | 时间（最长 400 天）、分类、支付方式、标签、币种、原币或综合折算 |
| 保存与迁移 | 三套系统预设（新手 / 进阶 / 专业），先预览再应用；我的预设最多 10 个，可连筛选一起存；工作台与预设跨设备同步，冲突时选择；配置文件导入导出 |

限制：一次只看**当前一本账**；组合卡片里的槽位不能各自设时间或筛选。

### 1.2 电脑版总览：用户现在能改什么

- 6 种固定卡片：账本（每本账一张，可选主要指标「支出 / 收入 / 结余」，开关趋势与最近账目）、多账本收支（可选账本范围，按币种分别合计）、趋势、最近账目、待处理、快捷操作。
- 拖动、横纵缩放、隐藏 / 加回、撤销 / 重做、恢复默认、取消 / 完成。
- 顶部月份，只在这次打开期间记住。
- 右侧栏固定为「快捷操作 + 消息」，不能改。
- 配置只存在这台电脑的这个浏览器里，不跨设备。游客只显示当前账本。

### 1.3 两者的根本差别

分析页是「一本账、往深里看」；总览是「所有账本、一眼看全、顺手处理」。电脑端还多了大屏、鼠标和键盘、长时间开着、可能多窗口多屏。所以清单不止「把分析卡片搬过来」，更多是总览独有的三件事：**跨账本**、**能直接处理事情**、**桌面能力**。

## 2. 清单

「工作量」是粗估：**轻** = 复用现有组件和数据，只在总览接线；**中** = 新界面或新计算，不在服务器上存新东西；**重** = 服务器要存新东西或新增查询。「需拍板」见 §3。

## 3. 需要所有者先拍板

1. **跨账本合并的口径**（A2、A3、A5、C6）：几本账相加时，按币种分开列（现在多账本收支卡的做法），还是也允许综合折算成一种币种？分类、标签是每本账各自的，跨账本按分类或标签合并只能靠名称对齐，同名不一定是同一回事。建议：跨账本只做总额、收支、日历这类不依赖分类的；依赖分类的卡片固定一本账。
2. **A15 提醒线**：它像简化版预算。如果做，定位为「总览上的显示规则」：不发通知、不写进账本、不给其他成员看。
3. **A7 时间线里其他成员的操作**：共享账本的成员现在能在协作页看到编辑记录；在总览上汇总显示，是否算新的暴露面。
4. **C4 账期起始日**：只在总览生效会和分析页、明细的月份对不上；要做就全应用一起改，应作为独立的一件事。
5. **同步存在哪**（E1）：分析工作台在服务器上每个账号一行配置。总览配置要么并进这一行（不用迁移，但要确认旧版本客户端会原样保留它看不懂的字段），要么新开一张表（要一个迁移）。
6. **便签、模板存哪**（A8、A10）：只存本机，还是随总览一起同步。
7. **默认长什么样**：自定义能力再多，新用户第一次看到的总览仍需要所有者的意见。

## 4. 建议的先后（【推荐】，待确认）

- **第三批或待决定**：A15、A7、C4、C6 的跨账本部分、E7、F5。

## 5. 实施进度与本轮采用的口径

所有者 2026-11-16：第一批与第二批一起做；另外要求电脑端卡片也能像手机分析页一样**由用户决定大小，并按大小改变显示方式**。

§3 中与这两批有关、所有者没有另行指定的，本轮按下面的口径实施（都可以再改）：

| §3 | 采用 | 理由 |
|---|---|---|
| 1 跨账本合并 | 分析卡片只指定**一本**账（默认跟随当前账本）；跨账本只由总览卡片做（多账本收支、最近账目、月历、对比、待整理）。原币按币种分别相加；综合折算时各账本先按历史汇率折算再相加 | 分类、标签、支付方式每本账各自独立，跨账本合并分类会把同名不同义的分类加在一起 |
| 5 同步存在哪 | 新开一张表（单独的接口与版本号） | 分析工作台的服务器校验与旧版本客户端都是严格字段，塞进同一行会被拒绝或被旧客户端写丢 |
| 6 模板存哪 | 随总览配置一起保存、一起同步 | 换电脑时常用账目也在 |
| 7 默认布局 | 沿用 1.18.12 的默认组成（账本卡片、多账本收支、趋势、最近账目、待处理；快捷操作在右侧栏） | 不改变现有用户第一眼看到的内容 |

| 版本 | 内容 | 对应条目 |
|---|---|---|
