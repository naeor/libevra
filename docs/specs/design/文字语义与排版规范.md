## 10. 样式与业务文字的职责边界

原始目标是同一文字角色改一处即可全站生效；集中的是字号、行高、字重等设计决定。账本名、用户名、备注等用户数据仍来自业务数据，默认名称仍来自对应业务定义，金额/时间/计数由格式化与计算产生，不为统一样式另建一份文本事实表。

固定界面文案现由[国际化规范](国际化与本地化规范.md)规定的中英文资源与 `t()` 管理；服务端错误和历史事件按其契约转换显示。早期“尚无 i18n”的前提已经改变，但“样式集中不等于复制业务事实”的决定仍有效。文字样式调整不能顺带搬运业务状态、改默认值或用翻译后的标签控制逻辑。

## 13. 现行文字规则

### 13.1 文字语义等级

| 语义 token | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| `text-page-title` | 20px | 28px | 600 | 一级页（绿头）与二级页标题，字距 −0.025em |
| `text-section-title` | **16px** | 24px | **600** | **正式功能区标题** |
| `text-card-title` | 14px | 20px | 500 | 卡片标题 / 重要正文 |
| `text-body` | 14px | 20px | 400 | 普通正文 |
| `text-body-relaxed` | 14px | 24px | 400 | 多行正文与必须阅读的说明（S16 微调行高） |
| `text-helper` | 12px | 16px | 400 | 单行辅助信息 |
| `text-helper-relaxed` | 12px | 20px | 400 | 多行说明、错误提示 |
| `text-micro` | 11px | 16px | 400 | 底部导航、紧凑徽标 |
| `text-link` | 12px | 16px | 400 | 次级绿色文字操作 |
| `text-button-lg` | 15px | 22.5px | 500 | 主按钮（`Button.tsx` 等） |
| `text-button` | 14px | 20px | 500 | 常规按钮 |

所有 Token 定义在 `apps/web/src/index.css` 的 `@theme`；共享组件消费语义角色，页面不复制一套字号表。变更时同步核对行高、字重及真实页面。

### 13.3 特殊字号与边界

- 明细动态标题、海浪品牌按原进度插值，海浪大小品牌按[海浪要求](海浪效果要求.md)。
- 图表刻度、图例和浮层允许已有 10px 密度规格；输入框至少 16px，避免 iOS 聚焦放大。
- 手动记账金额使用 30px（`text-3xl`）；金额不归并成普通正文，不擅自放大为 36px。
- `InfoHint` 使用 11px `text-micro`；`CopyButton` 文本域为 16px，不再保留旧 10px 例外。
- 登录流程标题使用 `text-page-title`（20px），品牌字标 24px；不沿用旧的 18px 页面标题提案。
- 既有等值工具类不为改名字而全量替换，新代码优先语义角色。白名单与说明以 `typeScale.test.ts` 为可执行核对点。
- 账号、账目、邀请码等需逐字辨认的标识保留等宽与必要字距，不当作装饰性字体清理；日期/金额的列对齐使用 `tabular-nums`，不因此强制整页等宽。
- 品牌字距随字号采用相对单位；海浪品牌现有 `0.16em` 与动态字号共同构成几何效果，不改成固定像素字距。动态标题、海浪和键盘金额的字号变化不得机械套入静态正文级别。

### 13.6 防退化与修改验证

任意字号只允许在守卫白名单中使用，例外须说明产品原因；不能靠扩大白名单掩盖退化。修改共享 Token 后检查调用它的真实页面、英文、窄屏和输入焦点，按[开发与验收规范](../../ops/开发与验收规范.md)执行相应检查。

### 13.8 页面文字层级

| 角色 | 现行规则 |
|---|---|
| 页面标题 | 20px/600；保持动态标题和导航字距 |
| 功能分区 | 16px/600、深墨色 |
| 字段、设置项、列表名称 | 14px/500，`text-card-title text-ink` |
| 字段值 | 14px 深色；名称与值靠位置区分，不全部加粗 |
| 多行阅读正文 | 14px/24px，`text-body-relaxed`；靠留白分节 |
| 辅助解释 | 12px/20px，`text-helper-relaxed text-muted`；不降低透明度 |
| 日期、时间 | 12px/16px；数字使用 `tabular-nums`，需逐字辨认的编号用 `font-mono` |
| 警告、错误 | 保留完整提示和展开能力，不一律降为辅助文字 |

软件更新首页保留版本大字、公告名称、固定高度预览、正文省略号与始终可达的全文入口，下方列五个历史版本；行高改变后重新验证截断，不改变公告机制。

### 13.9 个人资料的局部规则

昵称、用户名、账号编号、注册时间采用紧凑左右布局：名称 14px 灰色普通字重，值 14px 深色。局部只读 `dl` 不反向改变其他页面的共享 `FactRow`。恢复码入口与安全提醒保留。账号编号等宽，点击打开独立底部复制面板，主页面不常驻复制文字。
