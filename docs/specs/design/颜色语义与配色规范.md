# Libevra · 颜色语义与配色规范

本文定义颜色的产品含义与使用原则。运行时属性、主题控制器、Token 分组和正式映射由[颜色主题系统实现规范](颜色主题系统实现规范.md)负责；精确色值以 `apps/web/src/index.css` 为实现源，不复制第二套候选表。

## 1. 颜色表达什么

- 品牌强调、正文、辅助文字、表面、边界、危险、警告和财务类别是不同语义，不能因为色值接近就互换。
- 支出、收入、转账使用财务语义色，不借分类序号色。危险与警告不跟随用户选择的品牌色相改变含义。
- 图表颜色不是唯一信号；同时提供名称、标记形状和可读的文字/数据。
- 颜色不替代禁用、选中、错误、权限和焦点的真实语义，不改变金额或业务判断。

## 2. 前景、表面与可读性

品牌、危险、警告、墨色、热力、用户标签及海浪各自使用对应前景角色。前景与背景按实际主题组合核对，不以一种色盘的结果代替其他组合。

文字、焦点、输入边界应分别按其可访问性用途验证；装饰细线与表面分层不能冒充可交互边界达标。不能为通过断言降低测试标准或擅自更改已确认海浪色阶；确有冲突时说明实际配对并由所有者决定视觉方案。

普通深色卡片使用中性表面；品牌强调保持局部。浅色已有对比度债务、任意标签色前景等未解决项不能因文档整理标为通过，具体边界见实现规范。

## 3. 固定色与特殊内容

二维码保留固定黑白，用户标签颜色是用户数据；已有特典头像、玻璃光效和品牌海浪的局部例外见[颜色清单](颜色清单.md)及实现规范。例外应说明原因，不能用硬编码绕开主题。

海浪几何、手势与进度不属于颜色规则；S19 材质只消费其轮廓与主题值。具体交互按[海浪要求](海浪效果要求.md)，组件材质按 [S19 规范](S19-材质组件与动效设计系统.md)。

## 4. 修改与验证

先确认语义角色和共享使用者，再修改单一源；验证实际浅深主题、英文、选中/禁用/焦点/错误状态。颜色守卫、对比度测试与真实页面共同验证；历史对比度数字只属于当时输入，不能直接沿用。
