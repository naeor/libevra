本规范负责「控件用途 → 风格表现」。颜色、字号、布局仍遵循同目录原有规范；不替代业务权限、导航协调器或特殊动画。

### 动效语义与实验依赖

页面导航由 `workspace/paneHistory.ts` 与 `PaneRouter.tsx` 管理，S19 呈现层只消费已接受的 push/pop；`pilot.tsx` 是唯一协调器，按账本空间海浪 → switchTab → objectExpand → 记账工作区 → 默认次级导航的顺序判定，五类语义各用一个呈现器，不因材质相同而叠加另一套导航或入场动画。账目容器 Object Expand 的正式接入与独立演示边界见 §6；正式实现复用原型几何，演示数据不进入业务。

`s19/motion/abcPresentation.ts` 和 `aTabs.ts` 仍直接引用 `experiments/abc-motion/controller.js` 与 `tab-glide.js`，由开发风格入口注册；`abcBridge.ts` 还依赖对应类型声明。该目录不能按“历史实验”删除。后续建议在独立任务中把被产品消费的控制器及类型迁入共享呈现层，保留实验页作为调用方，并回归快速反向、返回、滚动恢复与减少动态效果；本轮维护不搬动实现。

## 2. 正式可调用材质与候选边界

| 风格 | 稳定默认 | 显式变体与边界 |
|---|---|---|
| A / Soft Surface | 柔和实体薄片，圆润边缘，宽浅阴影 | 继续复用现有卡片、工具、品牌色角色 |
| B1 / Porcelain | 原有不透明 Satin 瓷底 | `finish: "satin" / "glazed"` 共用实体底座、圆角、厚度；反射默认 60%。Satin 宽柔，Glazed 窄亮并有虚拟光源，不采样后方背景 |
| B2 / Glass | 原有稳定玻璃，保留清透／均衡／柔和 | `frosted` 用原生背景模糊；`clear` / `lens` 在普通 DOM 场景降级稳定玻璃。`optics: "enhanced"` 显式启用轻量边缘候选，不等于真实折射 |
| C / Classic Surface | 原有清楚的实体纸面 | 忽略不属于 C 的瓷/玻璃候选，不替换经典视觉语言 |

已确认参数只在 `MATERIAL_DEFAULTS` 定义：Frosted 放大目标 1.03×，Clear/Lens 1.05×；边缘 45%，左上亮、右下暗；瓷反射 60%。Material Lab 从这里读取。倍率是**有适当纹理时的目标**，不是任意 DOM 背景的承诺；`materialCapability()` 明确返回当前 DOM 实际倍率 1。不得为此持续截图、复制 DOM 或引入曲面 WebGL 生产管线。已有纹理采样代码仍只由 Lab 引入。

普通组件默认 `finish: "auto", optics: "stable"`。新候选没有通过本轮 iPhone 验收前不得批量开启；调用处去掉 `appearance` 即回到稳定路径。瓷面实验的共用配方迁出不改变 Lab 的已选参数。

显式瓷面/增强玻璃用局部叠层承载反射，弹窗应放在页面层与卡片同级；已有把弹窗嵌在卡片内部的业务保持稳定默认，不直接开启候选，以免改变弹窗相对其他页面层的叠放顺序。材质伪元素不接收点击，滤镜不放在内容祖先上。

B2 原始三档值与账号偏好不变。展示卡片用 content；操作面使用 chrome，并令填充至少为 `contentFill + 0.12`，避免柔和档的操作面反而比展示卡片更透。原有模糊继续只作用于面板的装饰伪元素，不模糊文字、不在含 fixed 子节点的父容器加滤镜。输入、品牌主按钮、危险操作不接受透明材质覆盖。

## 3. 控件用途 → 默认表现

| 用途 / 调用 | A | B1 | B2 | C | 形状、状态与层级 |
|---|---|---|---|---|---|
| `Button` / `primary`：保存、完成 | 实体品牌薄片 | 品牌色实体瓷感 | 高不透明品牌底 | 实体品牌底 | 既有 field 圆角；焦点环；禁用/加载阻止操作 |
| `secondary`：取消、查看 | 品牌浅底 | 不透明瓷底 | 清楚的操作浅底 | 浅色实体 | 不与主要操作争夺层级 |
| `danger` / `danger-quiet` | 四风格均用主题危险色语义 | 同左 | 同左，不玻璃化 | 同左 | 实底用于主要破坏操作，描边用于次要；不替代确认逻辑 |
| `IconButton` | 轻薄工具片 | 瓷片 | 亮面操作玻璃 | 纸面 | 正圆 44px 点击区；必须传 `label` |
| `CapsuleButton` | 实体浅阴影 | 温润瓷片 | 半透明亮面 | 纸面 | 胶囊、自适应/省略；均无独立背景模糊 |
| `Card`：数据展示 | 薄片 | Satin 基底 | 内容玻璃 | 纸面 | card 圆角、普通层级；不假装可点击 |
| `ActionCard`：整块点击 | 同 Card | 同 Card | 同 Card | 同 Card | 原生 button；焦点、按压、选中/禁用；不得嵌套按钮 |
| 可编辑卡片 | `Card` 内放 `TextField` / `IconButton` | 同左 | 同左 | 同左 | 编辑入口是独立控件，不把容器改成按钮 |
| `BottomSheet` / `ChoiceSheet` | 实体操作薄片 | 现有瓷操作面 | 可读性优先的操作玻璃 | 实体纸面 | 既有 sheet 圆角、遮罩与层级；复用焦点、关闭、安全区 |
| `ConfirmDialog` | 实体确认面 | 瓷操作面 | 操作玻璃 | 实体确认面 | 既有中央对话框；安全选项优先获得焦点 |
| `TextField` | 四风格均保留清晰实体输入内衬 | 同左 | 同左 | 同左 | label/hint 关联；无透明采样；沿用 focus/disabled/invalid 语义 |
| `SegmentedControl` / `Switch` | 按原 Token 映射轨道与选中面 | 同左 | 同左 | 同左 | 受控值、真实 disabled；分段复用已确认滑动胶囊 |

`Button` 保持原来的默认 `fullWidth=true` 与表单提交行为。工具/胶囊/操作卡片默认为 `type="button"`。`loading` 会设置真实 `disabled` 与 `aria-busy`；文字仍由调用者提供，不因减少动态效果而消失。原 `disabledClassName` 的优先级保留。

## 4. 调用与有限覆盖

以下路径适用于 `apps/web/src/pages/` 中的调用者；从其他目录调用时调整相对路径。

```tsx
import { Button } from "../components/Button.js";
import { Card, ActionCard } from "../components/Card.js";
import { IconButton, CapsuleButton, Switch, SegmentedControl } from "../components/ui/PurposeControls.js";
import { MotionPresence } from "../components/ui/ComponentMotion.js";

<Button variant="primary" motion loading={busy} onClick={save}>保存</Button>
<Card>普通展示内容</Card>
<ActionCard onClick={openDetails}>查看详情</ActionCard>
<Card appearance={{ finish: "glazed" }}>少量瓷面强调</Card>
<Card appearance={{ finish: "frosted", optics: "enhanced" }}>显式玻璃候选</Card>
<MotionPresence visible={needsCaption}>
  <CapsuleButton onClick={openPicker}>筛选条件</CapsuleButton>
</MotionPresence>
```

高级 `appearance` 仅有 `finish`、`optics`、`shape`（default/pill/circle）、`elevation`（default/flat/raised）。不提供任意颜色覆盖：品牌、危险、正文颜色来自用途与主题。变体只在所属风格生效；primary/danger/field 拒绝透明变体。大多数调用无需 `appearance`。

Gallery 的边缘/反射/卡片圆角由局部 `materialTuningStyle()` 设置并限幅；展示填充在独立文档内使用既有 B2 映射。正式页面不要复制 Gallery 的调参面板、滑块值或局部变量，产品偏好仍由原控制器管理。

## 5. 动作与触发必须分开

| 动作 | 允许触发 | 默认参数 A / B1 / B2 / C | 不该触发 |
|---|---|---|---|
| Press | `Button motion` 的真实按下/释放；工具默认启用 | 120 / 100 / 100 / 80ms，轻微 scale | 挂载、禁用、普通渲染；旧特殊动效按钮不再叠加 |
| Select | Switch 的 checked 改变 | 200 / 180 / 180 / 120ms | 挂载；分段胶囊已有独立 200ms，不套第二层 |
| Reveal | 持续挂载的 `MotionPresence` false→true | 220 / 200 / 200 / 140ms | 初次挂载，true→true，两个都显示胶囊的页面互切 |
| Dismiss | true→false；先 inert，结束后 hidden | 180 / 180 / 180 / 120ms | 不依靠延迟改变导航或业务状态 |
| Feedback | 完成事件令 `useComponentFeedback(ref, signal)` 的 signal 改变 | 240 / 200 / 220 / 160ms | 挂载、失败、仅点击但尚未完成 |
| Loading | 明确 busy 状态 | 1000 / 1100 / 950 / 900ms 周期 | 无条件循环；退出状态即卸载指示器 |

时长权威值在 `component-motion.css`；A 宽柔、B1 克制、B2 轻盈、C 简短。WAAPI 从当前呈现位置取消/反向，结束清理；隐藏或卸载清理。减少动态效果时不做位移动画，保留状态文字。不要给 `MotionPresence` 使用路由 pathname 作为 key；它不决定导航目标、历史或滚动恢复。

原 BottomSheet/ConfirmDialog/ChoiceSheet、底栏指示器、账本胶囊、明细收缩、搜索和专属业务转场继续使用原协调器。**不得为展示通用动效而重包这些组件。**

## 6. 新增组件的最短流程

### 共享壁纸与材质的组合

背景只从 `s19/wallpaper.css` 取 `--lv-wallpaper-bg`，旧材质和转场读取的 `--s19-bg` 是同一来源的别名。三种配方为 aurora（默认柔和极光）、luminous（清透光域）、quiet（静谧渐层）；几何由壁纸决定，光色由既有 `brand / canvas / surface` 和原 B2 暖冷辅光派生，风格仅调整扩散/强度。A 是宽柔打光，B1 使用更宽的低频过渡而不模糊前景，B2 保留清晰光色与既有展示/操作玻璃及三档参数，C 降低对比度。深色压低环境亮度，保留现有深色组件规则。

`visualStyle.ts` 继续承担本机外观状态与订阅；`libevra.wallpaper` 只保存经过白名单校验的壁纸 ID，没有新后端或账户配置。旧用户、未知值使用极光，不改写其他偏好；读写失败保留会话值，storage 事件跟随其他标签页。主题、风格、玻璃预设和壁纸互不重置。

文档固定背景与大屏固定工作区共用配方，页面不复制渐变、不截取 DOM，也不新增持续滤镜或循环。账本空间欢迎态壁纸透明，展开时只读取既有 `--p / --q4`，不改变海浪几何、材质、品牌交接与导航协调器。外观页三张缩略图使用同一配方及适用布局下的既有材质 Token。

### 账目容器变形的接入边界

`prototype/` 保存电脑端已验收的独立演示。`geometry.mjs` 的坐标、关键帧、返回目标可靠性和周围内容姿态计算不依赖业务；正式 `s19/motion/objectExpand.ts` 直接导入它，由既有 MotionPilot / PaneRouter 在提交前捕获实际来源，提交后对空容器和真实 React 详情分别动画。原型 `motion.mjs` 的 `ContainerPresentation` 仍服务演示 DOM，模拟数据不进入业务；独立 URL 不改变 Object Expand 语义。业务入口通过 `data-object-source` 标记匹配的目标路径，只有实际导航成功才播放，不改变选择、冲突、权限或拖放判断。

共享机制在点击时测量来源，几何与内容在帧锚定时钟上按同一条曲线密集采样，交给 WAAPI 播放；时长与交接比例来自 Motion Token（展开 320ms、收回 300ms）。详情文字不变形：内容按容器宽度等比缩放。A 约 1.1 倍前移并压暗周围，B1 按容器节奏把上下内容完整挤出舞台，B2 后方不动、玻璃（模糊 + 透明填充）直接画在容器本身，C 轻微避让。来源呈现副本 inert、不带事件；返回使用原坐标和滚动状态，目标删除、改序、超出安全区或视口改变时淡出降级。减少动态效果直接提交；新导航、中断与卸载释放动画并复原被借用的真实节点。真机 Safari 的最终观感仍需单独验收。

1.19.44 起的接入约束（卡片逐渐成为详情）：点击当帧容器从来源卡片的实际位置与尺寸开始长大（第一帧透明叠在真实卡片上，12% 内补满）；详情页面用 React transition 在后台提交，到达后放进容器——按容器宽度等比缩放、顶端对齐、按容器圆角裁剪——随容器一起长大并在 6%–40% 渐显，所以任何时刻容器里都有内容，不再有“铺满却还是空的”一段。详情还没提交时容器最多长到进度 0.12 并慢速蠕动到 0.16，到达即放开。React 提交时把原页面移出工作区，同一个节点随即接到背景舞台（层级 35，在页面之上、常驻底栏 40 之下）继续它的风格响应，不克隆整页；B1 下半页是唯一一张副本，底栏用一份副本留在原处直到被容器盖住。容器在 70% 铺满，原页面与底栏副本在 68%–75% 于其下退场，容器底色 73%–97% 淡回统一壁纸，详情（层级 46）停在最终位置。几何是一条连续曲线（`cubic-bezier(.32,.2,.18,1)`）：原型的两段节奏在 60Hz 手机上表现为“停一帧、再一帧跳出 275px”，现在 12 个 ≥6px 的生长帧、单帧最多约 145px；A 的前移作为叠加的一次起伏保留。详情未到达前返回：路由交回原页，容器从当前姿态缩回卡片、后半段淡去。已到达后返回或正常收回：同步提交列表（恢复滚动），被移出的详情节点放进前景，在收缩的容器里按同一几何缩小、50%–82% 淡出，容器回到实际来源后 78%–100% 淡出露出真实卡片；列表与底栏在容器补满后（8%–10%）出现，出现后移除透明度动画并清掉首帧静态值。带 `backdrop-filter` 的元素不能放在做透明度动画的祖先里（祖先会成为背景根，玻璃读不到后方），这是 B2 容器不用 frosted `::before`、B2 原页面推迟透明度动画、详情渐显结束即移除透明度动画的原因。

帧锚定时钟（`lib/frameClock.ts`）：Object Expand、主 Tab 交换与明细搜索开合的 WAAPI 动画创建后立即暂停，由 rAF 写 `currentTime`；第一帧固定是起始姿态。正常帧间隔取最近 5 帧的中位数（60 / 120Hz 与低电量 30Hz 各按自己的节奏），明显更长的间隔（提交、首次绘制、长任务）只推进一个正常帧，停顿之后不会一下跳出一大段（记账工作区同样用这个时钟；账本空间海浪用同一步长推进主进度，层的弹簧也按这个步长积分）（1.19.43 推进 34ms，Tab 曲线下等于一帧跳 30%）；单帧仍以 34ms 为上限。`limit` 让转场在内容尚未提交时只走到约定位置（主 Tab 与 Object Expand 等新页面）。连续 600ms 没有 rAF（后台、停帧）时看门狗直接收尾。原因是 iPhone Safari 合成器动画以创建时刻为起点，紧接着的重帧会吃掉前一两百毫秒，第一帧就落在中后段；Chromium 在首帧显示时才定起点，桌面逐帧测试测不出来。代价是这几类转场按 Safari 的 rAF 频率（通常 60Hz）更新。`?motion=1` 徽章显示每次转场的帧数、墙钟时长、首帧间隔与最长间隔，供真机核对。浏览器自带返回动画时（`PopStateEvent.hasUAVisualTransition`；旧 Safari 以边缘横向拖动或 touchcancel 判断）协调器只提交页面，不叠收回；视口只在宽度变化或高度变化超过 150px 时收束转场（只改变可视区的软键盘不打断记账工作区）。明细搜索点击当下只改 DOM 状态并在同一手势里聚焦（键盘照常弹出），胶囊从按钮实际位置左右展开，标题、右侧按钮、月份行、范围说明、S19 底衬与顶部收起读同一个 `--search-k`（与胶囊同一条控件形变曲线），React 状态在形变结束后同步；快速重复开合从当前姿态接续。

技术选择：Shared Element 是交互语义，FLIP 提供首尾几何，WAAPI 承担可取消的呈现；现有 View Transition API 继续服务普通页面转场，对象展开不再叠加浏览器快照动画。选择 WAAPI 是为了独立控制空容器、文字淡入和四种背景响应，并保留无 API 的即时降级；WebKit 在 [Safari 13.1 / iOS 13.4](https://webkit.org/blog/10266/web-animations-in-safari-13-1/) 提供 WAAPI，[Safari 18](https://webkit.org/blog/15865/webkit-features-in-safari-18-0/) 才提供 View Transitions，二者不作为相同的支持门槛。

主 Tab 交换（switchTab，`tabExchange.ts`）：四个主 Tab 之间整页横向交换，两页共用 280ms 与 `cubic-bezier(.3,.15,.15,1)`（起步约 4% / 帧、10%→90% 约 133ms、末段平稳减速；Tab Switch Lab 的 200ms 前冲曲线前两帧就走完 67%）。点击与新页面初始化解耦：点击当帧移动**真实的旧页面**，新页面用 React transition 在后台渲染；旧页先走到约 8%，未到达就慢速蠕动（最多约 13%）。React 提交新页面时把旧页从工作区移除，同一个节点随即接到交换舞台（统一壁纸之上、真实页面之下）继续离开，新页面按时钟当前时间对齐进入，两步在同一帧绘制之前完成；不克隆旧页。分析页的网格宽度首帧按工作区宽度估计（不再先按 0 宽渲染再整页重排），卡片正文按测量尺寸以 transition 渲染并短暂淡入，不占住交换的帧。常驻底栏、加号与壁纸不移动。最左到最右只交换一次；正在交换时只排最后一次点击，完成后从实际所在页出发；浏览器返回同样按 Tab 顺序决定方向。各 Tab 的最后筛选（查询参数，按账本隔离）由 PaneShell 记住，滚动由协调器按 Tab 恢复；再点当前 Tab 仍回到根。输入中、弹窗打开、深色或减少动态效果时即时切换。新页面 1.5 秒仍未提交则放弃呈现、只交付页面。

默认次级导航由 `isDefaultMotionEdge` 统一覆盖：从任一主层级或次级页面 PUSH 进入另一个次级页面都使用各风格既有的“新页从右侧覆盖”转场，返回只回放刚发生过的那条边的反向；账本空间（进入与离开是它专属的海浪转场，见下）、登录/恢复等外壳外入口不参与。查询参数属于页面状态，不再阻止转场；同一页面换筛选保持滚动。B1 轨道只移动透明正文组（`[data-motion-body]`）：页面既没有 `<main>` 也没有可拆分的标签页顶栏时（明细首页 `.detail-root`、卡片编辑等），整页作为一个轨道移动——1.19.45 之前这些页面的正文不进轨道，新页叠在原地不动的旧页上（明细 →「更多」的重合）。

`navigation.ts` 单独声明层级，`enterMode.ts` 只负责记账工作区（五种记账方式页及其识别核对步骤，`inEntryWorkspace`）的进入、离开与工作区内切换，不成为第二个 Router。四个 Tab 根页与五种工作模式显示 PaneShell 持有的 BottomNav，次级页隐藏；工作台编辑继续使用自己的操作栏。

记账工作区（1.19.45 起，`ENTER_MODE`）：**进入**——点击后新工作区带着与统一壁纸逐像素对齐的纸面（外层平移、内层反向平移，不用滤镜或裁切）从屏幕底边升起、经过底栏后方接替当前页面，320ms `(.32,.4,.16,1)`；原页面按风格让位：C 上移屏高 18% 并轻微压暗、A 退远缩放（0.92）并压暗、B1 与新工作区在同一条竖向轨道上移（间隔 24px，不需要纸面）、B2 原地被壁纸色薄层“雾化”（不用会破坏玻璃背景的滤镜）。与主 Tab 同一套交接：点击当帧就移动真实旧页，新页面用 React transition 在后台渲染，未到达时纸面最多升到底栏上缘（被底栏挡住，不露出空白工作区），React 移出旧页后同一节点接到页面之下的舞台继续让位、新页面按时钟当前时间对齐进入。例外是挂载即聚焦金额框的手动记账（`focusesOnEntry`）：仍在点击里同步提交，iOS 才会弹出键盘，也不再把焦点移到标题上；拍照的文件选择仍在卡片点击里同步打开、选完才导航；其余方式页都不在挂载时自动聚焦或读剪贴板。只改变可视区的软键盘不打断工作区转场（舞台固定在布局视口上）。**离开**——从工作区回到主 Tab（保存后「返回主页」、底栏 Tab、返回键）或记录过的来源页时，目标页面提交前什么都不动，到达当帧工作区接到页面之上（层级 20，在底栏 40 之下）的舞台、带着纸面下沉 280ms，原页面从让位姿态回到原位；列表刷新与滚动照常恢复。进入还没结束就返回时，从当前姿态原路倒放（返回页先隐藏，由舞台里停着的旧页代表，结束时换回）。**工作区内切换**——「再记一笔」、识别结果回到输入方式、换一种记账方式：上一屏（保存成功的那一笔）向上收起 24px 并在前 40% 淡出，新的一笔从下方 32px 升入、自 35% 起淡入，260ms；「再记一笔」通过 `lib/entryFlow.ts` 交给呈现器，仍在点击里同步提交，焦点照旧交回金额框。保存失败、取消、重复提交都不导航，因此不会出现“已保存”的转场。转场期间整页被平移，挂载时量几何的代码会量到错误位置：保存条的键盘避让（`useKeyboardInset`）在页面带 `data-mode-live / data-tab-live / data-object-live` 时推迟到转场结束再量。

账本空间海浪转场（1.19.45 起，品牌转场，`LEDGER_TIDE`，`s19/motion/tide.ts`）：进入 `/start` 时，账本空间的四层海浪从屏幕上缘涌下，按开始页既有的“下行”节奏 4→3→2→1 接力覆盖当前页面（最浅的 4 号领头）；4 号盖满整屏时在下方后台提交账本空间，1、2 号盖满整屏后按既有的“退去”节奏（上行 1→2→3→4）退到账本空间自己的海浪位置（顶栏态，首次进入为展开态），与页面海浪逐像素重合后 140ms 淡出交接，品牌字样随之出现；整段约 0.9–1 秒。离开（进入账本、返回）反过来：账本空间自己的海浪先叠一层相同的海浪并盖住品牌字样，涌下盖满整屏，提交目标页，再整体退出屏幕上缘。层间先后与回弹就是开始页的 `LayerMotion`（在归一化进度上驱动），浪沿形状、左右游动与材质绘制都是开始页的原函数；环境相位与页面共享（`s19/oceanPhase.ts`），交接不错位；海浪覆盖范围先铺一层统一壁纸，B2 半透明玻璃不透出旧页。转场海浪整屏盖着时页面自己的海浪只推进相位、不重画。只在浅色 A / B1 / B2 / C 播放（开始页海浪只有这四种材质）；Original、深色、减少动态效果与浏览器自带返回动画时直接切换；账本空间内部的成员 / 分享子页面（`/start/…`）不在此列；账号切换账本仍是整页重新载入，不播放；明细标题「Libevra」进入账本空间改为站内导航（原整页重新载入），与账本切换面板的入口一致。开发 / 测试构建的 S19 风格把手可整体缩放节奏（0.85× / 1× / 1.2×）并在当前页预演，只在本次会话生效。

汇总详情复用来源显示值与筛选后的 MiniEntry，不创建第二套金额统计；结余仅为范围内净收支，日均沿用既有天数和舍入。上下文缓存有界且隔离账号、账本和工作区，刷新/直接 URL 无上下文时引导返回明细重新打开。上下边缘色从共享壁纸色源混合并在配方边缘收敛，html 画布与 theme-color 消费同一令牌；手机外壳的 body 保持透明，壁纸只画在固定的 `body::before` 上（body 不是层叠上下文，给 body 上底色会盖住首屏壁纸，长页面滚过一屏后露出壁纸形成水平断层）。不截屏或逐帧采样；iOS 26 Safari 已不再可靠地读取 theme-color，原生工具栏颜色只作尽力建议。

### Motion Token

动效时长、缓动与交接节奏的唯一来源是 `apps/web/src/lib/motionTokens.ts`，按交互语义组织；业务代码读语义条目，不写新的毫秒数或 `cubic-bezier`。调整一类交互只改这里，相关页面一起更新。时长指帧锚定时钟上的**可见运动**，点击后的准备时间不计入，要靠减少同步工作（后台提交、首帧尺寸估计、时间切片）缩短；`phases` 是同一时钟上的比例，改时长时交接不变形。

| 语义 | 条目 | 当前值 | 使用方 |
|---|---|---|---|
| 普通次级导航 | `NAVIGATION` | B1 320ms `(.4,0,.2,1)`；B2 200ms `(.2,.75,.25,1)`；C 200ms `(.22,.68,.25,1)`；A 按变体 250–400ms | ABC 呈现控制器（时长由此传入）、MotionEngine |
| 主 Tab 横向交换 | `TAB_SWITCH` | 280ms `(.3,.15,.15,1)`；未提交时先走 26ms、蠕动至 36ms；1.5s 放弃 | `tabExchange.ts` |
| Object Expand | `OBJECT_EXPAND` | 展开 320ms / 收回 300ms；几何 `(.32,.2,.18,1)`；交接比例见源码注释；等内容 0.12→0.16 | `objectExpand.ts` |
| 控件形变 | `CONTROL_MORPH` | 200ms `(.2,.72,.2,1)` | 明细搜索胶囊、顶部收起与标题让位 |
| 记账工作区 | `ENTER_MODE` | 进入 320ms / 离开 280ms `(.32,.4,.16,1)`（`?enterMs=` 可比较 280 / 360）；等新页面时最多升到底栏上缘；原页面让位（C 18% + 薄层 .2、A 0.92 + .45、B2 薄层 .4、B1 同轨间隔 24px）；再记一笔 260ms | `enterMode.ts`、`lib/entryFlow.ts` |

设计原则：点击后一两帧内必须出现可见变化；大部分时长留给真实可见的移动，而不是等待或几乎察觉不到的减速。高频反馈最短；普通页面切换与控件形变轻快（约 200–320ms）；需要表达空间关系的对象展开可稍长（约 300–350ms）；普通转场不超过 400ms（记账工作区是整屏的工作区交接，取 300ms 级：1.19.44 的 140ms 揭示走完 844px 时第一帧就是 329px，看不出“从下面上来”），品牌动效另行判断（账本空间海浪约 1 秒）。曲线优先选起步有响应、中段持续、末段平稳的形状，用 60Hz 逐帧位移分布（每帧位移、可见帧数、10%→90% 时长）验证，不只看配置的 duration。底栏指示器与开始页海浪本身（`LAYER_MOTION`）等专属动效的参数留在各自文件，不作为可复用语义；账本空间的进入 / 离开转场登记在 `LEDGER_TIDE`。

| 胶囊与可选标签 | `CapsuleButton`；新增 `FilterChip` | OcrReviewDetailPage 的选择按钮、页面内筛选胶囊 | 导航辅助用 CapsuleButton；独立开关条件用 FilterChip |
| 分段/切换 | `SegmentedControl`、`SlidingSelection`、`Switch` | 业务分段已经逐步接入 SlidingSelection | 互斥单选用 SegmentedControl；原胶囊不叠加动画 |
| 输入/搜索 | `TextField`、`PasswordField`、`AmountField` | AttachmentsPage 普通 search；DetailPage 专属搜索 | 普通搜索直接 TextField type="search"；不新增同义 SearchField；金额和密码不重写 |
| 选择器 | `ChoiceSheet`、`ChoiceDialog`、已有日期/币种选择器 | 业务选择器还有自己的开关状态 | 保留成熟弹层；不新造通用选择弹窗 |
| 展示/点击/编辑卡片 | `Card`、`ActionCard`、`SettingsCard` | 账本/分析业务卡片独立结构 | 新普通卡片用现有入口；含编辑控件用 Card，不嵌套按钮 |
| 面板/确认 | `BottomSheet`、`ConfirmDialog` | 业务面板的内容和协调器独立 | 复用焦点、滚动锁、关闭语义；不套第二个 Presence |
| 加载/禁用/选中 | Button loading/disabled、受控选择组件 | LedgerImportPage/ScanPage 手写加载指示 | 按钮加载沿用 Button；文字加载用 StatusMessage loading |
| 错误/完成 | 新增 `StatusMessage`；TextField 新增 error | LedgerPage、LedgerInvitePage、JoinPage 等重复 alert/status 样式 | 字段错误传 error，区块错误/完成用 StatusMessage；业务校验仍由页面负责 |

### 新接口与兼容性

统一从 `components/ui/StatusControls.tsx` 导入：

```tsx
<Badge tone="warning" size="small">待处理</Badge>
<FilterChip selected={selected} onSelectedChange={setSelected}>仅看已选</FilterChip>
<StatusMessage loading>正在加载</StatusMessage>
<StatusMessage tone="error">加载失败，请重试</StatusMessage>
<StatusMessage tone="success" completion={completedCount}>保存完成</StatusMessage>
<TextField label="名称" hint="填写显示名称" error={validationError ?? ""} />
```

- Badge 的 `tone` 为 neutral/success/warning/error，`size` 为 small/regular；使用既有语义色和胶囊角色，只有文字状态，无点击和 live region。不添加独立模糊。
- FilterChip 复用 CapsuleButton 的尺寸、材质、按压、disabled/appearance；`selected` 与回调受控。选中标记预留固定宽度，不因文字图标替换而抖动。互斥选择不要用多个 FilterChip 重造分段控制。
- StatusMessage 用已有语义软底与 field 圆角，保持文字清晰，不强制玻璃化。错误用 alert，其他状态用 status；loading 不遮蔽说明文字。图标槽固定，默认不入场；仅业务完成后递增 `completion` 播放已有 Feedback，同值或父组件渲染不重播。实际重试按钮可通过 children 组合。
- TextField 新增可选 `error`，同时关联错误、hint 和外部 aria-describedby。没有 error 的旧调用不变；已有手动 aria-invalid 仍可用。错误由真实校验结果提供，不在挂载时擅自校验。`error` 为 undefined 时省略该 prop（项目启用 exactOptionalPropertyTypes）。
- 普通控件允许 className 做容器宽度/间距调整，输入保留原生 size/disabled 属性；颜色使用语义 tone/variant，不散写任意色值。需要改变点击区时优先保留 44px 最小目标，不用缩放文字压缩控件。

### Coverage Agent 的使用顺序

先查本节与 Gallery 的「标签与状态」。该分类提供直接从正在渲染的 TSX 源码提取的完整示例，props 受同一份类型检查；复制到 `src/pages/` 可直接使用，其余目录调整 import 相对路径。其它分类的短示例是调用片段，业务回调由页面提供。

新控件先选语义组件，再传业务数据/回调；保留原权限条件、查询、导航和业务动画。只有至少两个真实场景缺少同一能力、且组合现有组件无法表达时才新增共享接口。旧页面按 Coverage 的任务逐项迁移，不把这份清单当成批量改动授权。

显示/隐藏沿用 MotionPresence 的布尔边沿；用于展开说明时配 aria-expanded/aria-controls，关闭立即 inert。需要保持附近控件位置时由容器预留内容槽，如 Gallery 示例；不同时叠加高度、位移和回弹动画。重渲染、同类页面切换、持久显示均不构成入场事件。减少动态效果和异常中断继续使用既有清理逻辑。
