设计权威规则：字体、布局、颜色、海浪、S19 组件与动效。

做全局归一前，先读文字规范 §13.3 的功能性例外和布局规范 §15.3 的容器职责；不能把动态几何、可辨认编号或滚动/键盘边界当作重复样式清理。各规范的历史依据保存旧试验，现行正文直接给出有效约束。

原始目标和已有成果仍在专题正文：文字规范 §10/§14、布局规范 §18、颜色语义 §5、主题实现 §16 及颜色清单的演进摘要。它们说明为什么采用现在的规则；逐项试验和旧值再沿历史依据追溯。

优先阅读[任务索引](../../00-%E7%B4%A2%E5%BC%95.md)定位权威规则，再按下表进入实现或子目录。目录清单不证明功能已验收。
