## 2. 弹出面板模板（所有者 2026-11-14 决定；1.19.58–1.19.59 已实施，仅本机；档位数值待看截图调整）

现行规则已写入 [S19 设计系统「弹出面板模板」](S19-材质组件与动效设计系统.md)，实施记录见 [1.19 版本记录](../../changelog/1.19.md) 1.19.58、1.19.59。下面保留决定原文与分类表，作为来源。

现状：弹层共享一套行为工具（退场、焦点、滚动锁、键盘抬升），但外观与结构没有统一模板，遮罩有三档深浅、五种关闭按钮、五种高度规则。按用途归为六类：

| 模板 | 用途 | 成员示例 |
|---|---|---|
| T1 选项、操作列表 | 从列表里选一项或执行一个操作 | 选币种、选账本、账本管理、软件更新“更多”、分析卡片菜单、排序、统计口径 |
| T2 表单编辑 | 填写少量字段 | 筛选、新建账本、分类编辑、批量修改 |
| T3 确认、警示 | 确认或在几个选项中选择 | 删除确认、二选一；分析的“放弃编辑”应改为此类 |
| T4 信息说明 | 展示信息，可附一个动作 | 头像创作注记、全部币种、账号编号、外观预览、账本通知 |
| T5 大面积编辑 | 内容多、接近全屏 | 批量添加、分析卡片编辑器、预设库、附件预览、同意书（门禁变体：不可随手关闭） |
| T6 轻量浮层菜单 | 锚定在按钮旁，无遮罩 | Pad 与电脑版的下拉菜单（留到 Pad 阶段） |

已决定的规则：

1. **遮罩**：任何情况下弹窗出现后背景都变暗以突出弹窗，深色模式同样变暗，不允许变亮；具体数值可以调整。浅色 Original 下底部面板约 0.25，中央对话框和全屏面板约 0.35；S19 的 A、C 风格补上自己的遮罩定义，与 B1、B2 深浅一致。
2. **对话框背后的 2px 背景模糊**去掉。
3. **信息说明类（T4）**用底部面板。
4. **下拉关闭**：所有底部面板支持下拉关闭；属于“关闭前询问”的面板，有改动时下拉也先询问。拖动条只显示在可以下拉的面板上。
5. **关闭入口**：统一右上角 ×；去掉列表底部重复的“关闭”行。
6. **关闭前询问**：轻量、操作少、使用频繁的弹窗直接关闭；重要、操作多、误关损失大、又不常用的弹窗在**确有改动时**先询问是否放弃修改，没有改动时直接关闭。涉及设置的编辑弹窗倾向于询问。点背景、下拉、×、Esc 与系统返回一视同仁。逐个弹窗的分类见下表（所有者 2026-11-14 确认）。
7. **高度**：参照 Apple HIG 的 detent（中档约半屏、大档接近全屏）、Material 的“初始不超过半屏、内容短则按内容”和 NN/g 的“部分遮盖、只适合短操作”，采用三个档位，每类模板固定一档：按内容（不超过半屏）用于 T4 和很短的列表；半屏（约 52%，与账本选择一致，内容多时在面板内滚动）用于 T1、T2；大档（接近全屏，统一一个值，顶部留出一点背景）用于 T5。中央对话框按内容。第一版只支持下拉关闭，不做半屏与大档之间的拖动切换。**全部实施后，把每个弹窗的实际效果展示给所有者，再按观感调整档位数值；不能为了固定比例让个别弹窗看起来别扭。**
8. **原生 `<dialog>` 弹窗**（附件预览、账本通知铃、账号编号）改用项目自己的面板组件，以获得统一材质、遮罩、动画，并在 Pad 分屏时只覆盖所在工作区。所有者强调 Libevra 要有自己的视觉风格，不直接套用浏览器或网站现成模板。
9. **Pad 与电脑版浮层菜单（T6）**留到 Pad 阶段再纳入规范。
10. 迁移弹窗时，账本管理里的可编辑判断、批量修改里的禁用原因等属于权限与显示判断，**只换外壳，判断原地不动**（AGENTS §5）。

### 关闭前询问：分类（所有者 2026-11-14 确认）

没有可编辑内容的弹窗（T1 列表、T3 确认、T4 信息说明、账本通知、附件预览）关闭不丢任何东西，一律直接关闭。下面只列有输入内容的弹窗：

| 弹窗 | 里面要填或改什么 | 使用频率 | 关闭前 | 理由 |
|---|---|---|---|---|
| 明细与分析筛选 | 多个维度勾选 | 很高 | 直接关（暂定） | 条件不少，但使用太频繁，频繁询问反而打扰；以后可再评估 |
| 排序、统计口径 | 单选 | 高 | 直接关 | 选择即生效 |
| 新建账本（Pad、电脑版侧栏） | 一个名称 | 低 | 直接关 | 只有一个字段 |
| 分类新增、编辑 | 名称、上级、排序、图标、颜色 | 低 | 询问 | 不常用，属于设置类编辑，所有者认为较重要 |
| 批量修改 | 勾选要改的分类、标签、支付方式 | 中 | 询问 | 一次影响多笔账目，所有者要求询问 |
| 留言“引用说明” | 写一段文字 | 低 | 询问 | 写下的文字丢失后要重写 |
| 批量添加 | 一次填写多笔账目 | 低 | 询问 | 输入多，误关损失大 |
| 分析卡片编辑器 | 指标、图表、筛选等多项配置 | 低 | 询问 | 配置多，误关损失大；目前关闭时不询问 |
| 分析预设库 | 浏览、导入、导出，不在面板内编辑 | 低 | 直接关 | 没有未保存的输入 |
| 同意书、重大公告 | 门禁，不能随手关闭 | — | 不适用 | 保持现有门禁行为 |

分析工作台退出编辑模式时已有“放弃编辑”确认，保持不变（按 T3 改外观）。

### 2.1 选中指示与已选条件标签（大部分已定，A 浮起改用 §2.2 的 A2 档，待所有者确认）

样板在开发用组件样板页“选中指示与条件标签”一节（`component-gallery.html?s19=a|b1|b2|c`，`ca554a53`、`2a7b6b46`），对比图保存在本机 `Claude outputs/S19-选中指示样板-20261114/`（被 Git 忽略）。

起因：B2 筛选面板里的浅绿实心选中块像贴在玻璃上的贴纸。所有者 2026-11-14 定下的方向（先在开发用组件样板页做对比样板，看图后再定稿）：

- **选中要有两个信号**：选中块（或浮起的选项）本身，加上选中项文字变为品牌色；不能只靠材质的细微差别。
- **会移动的选中**（筛选面板左侧维度导航、分段等）：
  - B1、B2：在选中项上放一块模拟玻璃（与底栏选中玻璃同一配方，不做真实背景模糊），切换时滑到新选项，移动带与底栏相同的轻微弹性；选中文字变品牌绿。**已定：玻璃不染色，保持透明**（所有者看过不染色与约 10% 品牌色调的对比图后决定，2026-11-14）。
  - A：不出现绿色块，被选中的那一项自己浮起来，浮起后文字变品牌绿；需要浮起与落下的小动画。符合 A“柔和、有空间感”的理念。第一版只有一点阴影，浮空感太弱（A 的卡片底与面板底几乎同色，影子又收得很小）；所有者要求加强空间感、**不加绿色**。第二版样板：分层阴影（接触影、中层影、宽环境影），影子用墨色而不是纯黑；环境影单独一层，浮起时一边下移、放大一边淡入；上缘亮线；浮起 3px、放大 3%，浮起带轻微越过、落下干净不回弹。参考了分层阴影与“越高影子越大越淡”的常见做法、visionOS 的放大加影悬停效果。所有者看后认为第二版偏大；第三版改用 §2.2 的 A2 浮起档（介于第一、二版之间），**待所有者确认。**
  - C：浅绿实底选中块作为一整块滑到新选项，文字同步变品牌绿；动效性格“经典、干脆”，时长偏短、几乎不回弹。
- **四种风格同一个“模型”**（所有者 2026-11-14）：每种风格都有同样的三类行为——会移动的选中、条件标签出现与消失、网格选中——并且都有对应动画，区别只在外观和动效性格（B1/B2 弹性玻璃、A 浮起、C 干脆滑动）。
- **已选条件标签**（如“2026年11月 ×”，可删除的对象，与选中指示区分）：**B2 已定为带淡绿的瓷片**（所有者 2026-11-14 看对比图后决定：放在不透明面板上时，磨砂玻璃背后没有可透出的内容，看起来与瓷片几乎一样，瓷片更稳、更易读）；B1 带淡绿的瓷片；A 带淡绿、轻轻浮起的柔和薄片（与选中浮起同一套分层阴影，低一档）；C 纸面加细线、绿色文字。出现时轻微放大淡入，删除时缩小淡出。所有者说明瓷片并非 B1 独有，B2 也有使用瓷片的地方。
- **候选原则（待写入章程时由所有者确认）**：材质由“它背后是什么”决定——直接浮在壁纸或页面内容上的元素（底栏、浮动按钮、顶部工具）用玻璃才有玻璃感；放在面板里面、背后是实心面板的元素（选中块、标签、输入框）用瓷片或实体，靠颜色与光影区分层级。
- **月份网格的选中项**：不做长距离滑动；B1、B2 玻璃在旧格淡出、新格淡入，A 选中格浮起，C 旧格与新格交叉淡化。
- **动效统一**：会移动的选中块与底栏选中玻璃共用同一套弹性参数，定稿后登记进 Motion Token；减少动态效果时直接切换。
- **后续**：样板定稿后，把“选中指示”“条件标签与徽章”等补入 S19 规格 §3 的用途表，并扩展为完整的语义材质章程（层级 → 用途 → 状态，四种风格各自的材质语言），全站同类控件收敛到统一组件。

### 2.2 A 风格浮起档位（草案，待所有者确认）

起因：A 选中浮起第一版太弱、第二版偏大；所有者 2026-11-14 希望介于两者之间，并把 A 里所有“浮起”规范成档位。盘点发现 A 现有十几种各写各的阴影配方（`apps/web/src/s19/s19-lab-tokens.css` A 段），有的用墨色、有的带品牌色，普通卡片的影子被负扩散收得几乎看不见，同一用途（例如分段选中与顶部工具）用了不同配方。

草案用同一个物理模型分五档：离开下面的平面越高，接触影越淡、环境影越大越往下越虚、位移越大；阴影一律用墨色（与背景同色相、更暗），不用纯黑。样板见组件样板页“A 浮起档位”一节（`8adf9e34`）。

| 档位 | 含义 | 配方要点 | 现有令牌归入（盘点） |
|---|---|---|---|
| A0 嵌入 | 凹进平面 | 只有内阴影 | `--s19-track-sh`（分段轨道、外观选项组） |
| A1 静置 | 贴在平面上 | 细边 + 近影 + 很小的环境影，不位移 | `--s19-card-sh`、`--s19-mini-sh`、`--s19-entry-sh`、摘要卡的 `*-sh-tight`（因容器裁切用贴身影）、`--s19-ticket-sh` |
| A2 浮起 | 从原位抬起 | 上缘亮线 + 接触影 + 中等环境影；上移 2px、放大 1.5% | 选中项、条件标签（新）；`--s19-pill-sh`（分段选中、外观选项选中、编辑控件）、`--s19-tool-sh`（顶部工具、搜索框、筛选入口、工具悬停） |
| A3 悬浮 | 浮在页面之上 | 更大更虚的环境影 | `--s19-key-sh`（账本卡、raised 材质）、`--s19-shelf-sh`（加号菜单入口卡）、`--s19-amount-sh`（金额框）、`--s19-plus-sh`（加号）、将来的提示条 |
| A4 覆盖 | 盖在页面之上的整层 | 宽而深的影（底部面板向上） | `--s19-sheet-sh`、`--s19-dialog-sh`、`--s19-dock-sh`、`--s19-action-bar-sh` |

不属于高度的：主按钮的品牌色光晕 `--s19-accent-sh` 是“强调”，单独保留。金额框、账本卡、加号现在的影子带品牌色，归档后是否保留这一点品牌色待定。

- **选中浮起第三版 = A2 档**：上移 2px、放大 1.5%（月份格 2%），环境影约为第二版的三分之二；浮起轻微越过再落定，落下干净不回弹。第一、二版在样板里保留为对照（`?alift=1|2`）。
- **定稿后**：把五档写成 A 的正式令牌（`--s19-a-elev-0…4` 一类），现有令牌改为引用档位；全站 A 的阴影只从档位取，不再各写配方。实施时逐页截图核对，避免某处突然变重或变轻。
- **将来的“浮起程度”自定义（所有者 2026-11-14 提出，很后期）**：五档都是同一个模型，可以用一个强度系数同时缩放阴影深浅与位移，做成“轻 / 标准 / 明显”之类的预设，与 B1 已有的“背景模糊：轻柔 / 标准 / 朦胧”同一种做法。前提是先完成上面的档位统一。

## 5. 中低优先级问题（审查结论，待上述事项讨论完后再做）

以下均为只读审查发现并经源码复核（标“未复核”的除外），不改变已定原则；建议修法只为让界面一致。

**中优先级**

- 手写的互斥选择与分段按钮：选中项被误认成主按钮（渐变加品牌投影），未选中项是不透明白片；另有登录切换、留言引用、账本导入三处手写分段完全没有材质。应统一到分段控件或胶囊按钮。
- 登录页整页不透明底色在 A、B1、B2 下盖住壁纸。
- 分析工作台放在弹出面板里的小控件没有材质，C 风格缺规则；编辑顶条是不透明底色。
- toast 有五套实现，系统里没有 toast 材质角色，撤销条渲染在外壳外。→ 所有者已定方向：随风格使用语义材质，统一为一个组件（§4）。
- 恢复码卡片的强调底被普通卡片材质盖住；邀请码、分享卡用私有透明度。材质缺“强调”变体。
- 从弹出面板里发起导航时，面板收起的 200ms 内被判为“有弹窗打开”，导致转场丢失；确认框（alertdialog）不在判断范围内。→ 随 §2 弹出面板模板在 1.19.58 处理。
- 几个“完成 / 返回”出口用前进方向跳转：OCR 核对完成、公告详情返回、月份下载完成、重新生成恢复码完成、账目详情完成。应改为回到来路页。
- 深色模式下转场规则不统一：Tab 与普通翻页即时，对象展开与记账工作区仍播放，且展开时的压暗层在深色下变亮。→ 压暗层变亮在 1.19.60 修正；哪些转场保留并入深色模式重做（§4）。
- 搜索键盘打开时点结果，键盘收起引起的可视区变化可能把对象展开收束到终点（推测，需真机）。
- 兼容选择器依赖类名巧合，改一个透明度或圆角类就会悄悄失去材质。
- 颜色守卫按文件名整份豁免 5 个文件，豁免理由与实际不符；A、B1、C 令牌没有完整性检查。
- `uiConsistency` 测试读入 CSS 后清空，等于没有扫描 CSS；缺少“弹层必须带材质钩子”“S19 CSS 必须带作用域”“动效写法白名单”等守卫。

**低优先级**

- 组件不统一：徽章、提示块、图标按钮、开关（三套）、浮层菜单、手写输入框各写各的；分段控件组件没有使用方，且读取令牌时不带作用域。
- 动效时长未登记到 Motion Token：弹层、遮罩、账本胶囊、加号菜单、Pad 工作区；部分提示的出现与消失没有动画，加号菜单缺减少动态分支。
- 两个调试用地址参数（`?enterMs=`、`?s19tab=`）在正式构建中也生效，后者写入后界面上改不回来。
- 批量添加里“去账本设置”做了不必要的整页重载。
- 退出或弃置当前账本时整页重载没有海浪遮盖（只能加遮盖，不能去掉整页重载）。→ 所有者决定加海浪遮盖，1.19.60 已完成。
- B2 翻页中途返回会先跳到终点（View Transition 无法倒放）。
- 部分列表打开账目不使用对象展开；从详情页跳回主 Tab 时没有转场。
- Original 风格下也显示约 20% 强度的壁纸，文档未说明是否有意。→ 所有者决定去掉，1.19.60 已完成。
- Pad 工作区动效、B2 快照预算按手机设定（iPad Pro 12.9 会降级）。
- 资料编辑草稿守卫直接写浏览器历史，与边缘返回判断的相互作用待查（推测）。
- 若干代码注释与实际行为不符（lab 文件“正式构建会删掉”等）。
- 未复核：手写输入框约 25 处、内联样式改圆角、几处可点击卡片被当成展示卡、游离的私有阴影、深色下写死白色、部分令牌只有 B2 定义、减少动态下关闭弹层仍等 200ms、底栏让位两套时长、私有入场动画、转场判定缺测试、Tab 列表重复登记。

## 6. 待所有者拍板（2026-11-14 汇总）

来源：1.19.58–1.19.60 三个实施 agent 的报告、Toast 方案（§4）、弹窗截图（本机 `Claude outputs/S19-弹窗档位截图-20261114/`，B2、390×844、游客模式）与选中指示样板（§2.1、§2.2）。每条附推荐；所有者答复后在此处改为“已定”，并移入对应章节。

**A. 弹窗档位与遮罩（看截图）**

1. 明细筛选、分析筛选在半屏档（约 52%）下太挤：左栏“币种”被底部操作栏切掉，“附件”要滚动才看到，月份网格只露出第一行。1.19.58 之前筛选是固定 560px（约 66%）。推荐：筛选单独用一个“高半屏”档（约 66%，可调），其余 T1 / T2 仍用半屏。
2. 中央确认框（T3）背后的变暗在 B2 下很淡：S19 的底部面板与对话框共用同一个 `--s19-scrim`（B2 .22），而 Original 是面板 .25、对话框 .35 两档。推荐：S19 也分两档，对话框比底部面板深一档。
3. 分析工作台的“添加卡片”托盘不是模板面板（没有遮罩、四周留边、没有拖动条）。它需要边看工作台边拖卡片，推荐保留为特殊“托盘”，只统一材质与圆角，不纳入六类模板。
4. 游客模式截不到的弹窗（账本选择与管理、软件更新「更多」、头像创作注记、外观预览、账本通知、附件预览与排序、批量添加、批量修改）需要正式账号，只能在所有者的设备上看（部署后或本机登录）。

**B. 弹出面板模板实施中留下的**
