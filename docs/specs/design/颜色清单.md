# Libevra 颜色清单与局部例外

本文只维护局部颜色例外与实现入口；产品色彩语义见[颜色语义规范](颜色语义与配色规范.md)，主题映射与固定色边界见[实现规范](颜色主题系统实现规范.md)。全局 Token 数值以 `apps/web/src/index.css` 为准，不保留旧 19 色或 31 色统计作为现行清单。

### S19 海浪曲面（2026-11-08）

`s19/ocean-material.css` 只消费 `ocean-1…4 / on-ocean / surface / ink / control-knob`，A／B1 保持不透明，B2 从原海浪色混入 8% surface，再按 1…4 层使用 54%／43%／34%／25% 填充。高光、阴影与浅刻印也由现有令牌派生，不新增全局颜色角色；C／Original／深色不变。材质、覆盖遮罩和大小品牌规则统一见[海浪要求](海浪效果要求.md#s19-分层转场与材质11936b1--b2-材质-11937光源时机与内容落差-11938光照收尾-119392026-11-08)。

### B2 玻璃材质（2026-11-07）

手机浅色 B2 的局部 `--s19-*` 材质令牌归于 `apps/web/src/index.css` 的 B2 区块：环境颜色沿用已验证渐变，内容填充使用 `rgb(250 251 249 / alpha)`，高光使用白色，操作层填充沿用该区块的玻璃底色。透明度与模糊的统一定义在 `apps/web/src/s19/b2Glass.ts`；不新增全局颜色角色，不改其他风格、深色、Pad 或桌面色盘。

中央记账菜单的 `--s19-entry-bg / -sh / -filter` 分别复用工具填充、工具高光阴影和完整表面模糊（饱和度 1.5）。三档预设仍走同一参数源：菜单填充随栏面透明度、模糊随表面强度；不使用旧页透出强度作为菜单不透明度。原生模糊仅覆盖实际菜单及 12px 顶缘渐隐，到底栏背景起点为止，五张卡不重复模糊。A 菜单复用实体卡片及环境色渐变；B1 入口保留瓷片，背景复用自身工具填充及栏面滤镜、沿用 B2 的局部渐隐范围；C 保持原材质。

手机账本胶囊四风格均不使用背景模糊：A / B1 / C 沿用各自 `--s19-card-bg / -sh`；B2 的 `--s19-book-bg` 将 30% 工具填充与 70% `surface` 混合，`--s19-book-sh` 沿用工具边缘高光与轻影。较高的填充保证无模糊时名称清晰，仍随栏面预设保留透色差异，不加整宽背景条。


### 降临特典主题配色（2026-10-25）

仅 `data-avatar-id="descent-special"` 使用以下绿色审核配色；其他六色盘通过 `index.css` 既有品牌令牌派生，同步跟随浅深模式。浅底绿色默认值在 `08-descent-special.svg`，深底由局部变量覆盖；不影响其他头像或全局颜色角色。

| 角色 | 浅底 | 深底 |
|---|---|---|
| `--descent-bg` 底盘 | `#edf5f0` | `#447d63` |
| `--descent-star` 星体 | `#55997a` | `#fffdf5` |
| `--descent-outer` 尾迹 | `#c6ddcc` | `#6c9c80` |
| `--descent-halo` 辉光 | `#6ca58a` | `#d4e4d5` |
| `--descent-flower` 四片花瓣 | `#e3eee6` | `#4c846a` |
| `--descent-special` 特殊瓣 | `#dae8de` | `#588e74` |

特殊瓣在浅底更深、深底更亮，保持背景暗纹层次。

非绿色浅底采用 `brand-soft` 底盘、`brand` 星体；尾迹为底盘混入 25% 品牌色，辉光为品牌色混入 15% 底盘，四片花瓣和特殊瓣分别混入 6% / 12% 品牌色。非绿色深底采用 63% `brand` 与黑色混合的底盘，暖白星体不变；尾迹为 55% `brand` 与底盘混合，辉光为 60% `brand-dark` 与白色混合；四片花瓣和特殊瓣分别向底盘混入 8% / 18% 品牌色。混色空间统一为 sRGB，SVG 几何保持不变。


## 代码定位

- 全局与七主题映射：`apps/web/src/index.css`。
- 图表调色板：`apps/web/src/lib/chart/theme.ts`；分类排名映射的已知限制与未来方案见实现规范 §6。
- S19 局部材质、环境和海浪效果：以 S19 设计系统、海浪规格和各自代码为准。
- 用户标签色是数据，不能被主题替换；二维码等固定色例外只在实现规范定义。
