## 1. 结论摘要

**可直接复用（已经过代码确认）**

1. 交易业务日期字段真实存在且语义明确：`Transaction.occurredLocalDate`（`date`，本地日历日），另有 `occurredAt`（瞬间）与 `occurredTz`（IANA 时区）分离存储；分组/过滤应一律用 `occurredLocalDate`。
2. 日历运算已有 shared 基础：`packages/shared/src/stats.ts` 的 `addDays / daysBetween / startOfMonth / endOfMonth / comparisonRangeFor / fillSeriesGaps / rangeForPreset`，均为 `YYYY-MM-DD` 字符串、UTC 仅作民用日历计算。
3. 月归属与“月至今”比较口径已有既定实现：整自然月比上一整月；月至今比上月同段（短月截断）；滚动窗口比等长前一窗口。
4. 综合汇率逐笔折算与完整性已有权威实现（S16-D）：`packages/shared/src/fx.ts` 的 `aggregateFx` 返回 `complete / missingCount / reviewNeededCount / reviewDates / months`，B 必须复用、不得重算。
5. 图表基础设施可复用：`apps/web/src/components/chart/{ChartFrame,Axis,Legend,useElementWidth}.tsx`、`apps/web/src/lib/chart/{theme,scales,geometry,format,guards}.ts`，以及既有 `charts/{TrendChart,CalendarHeatmap,CategoryDonut,SummaryPanel}.tsx`。
6. 权限入口可增量复用：API `requireAuth` + `request.book`（`apps/api/src/ledger/access.ts`）；统计只按当前 `bookId` 查询，不新增权限模型。

**B-0 补齐的缺口（本分支已提交）**

- 自然周（周一起）与 ISO 周键：原 `STATS_BUCKETS` 只有 `day|month`，仓库没有任何周桶实现 → `timeCalendar.ts` 提供 `weekSpan / isoWeekKey / enumerateBuckets`。
- 统一半开区间 `[start, end)` 与解析：原 `DateRange` 是闭区间，且无通用 span 类型 → `TimeSpan / parseTimeSpan / spanFromInclusiveDates / spanToInclusive`。
- 时间桶完整性状态：原 `fillSeriesGaps` 无条件补 0，无法区分“真实 0”与“未知” → `BucketState`（`complete/in-progress/future/unknown/unavailable`）与 `BucketContext.coverageEnd`。
- 桶枚举与裁剪：原按月补全依赖字符串比较且不裁剪 → `enumerateBuckets` 生成自然对齐、裁剪到区间的桶。

**仍缺、需后续阶段解决**

- 周粒度进入统计 API 与离线镜像（B-1）；`dataVersion` 生产方（Q-BA-4）；离线覆盖元数据（R-B-02）；写后统计失效策略（R-B-04）。
