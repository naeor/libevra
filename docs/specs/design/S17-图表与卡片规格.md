## 1. 范围

本文规定 B（图表适配与渲染）、C（卡片系统）、D（分析详情页）三层。**不规定**：财务计算（A 层，能力目录）、网格与容器（E 层）、配置存储（F 层）。

三条贯穿约束：

1. **图表只画结果，不重新计算权威金额**（总需求规格 §4）。展示层的派生（排序、折叠“其它”、像素取整）必须是纯展示派生，不改变金额文本；
2. **金额文本是整数字符串，比例才是 number**（ACC-05）。几何（弧长、柱高）用 0–10000 的有界比例；金额标签用字符串格式化，绝不经 `Number()` 往返；
3. **同一分析结果在不同尺寸下数值一致**。尺寸只改变“显示什么”，不改变“结果是什么”。

## 2. 三轴分离：图表家族 × 分析结果 × 卡片尺寸

所有者举例的“环形图 1×1 / 1×2 / 2×2、柱状图 1×1 / 1×2 / 2×2”是**设计方向示例，不是最终尺寸清单**（总需求规格 §6）。做法：每个图表家族**只写一次绘制逻辑**，通过“密度档位”适配容器，而不是为每个尺寸复制一份绘图代码。

### 2.1 图表家族（CF）

| ID | 名称 | 表达什么 | 现有基础 | 备注 |
|---|---|---|---|---|
| CF-01 | 数值卡 | 单个金额 / 比率，可带变化 | `SummaryPanel`、`FxStats` 摘要 | 所有卡片家族中兼容性最广 |
| CF-02 | 环形占比 | 一组非负、分母可靠的构成 | `CategoryDonut` | 严格条件，见 §3.2 |
| CF-03 | 排行条 | 排序后的分项金额 / 占比 | 综合分类列表、环形图例 | 环形不适用时的首选替代 |
| CF-04 | 柱状 | 时间桶或有序桶的量，**可含负值** | 年度总览柱 | 净收支必须带零基线 |
| CF-05 | 折线 / 面积 | 连续时间趋势；累计曲线是其变体 | `TrendChart` | 面积只用于非负量；净收支用折线 |
| CF-06 | 日历热力 | 每日强度 | `CalendarHeatmap` | 颜色之外必须有数值读出 |
| CF-07 | 分布 | 星期 / 月内日 / 分位等有序桶 | 无 | 基于 CF-04 的有序桶变体，可共享实现 |
| CF-08 | 对比 | 本期 vs 比较期；分项贡献 | `SummaryPanel` 比较行 | 发散条 / 哑铃；零基数写“新增” |
| CF-09 | 堆叠 / 小倍数 | 多序列随时间变化 | 无 | 序列数有上限，超出折叠“其它” |
| CF-10 | 表格 / 清单 | 精确数值与来源入口 | `LedgerEntryRow`、综合列表 | **可访问性兜底形态**：任何图表都应能退化为它 |
| CF-11 | 依据条 | 数据来源、完整性、待复核 | `FxDisplay` | 元信息卡，不画金额图 |

| RS-4 | 排行 | 分项有序列表，可带变化值 |
| RS-5 | 有序分布 | 有序桶（星期 / 日 / 分位）的值与样本数 |
| RS-6 | 日期格 | 每日值 + 强度分级依据 |
| RS-7 | 表格 | 列定义 + 行（含来源筛选） |

### 3.2 条件与硬规则

| 规则 | 内容 |
|---|---|
| **环形占比（CF-02）** | 仅当：分项**全部非负**、分母**完整**（`complete && sourceComplete` 且 `shareDenominatorMinor ≠ null`）、至少 2 个分项、分项数 ≤ 上限（候选 8，其余折入“其它”）。任一条件不满足，卡片**不渲染环形**，自动退化为排行条（CF-03）并说明原因 |
| **净收支** | 含负值，只允许柱状（零基线）或折线；**禁止面积**（面积暗示累积量）与环形 |
| **负值** | 既有金额非负、方向由 `kind` 表达；若收到异常负的原件，该分析标为“此数据不能用于该图”，**不取绝对值造图**（审查 §5.1） |
| **标签构成（D-09）** | 一笔多标签，各标签之和 ≠ 总额，**只允许排行条 / 表格**，不允许环形 / 堆叠 |
| **币种** | 不同币种原额**不得同轴同尺**：原币图按币种分面；跨币种的单一量尺必须是折算后同一目标币种，并在卡片标题处写明目标币种与汇率口径 |
| **缺项** | 部分缺汇率 / 缺原件时，可显示“已知部分的小计”，但**占比类图表一律不画**；柱 / 线图可画已知部分，但卡片标记“不含 N 笔缺汇率”并链接缺项入口（ACC-07） |
| **单分类** | 构成只有一项时，环形无意义，退化为数值卡 + 分类名 |
| **不兼容的用户选择** | 图表选择器中把不兼容家族置灰并给原因；配置迁移或导入遇到不兼容组合时，自动降级到该形状允许的首个家族（CF-10 为终点），**不白屏** |

## 4. 卡片系统（C 层）

### 4.1 卡片实例

用户工作台里放置的是**卡片实例**（见能力目录 §1）。实例由以下部分组成（概念，非存储格式；存储与版本见[配置与分享](../product/S17-工作台个人配置与布局分享-方案草案.md)）：

| 部分 | 内容 | 是否可分享 |
|---|---|---|
| `instanceId` | 实例稳定标识，用于详情页深链、返回恢复；**同时是布局里的稳定唯一对象 ID**（[布局规格 §13.2](S17-工作台布局与格式模板规格.md)），创建后不变、不复用 | 导入时重新生成 |
| `analysisRef` | 目录 ID（如 AN-B05）+ 其参数（指标 / 维度 / 比较 / 过滤） | ✔ 不含账务数据 |
| `chartFamily` | CF-xx | ✔ |
| `rangePolicy` | `inherit`（跟随工作台）/ `pinned`（卡片自带区间） | ✔ |
| `title` + `titleKind` | `titleKind = preset`：保存预置翻译键，显示时按**当前界面语言**翻译；`titleKind = custom`：保存用户输入文本，原样显示、不翻译。自定义标题可能含私人信息，默认不导出、不进日志、不进分享快照（配置与分享 §6.2，Q-14）。导入时预置标题按接收者语言显示；自定义标题保留原文并可附语言提示（G-07） | 预置键 ✔；自定义文本默认 ✘ |
| `sizeIntent` | 用户保存的期望占位：锚点编号 + `baseCols` + `宽×高`（[布局规格 §12](S17-工作台布局与格式模板规格.md)）；**只存意图，投影后的降级尺寸不写回** | ✔ |

实例**不保存**：金额、账本 ID、交易 ID、分类 / 支付方式的**真实 ID**（导入时按名称重新映射，缺失则由用户重选，见配置与分享 §6.5）。

### 4.2 卡片结构

一个标准卡片由下列区域组成，区域的有无由密度档位决定（§5.2）：

1. 标题（含指标 / 范围的简短说明）；
2. 主体（图表或数值）；
3. 单位与币种说明（原币 / 目标币种）；
4. 完整性标识（若 `complete / sourceComplete / needsReview` 任一不满足）；
5. 辅助说明（可展开）；
6. 操作：进入详情（整卡可点或明确入口）；编辑模式下的卡片菜单。

### 4.3 状态

四种“没有数据”必须区分（ACC-06）；还有两个加载态：

| 状态 | 含义 | 展示 | 不得 |
|---|---|---|---|
| `loading` | 首次加载 | 骨架占位（保留最终高度，避免布局跳动） | 显示 0 |
| `refreshing` | 已有结果在后台刷新 | 保留旧结果 + 轻提示 | 清空后重画 |
| `empty-no-transactions` | 区间内确实没有交易 | “这段时间没有记录”，附“记一笔”入口（有写权限时） | 画一个全 0 的图表 |
| `partial-missing-rate` | 部分交易缺汇率 | 已知部分 + “N 笔缺汇率”入口；占比类图表退化 | 补零或估算 |
| `partial-missing-source` | 本机未覆盖该时段 / 原件不全 | “本机时段不完整”+ 去下载 / 联网入口（ACC-13） | 称“全年总额” |
| `needs-review` | 汇率或来源待复核（独立于上两者） | 显示依据条提示 | 与 `complete` 混用 |
| `load-failed` | 请求失败 | 区分 HTTP 错误与网络不可达（审查 F15）；重试入口 | 静默显示空 |
| `incompatible` | 配置的家族与结果形状不兼容 | 降级到允许家族并说明 | 白屏 |

### 4.4 筛选继承

- 工作台持有一组**全局筛选**（时间范围、原币 / 综合模式、币种）；卡片默认 `inherit`；
- 卡片可 `pinned` 到自己的时间范围；**被固定的卡片必须在标题处可见地标明自己的区间**，避免同屏出现“看似同一时期、实则不同”的数字；
- 卡片级覆盖“原币 / 综合”模式：**首版不允许【已确认 2026-10-27，Q-11】**。原因：`libevra.fx-mode:<userId>` 是设备本地偏好（S16-E 矩阵），按卡片覆盖会同屏混合两套完整性规则。卡片只能固定自己的**时间范围**（上一条）。
- 综合折算是否成为分析页默认：**保持默认关闭【已确认 2026-10-27，Q-18】**。多币种模板可以**引导**用户开启，但不得自动修改用户偏好。

### 4.5 异步与过期结果

沿用 S16-D §5、§7 的做法，并扩展到多卡片：

- 每次请求携带 **scope（用户 / 账本 / 模式 / 币种）+ 筛选指纹 + 请求代次**；响应到达时核对，不一致即丢弃（ACC-14）；
- **同一分析定义去重**：同屏多张卡片使用同一 `AnalysisDefinition` 时只发一次请求、共享同一结果与**数据版本戳**（总需求规格 §4.2 第 3 点）；
- 账号 / 账本切换时取消在途请求并清空卡片结果缓存，卡片先显示 `loading`，不得短暂显示上一账本的数字。

## 5. 容器自适应（卡片按真实宽高）

### 5.1 原则

所有者要求：卡片依据**父容器提供的实际可用宽度与高度**，而不是手机型号、屏幕宽度、网格列数或固定 1×1 / 2×2（总需求规格 §6）。原因：自由分割容器会产生不规则空间。

【推荐】实现方式：每个卡片用 `ResizeObserver` 观察**自己内容盒**的宽高（项目已有 `useElementWidth`，需扩展为同时观察高度），并映射到密度档位；**不使用媒体查询或视口宽度**决定卡片内部布局。CSS Container Queries 可作辅助（样式层），但档位语义以脚本层统一为准，以便图表内部（SVG 比例、标签策略）可读取同一档位。

### 5.2 密度档位（候选，【待研究】）

以下阈值为**起点候选**，须在原型与真机上冻结，单位为 CSS 像素（不是物理像素）。

| 档位 | 宽度候选 | 高度候选 | 典型内容 |
|---|---|---|---|
| XS | < 120 | < 96 | 单个关键数 + 极短标题 |
| S | 120–199 | 96–159 | 关键数 + 变化提示，或迷你图（无坐标轴） |
| M | 200–319 | 160–239 | 标准图表（精简坐标轴、关键标注） |
| L | 320–479 | 240–359 | 完整图表 + 图例 + 说明 |
| XL | ≥ 480 | ≥ 360 | 宽松版：更多标注、并排对比、迷你表格 |

宽度与高度**分别**定档（宽而矮、窄而高都会出现），组合规则由家族自己声明。

举例以说明为何不能按列数判断（算术示例，非承诺）：页边距 16、间距 12 时，320px 宽视口 2 列的卡片宽约 138；375px 约 165；390px 约 173；430px 约 193。3 列在 430px 视口只有约 125，已低于大部分图表的可读下限。自由分割后，同一屏上还可能出现更窄的单格。

### 5.3 各家族的密度行为（【推荐】）

| 家族 | XS | S | M | L / XL |
|---|---|---|---|---|
| CF-01 数值卡 | 主值 | 主值 + 变化 | + 比较期说明 | + 迷你趋势 / 完整性行 |
| CF-02 环形 | 不显示环，退化为数值卡（最大分项名 + 占比） | 环 + 中心值，无图例 | 环 + 前 3 项图例 | 环 + 全图例（带金额与占比），可选中 |
| CF-03 排行条 | 前 1–2 项 | 前 3 项，无金额列 | 前 5 项，含金额 | 前 8 项 + “其它”可展开 |
| CF-04 柱状 | 不显示 | 迷你柱，无轴 | 精简轴 + 极值标注 | 完整轴 + 选中读数 |
| CF-05 折线 / 面积 | 不显示 | 迷你线，无轴 | 精简轴 + 末值标注 | 完整轴 + 点选读数 + 比较线 |
| CF-06 日历热力 | 不显示 | 7 日条 | 当月格，无星期头 | 当月格 + 图例 + 读数 |
| CF-10 表格 | 不显示 | 前 2 行 | 前 5 行 | 更多行 + 来源列 |

“不显示”表示该尺寸下该家族不可放置（卡片声明 `minSize`，布局层据此限制缩放与放置，见布局规格 §5）。**不是所有图表都必须支持每一种尺寸**（总需求规格 §6）。

### 5.4 禁止的适配手法

- **整体缩放 SVG 与文字**（`transform: scale` 或 `viewBox` 拉伸令文字变小）：文字必须按真实 CSS 像素渲染，保持最小可读字号（候选 ≥ 11px 辅助文字，≥ 14px 主要金额）；
- **截断重要金额**：金额不得用省略号截断；放不下时改用紧凑记法并在详情 / 工具提示 / 无障碍文本中提供完整精确值（见 §5.5）；
- **用动画掩盖布局错误**；
- **不同尺寸下用不同的数据**（含“尺寸小就取前 N 项而不声明”：折叠必须显示“其它 N 项”并可展开）。

### 5.5 内容鲁棒性（大金额与长文本）

| 情形 | 规则 |
|---|---|
| 大金额（含 > 2^53 的整数字符串） | 金额以字符串格式化；使用基于字符串的紧凑记法（如“1.2亿 / 120M”）时，**紧凑形只是显示**，完整精确值始终在详情页、点选读数和无障碍文本里 |
| 币种符号与小数 | 小数位由币种决定（JPY 0 位 / 多数 2 位）；货币符号位置随区域，沿用既有格式化工具 |
| 长英文分类名 / 自建名 | 按词断行 → 省略号只用于**非金额**标题，且完整名可在点选 / 详情中读到；不撑破网格 |
| 中英文切换 | 预置分类译名随语言，自建名保留（审查 §3）；英文通常更长，卡片以英文长度验收 |
| 负数 | 统一负号与颜色之外的非颜色标识（如“−”与文字“支出较多”），不依赖红色 |
| 极端比例 | 小于 1% 的切片合并规则（F18）；0 值不画；比例四舍五入后总和 ≠ 100% 的处理要写明（最大余数法或不显示整数合计） |

### 5.6 卡片对布局层声明的约束【接口已确认；数值待研究】

布局层只读取、不自己决定“多小还算可读”（[布局规格 §15.1](S17-工作台布局与格式模板规格.md)）。每个卡片（按分析目录项 × 图表家族）**声明**：

| 声明 | 含义 | 状态 |
|---|---|---|
| `minSize` | 能显示出“可读、可操作”内容的最小 `宽×高`（单位：格，同时给出对应的最小 CSS 尺寸，§5.2 密度档位） | 数值【待研究】，W3 随首批卡片提出，原型 / 真机冻结（OQ-LM-02） |
| `sizeLadder` | 按偏好顺序排列的若干降级尺寸，如 `3×1 → 2×1 → 1×1`（可混合，例如 `3×1 → 2×2`）。**由家族自己声明**，布局层只执行 | 【推荐】；具体顺序【待研究】 |
| `compat` | 在任何降级档下都放不下时的**兼容入口**：`1×1`，显示卡片名称与“在详情页中查看”，点击进入该卡片的详情页（§8）；不删除卡片、不改配置；空间恢复后自动回到完整形态 | 行为【已确认】（不丢卡片、不丢数据）；样式【待研究 OQ-LM-11】 |
| 类型约束 | 允许的最大宽度、是否允许纵向拉伸、长宽比范围 | 【待研究】 |

规则：

1. **只存意图**：用户保存的是 `sizeIntent`；`compact` / `compat` 是投影派生，**不写回**（布局规格 §14.8）；
2. **降级不得违反数据规则**：卡片缩小只改变呈现密度（§5.2–§5.3），不改变数字、口径、完整性标识（ACC-01…15）；信息在小尺寸下不足时**隐藏次要信息**，而不是缩小字体到不可读或改用别的口径（§5.4 禁止项）；
3. **兼容入口也受 ACC 约束**：入口显示名称与完整性标识（若有），**不显示可能误导的缩略数字**；
4. 布局层从不读取卡片内的交易、金额或分类，也不按金额或交易数决定优先级（布局规格 §13.3）；
5. 容器里的卡片同样声明约束；容器对外只暴露自己的约束（布局规格 §8.4、§17），容器内部槽位的最小尺寸由容器负责。

## 6. 图表家族要点（B 层）

| 家族 | 关键要求 |
|---|---|
| 通用 | 手写 SVG 保持；颜色来自主题令牌（收入 / 支出色与品牌色分离；八分类色、五热力色，见 `lib/chart/theme.ts`）；七主题 + 深浅色均需验收；每个图表必须能提供 **CF-10 形态的数据表**作为无障碍替代 |
| CF-02 环形 | 弧长用 0–10000 比例；小切片最小弧度（候选 ≥ 2°）；点击切片 = 选中（F05），**选中后再明确进入来源**，不是点一下就跳走 |
| CF-04 柱状 | 带零基线；负柱向下；柱宽有最小值，超出则聚合桶（显示派生，声明聚合） |
| CF-05 折线 / 面积 | 点数上限由显示宽度决定，超出做**显示降采样**（保留极值），降采样不得改变选中读数的真实值；读数来自原桶 |
| CF-06 日历热力 | 分位着色依据写明；颜色之外有数值读出；跨月 / 跨年边界 |
| CF-08 对比 | 前期为 0 的写法统一；两个区间的起止日期明示 |
| CF-09 堆叠 / 小倍数 | 序列数上限；小倍数共享或独立 Y 轴要明示（独立轴会让小值看起来和大值一样大） |
| 图表库 | **继续使用 React + SVG 图表实现，不换库**【已确认 2026-10-27，Q-19】（总需求规格 §12）。若 S17 后期出现多轴 / 大跨度 brush 需求，另做独立 spike（包体、手机内存、主题、无障碍）。**布局编辑器**可以做独立 spike：自研 vs 现成库，比较与现有设计的契合度、手机 Safari 表现、拖动性能、包体积、键盘 / 无障碍、许可证、维护风险（W5 前，布局规格 §5.4）；只有确有必要才引入新依赖 |

## 7. 交互与可访问性

### 7.1 选择与高亮：一次选择，再明确进入来源

沿用审查 §8.1：点击图表元素（切片、柱、点、热力格）= **选中并显示读数 / 高亮对应图例**；只有点击明确的“查看明细 / 来源”入口才进入来源列表。理由：避免用户误触就离开当前视图，也使触摸与键盘行为一致。

### 7.2 下钻合同

来源列表必须与图表**使用同一 `from/to`、同一分类 / 币种 / 模式筛选**（ACC-09）。审查 F01（90 天下钻落入结束月份）在 S17-W1 必须修复，并作为验收用例：点“餐饮”看到的明细合计 == 图表中“餐饮”的数值。

### 7.3 来源追溯

- 数值旁的“数据依据”入口展开：区间、币种 / 目标币种、汇率口径与来源日期、缺项笔数；
- 综合模式缺汇率 / 缺原件的账目有直达列表；
- “最大单笔”等需要 ID 的追溯依赖 T2 查询（能力目录 AN-A03），在其上线前，卡片只显示金额且不提供“点开看是哪一笔”的假入口。

### 7.4 触摸区域

【推荐】可点击元素的有效点击区 ≥ 44×44 CSS px（含不可见的扩展热区）；任何情况下不低于 WCAG 2.2 AA 的 24×24 CSS px 目标尺寸底线。小于此的切片 / 数据点通过**图例或列表**提供等价入口，而不是缩小目标。

### 7.5 键盘

- 每个可交互图表是**一个**可聚焦单元，内部用方向键在元素间移动（roving tabindex），Enter 选中，再 Enter / 专用键进入来源；
- 详情入口、卡片菜单、编辑模式操作都有键盘路径（布局规格 §6 的拖动 / 缩放键盘替代）；
- 焦点可见，不被卡片 `overflow` 裁剪。

### 7.6 读屏与减少动态

- 每个图表配 `role="img"` + 简短总结标签，并提供可跳转的数据表（CF-10 形态）作为完整读法；颜色不是唯一的信息通道（形状、标签、图案）；
- 动画尊重 `prefers-reduced-motion`：关闭位移 / 缩放类动画，保留必要的状态变化（淡入淡出可缩短到近乎即时）；
- 选中读数使用 `aria-live="polite"`，避免拖动时连续播报。

### 7.7 手势冲突

同一区域可能同时存在：页面纵向滚动、图表内拖动读数、抽屉容器横向滑动、编辑模式拖动卡片。

**【已确认 2026-10-27，Q-13】原则**：

1. 普通模式与编辑模式严格分离；
2. 普通模式下点击卡片进入详情页；
3. 编辑模式下拖动、缩放**不会触发**进入详情页；
4. 抽屉容器**不得抢占页面纵向滚动**（横向手势只在明确的横向意图下由抽屉接管）；
5. 图表内的交互（读数、选中）不得与上述手势冲突。

**【推荐，待真机验证】具体做法**：图表内“按住后拖动读数”需要先长按 / 明确激活；抽屉用边缘滑动 / 页点；编辑模式用明确的拖动把手与缩放把手。Safari pointer capture 行为尚未验证（审查 §14）；这些交互在真机测试通过前不冻结（路线图 **S18-B** 设备矩阵，[§4.3](../product/S17-S18-新路线图.md)）。

## 8. 分析详情页（D 层）

### 8.1 定位

每张卡片点击进入**该卡片实例**的详情页，继承该实例的分析定义、筛选与图表家族，而不是打开一个通用结果页（总需求规格 §6）。

**卡片详情不同于容器详情**：容器（自由分割 / 抽屉）收缩成 `1×1` 后的“完整查看”只是换个地方显示同一批卡片（布局规格 §17.7–§17.8），没有“来源追溯”和“历史比较”；卡片详情是对某项分析的深入研究（本章）。两者路由和返回状态相互独立，不要共用页面语义。

### 8.2 内容（【推荐】结构）

1. 顶部：分析名称、范围、币种 / 模式、完整性标识；
2. 主图：该分析的完整版本（L / XL 档位，更精细的标注与选中）；
3. 比较：与上一可比期（或实例配置的比较）的并排；
4. 历史：更长时间跨度的同类走势（受数据覆盖限制，ACC-13）；
5. 文字说明：这个数字怎么算、分母是什么、哪些数据被排除（与能力目录登记的公式一致）；
6. 来源：进入来源账目列表，再进入单笔交易；
7. 依据：汇率口径与来源日期、缺项入口、待复核说明；
8. （专业分析）公式与样本数。

### 8.3 路由与状态

- 路由携带 `instanceId` 与来源上下文，**不携带金额**；实例配置从用户个人设置读取；实例不存在（已删除 / 来自其他设备尚未同步）时显示明确说明与返回入口，不白屏；
- 详情页内改变时间范围 / 币种 / 过滤，**只影响详情页本身，不写回卡片实例**【已确认 2026-10-27，Q-16】。如果将来提供“保存到该卡片”或“另存为新卡片”，必须是**显式**操作（带确认），不得自动写回；是否提供该入口【待研究】，不阻塞首版。

### 8.4 返回与状态恢复

返回工作台恢复：滚动位置、当前抽屉页、当前选中元素、全局筛选；**不恢复编辑模式**（始终回到普通模式，避免在拖动半途恢复）。审查 F03 的 P0 修复是 URL 状态化，S17 沿用并扩展到多卡片。

### 8.5 离线与权限

详情页读取走既有账本 read guard（ACC-12）；离线时只展示本机覆盖范围，并声明覆盖范围。共享账本只读成员能进入详情页并查看来源，不出现任何写入口。

## 9. 性能

【待研究】目标与预算，需在 S17-W2 前以真实数据基准测量，不在此处冻结：

| 项 | 候选做法 |
|---|---|
| 大量卡片 | 视口外卡片不挂载图表（占位保留尺寸）；挂载有并发上限；同一分析去重 |
| 大量账目 | 先聚合再画（五万笔不画五万个点）；综合路径沿用 14 个月 / 100,000 笔上限与让出主线程；超限给明确提示而非静默截断 |
| 渲染 | SVG 节点数预算（每卡片候选 ≤ 数百）；重计算放 `requestIdleCallback` / 分片；评估 Worker（仅当基准证明必要） |
| 重排 | 编辑模式拖动期间只更新位置，不触发数据重算 |
| 缓存 | 结果缓存键 = scope + 筛选指纹 + 数据版本；账号 / 账本切换即失效 |

## 10. 动画与视觉

- 风格：Libevra 设计语言——简洁、克制、品牌绿 `#55997a`、合理留白、七主题与深浅色；**正常分析页不出现编辑器控件**；
- 动画：柔和、连续（形状 / 布局变化用连续过渡，不用硬切），时长与缓动在原型阶段统一定义（项目若已有动效令牌则沿用，S17-W2 核对）；尊重 `prefers-reduced-motion`；
- **归属边界（2026-10-27）**：全应用统一动画体系（时长分级、缓动 / spring 原则、绿色顶栏收缩、页面 / 抽屉 / 弹层转场）归 **S18-A**（[新路线图 §4.2](../product/S17-S18-新路线图.md)）；本文只定义工作台内**必要的卡片动效**与可访问性要求，不在此冻结全局动效参数；
- 不过度装饰：不用渐变霓虹、3D、阴影堆叠。
