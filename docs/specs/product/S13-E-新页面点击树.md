### 2.3 设置（`/settings`，账号级；1.13.05 重构为首页 + 子页）

```

│   └─ 下方独立快捷控件「默认币种」：当前币种 + 6 个胶囊（人民币/美元/欧元/日元/港币/英镑）

├─ 显示与数据卡片 → /settings/appearance
├─ 账号安全卡片 → /settings/security
├─ 系统管理卡片（仅管理员渲染，普通账号无占位）→ /admin
└─ 关于 Libevra 卡片 → /about（无子页）
```

```
/settings/preferences 记账偏好
├─ 返回 → /settings（历史优先）
├─ 默认币种（同一 useDefaultCurrency；胶囊选择，保存后即时同步）
├─ 大键盘输入金额 / 沿用上一笔 / 登录后直接开始记账 / 币种显示顺序 / 主界面按钮位置（后续开放）

├─ 返回 → /settings
└─ 语言 / 主题色 / 汇率折算（后续开放；导出/导入不在此处）

/settings/security 账号安全
├─ 返回 → /settings
├─ 更改密码 → /settings/password
├─ 生成新的恢复码 → /settings/recovery-code
└─ 邀请码 → /settings/referral-codes
```

**移出：** 导出数据、导入历史账 —— 已迁到「账本设置 → 数据管理」。
**旧地址 `/export`、`/import` 保留**，继续对「当前账本」快捷导出/导入（兼容明细页快捷入口）。
**旧设置子路由** `/settings/password`、`/settings/recovery-code`、`/settings/referral-codes` 全部保留。

### 2.4 账本／协作一级页（`/ledger`）

```
账本 / 协作（TabPage）
├─ 绿色标题区
│   ├─ 标题：账本（单人）/ 协作（多人）
│   ├─ 副标题
│   └─ 右上角动作行（两个同尺寸圆形按钮）
│       ├─ 铃铛：通知面板（有未读红点；点开标记已读）
│       └─ 齿轮：账本设置 → /books/<当前账本 id>/settings
│           └─ 无当前账本时 → /start
├─ 当前账本卡片（一个卡片、两个大点击区）
│   ├─ 左区：当前账本名 / 编号 / 「查看详情 ›」→ /books/<当前账本 id>
│   └─ 右区：整块可点 → /start
│       └─ 较大的切换图标（上）+「切换账本」（下），水平/垂直居中；arrow 不作为主体
├─ 多人时右侧成员卡片 → /ledger/members
├─ 编辑记录（最近几条）→ /ledger/history
├─ 留言板（多人）→ /ledger/messages
├─ 邀请成员（单人/多人按现有逻辑）→ /ledger/invite
├─ 账本信息摘要 → 「详情」→ /books/<当前账本 id>
├─ 退出这本账（非创建者；确认）
└─ 底部导航
```

**两个点击区的最小尺寸**：左区与右区都 ≥ 44×44 CSS px；右区图标明显大于文字，整体居中；
窄卡（共享态半宽 / 手机）自动上下堆叠，**两种布局都保留「切换账本」完整文字，
且不是「小图标 + 右侧文字」的横向链接**。

### 2.7 切换账本面板（`BookSwitcherSheet`，详情/设置共用）

```
遮罩（点击关闭）/ 底部面板（Role=dialog, aria-modal, Esc、下滑、关闭按钮、body 滚动锁定）
├─ 面板高度：h-[clamp(18rem,52dvh,34rem)]（手机约 45–55% 视口；短屏 288px 下限；高屏 34rem 封顶）
├─ 拖拽手柄 / 标题「选择账本」/ 关闭 ×：固定在顶部，不随列表滚动
├─ 灰色说明：固定
│   - 查看用途："此处只切换正在查看的账本，不会更改当前记账账本。"
│   - 管理用途："此处只切换正在管理的账本，不会更改当前记账账本。"
└─ 列表区（min-h-0 flex-1 overflow-y-auto）：只有这里滚动
    ├─ 名称 / 编号 / 成员数
    ├─ 选中当前目标：✓ + 中性「当前记账账本」标签（如适用）
    └─ 点一行 → 只替换 URL 里的 bookId（navigate replace）
        - 选中当前目标 → 直接关闭，不发请求
        - 加载/错误/空列表有明确状态
```

**高度与安全区域**：面板底部保留 `env(safe-area-inset-bottom)`；账本少时保留自然留白（不再缩成
一条矮条）；账本多时列表在面板内部滚动，标题与关闭按钮不动。

**它不做的事**：不调用 `useActivateBook`/`useLedger`，不写 `currentBook`，不动离线作用域。

```
│           └─ 取消 / 永久删除（busy）
├─ 已归档列表（同样可永久删除）
└─ 归档确认弹窗（原有，保留）

支付方式（/books/:bookId/settings/payment-methods）
├─ 同结构；永久删除替换下拉为「改为未指定」或另一支付方式
└─ 影响计数来自 paymentMethods 映射

标签（/books/:bookId/settings/tags）
├─ 返回 → /books/:bookId/settings
├─ 新增标签（名称 + 颜色）
├─ 标签列表（每行：标签名 / 颜色 / 删除）
└─ 删除确认弹窗
    ├─ 描述：有 N 笔记账正在使用，删除后解除关联
    ├─ 后果 + 共享账本提醒
    └─ 取消 / 确认删除
```

> **UI 只决定"是否显示入口"**；服务端仍以 `book_members` 判定权限，viewer 写请求会被 403。
> 目标账本模式所有读写都带 URL 的 `bookId`，**不调用 `useLedger`**。

### 2.10 目标账本导出 / 导入

```
导出数据（/books/:bookId/settings/export）
├─ 返回 → /books/:bookId/settings
├─ 显示目标账本名称 + 编号
├─ 时间范围、文件格式、筛选（现有表单）
├─ 导出（fetchExport(filters, bookId)）
└─ 导出记录（useExportLog(bookId)）

导入历史账（/books/:bookId/settings/import）
├─ 返回 → /books/:bookId/settings
├─ 横幅：导入到「名称（编号）」
├─ 上传文件、预览、确认
├─ 确认框再次点名目标账本
└─ useImportEntries(bookId)
```

**当前账本模式**（`/export`、`/import`）行为不变：仍然对设备当前账本导出/导入。
