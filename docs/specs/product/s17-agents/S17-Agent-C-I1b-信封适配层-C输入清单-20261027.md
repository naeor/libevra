## 1. 适配层职责与禁止事项

- 输入：**C draft 结果** + **解析上下文**（A 的 `AnalysisDefinition` 解析物：analysisId/analysisType/metric/resolvedPeriod/resolvedFilters/resolvedCurrency/dataVersion/source 参数）。
- 输出：`AnalysisResultBase & { shape: "<c-shape>" } & <C 字段清单>`（拼装形态见 C《r4 形状映射》§0/§1；字段以 C `draftTypes.ts` 逐字为准，不重命名）。
- **禁止**：重算金额/占比/分位/归因/守恒；把 C 的 `ok:false` 图表输入门控（旭日/Treemap/桑基/`CrossCubeAdapterResult`）当成结果完整性；把 `sankey` 包装成结果形状（纯投影）；给 `calendar` 另立结果形状（只冻结 B 的 `calendar-heatmap`，C 为投影）；在适配层改 C 常量的冻结值。

## 3. 完整性/原因映射（I-1b 唯一映射表）

|---|---|---|
| `DraftCompleteness.complete`（有数据） | `complete` | — |

## 6. 建议验收（I-1b 测试清单，供 D+C）

1. 14 形状 golden fixtures：C draft → 适配 → 通过 A 的 `AnalysisResultBase` 类型守卫/JSON schema；字段逐字一致（无重命名、无丢字段）。
2. 9 态映射表逐行断言（§3），含 `partial→fx-incomplete` 限定与空集→`no-transactions`。
3. `Ratio` 进程内 bigint、HTTP `{numerator,denominator}` 字符串往返；金额 `bigint` 不被转 number。
4. 缺省≠0：`null` 保留 + 原因字段存在；适配层不补 0、不重算（可用 spy 断言 C 纯函数仅调用一次）。
5. 拒绝路径：`fxProjection` 三种拒绝与趋势拒绝 → 不泄漏 `ok:false` 到结果；`invalid_input` → 显式 adapter error。
6. 门控不下沉：旭日/Treemap/桑基/cross-cube 的 `ok:false` 不出现在结果 union（保持在图表输入层）。
7. 常量零改名：适配层不得引入 `-v1` 或未登记 method/枚举值（grep 断言）。
8. 适配层单提交可回滚；不触碰 C/B/A 纯函数与冻结协议文件。
