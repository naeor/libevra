## 2. 快速接入（三步）

```tsx
// 1) 把业务闭区间转成分析半开区间（B 的统一入口；400 天上限）
const span = analysisSpan({ from: "2026-09-28", to: "2026-10-27" }); // → { start: "2026-09-28", end: "2026-10-28" }

// 2) 取数据（原币、同步计算、账本变化自动重渲染）
const view = useMovingAverage({
  span,
  today,                        // 设备日历日 "YYYY-MM-DD"，与 rangeForPreset 同一约定
  windowDays: 7,                // A13=7；A14=30
  coverage: "local-ledger",     // 本地账本覆盖；覆盖未知时传 "unknown"
});

// 3) 渲染卡片（所有字符串由调用方 i18n/格式化；卡片不做计算）
<MovingAverageCard
  windowDays={7}
  title={t("stats.movingAverage.title7")}
  result={view.unavailableReason === null ? view.result : null}
  labels={{ raw: t("stats.movingAverage.raw"), average: t("stats.movingAverage.average7") }}
  metrics={[{ label: t("stats.movingAverage.latest"), value: latestAverageText }]}
  formatValue={(point) => pointText(point)}
  formatAxis={(value) => formatAxisAmount(value, currency)}
  caption={t("stats.movingAverage.caption7")}
  sampleText={sampleText}
  excludedInProgress={view.todayExcluded}
  excludedTodayText={view.todayExcluded ? t("stats.movingAverage.excludedToday") : null}
  emptyText={t("stats.movingAverage.empty")}
/>
```

`result === null` 时卡片**不显示图表与 metrics**，只显示 `emptyText`；`sampleText` 在有结果时必须传入且保持可见（B-Q20 验收要求：样本口径不能被隐藏）。

## 4. 适配层 `deriveMovingAverage`

文件：`apps/web/src/lib/analysisData.ts`

```ts
export const MOVING_AVERAGE_WINDOWS = [7, 30] as const;

export interface MovingAverageAnalysisQuery {
  readonly span: TimeSpan;        // 可见半开区间 [start, end)
  readonly today: string;         // 设备日历日 "YYYY-MM-DD"
  readonly windowDays: number;    // 7 / 30，正整数
  readonly maxDays?: number;      // 默认 400（MAX_ANALYSIS_DAYS）
  readonly coverage?: AnalysisCoverage; // "local-ledger" | "unknown"
  readonly scale?: number;        // 仅展示用定点展开，shared 默认 4
}

export interface MovingAverageAnalysisView {
  readonly result: MovingAverageResult;   // 只含可见区间的点与计数
  readonly points: readonly MovingAveragePoint[]; // 图表实际绘制的点
  readonly historyDays: number;           // = windowDays - 1（向历史补读的真实天数）
  readonly visibleFrom: string;           // 可见区间第一天（轴起点）
  readonly unavailableReason: "no-complete-observations" | null;
  readonly excludedInProgressDays: number; // 被排除的未完成日数（通常 0 或 1）
  readonly todayExcluded: boolean;         // 是否发生过排除（B-Q20）
  readonly input: AnalysisInput;           // 输入溯源：entries / coverageEnd / dataVersion
}
```

### 适配层不变式（冻结）

1. `query.span` 是**半开区间** `[start, end)`；闭区间入口用 `analysisSpan({from,to})` 转换。
2. 读取区间 = `[span.start - (windowDays-1), span.end)`：向历史补真实数据，使可见区间首点就有完整窗口；`historyDays = windowDays - 1`。
3. `coverage` 在**补读后的读取区间**上判定：`coverage: "unknown"` ⇒ 补读历史也为未知 ⇒ 所有点不可算（`gapReason` 全为 `window-incomplete`），`unavailableReason = "no-complete-observations"`。
4. 未知 ≠ 0：窗口含未知/未来日 ⇒ 该点 `average: null`、`gapReason: "window-incomplete"`；不补零、不插值。
5. B-Q20：`in-progress` 日（通常今天）**不进入任何窗口样本**，以 null 喂给 shared（不是 0）⇒ 只有包含该日的窗口变 `window-incomplete`；其余窗口的 `numeratorMinor/denominatorDays` 不受影响。
6. 可见化后的计数只统计可见点：`observedDays` / `computablePoints` / `unknownWindowPoints` / `missingHistoryPoints` / `complete` 均按 `query.span` 重算，历史补读不计数。
7. `unavailableReason` 仅在 `observedDays === 0` 时非 null（没有可画的真实数据）。
8. `windowDays` 非正整数或区间超过 `maxDays` 时抛 `AnalysisRangeError`（`analysis-range-invalid` / `analysis-range-too-long`），不静默截断。

## 5. Hook `useMovingAverage` 的数据来源与查询键

文件：`apps/web/src/lib/useTimeAnalysis.ts`

- 数据来源（与 `useStats` 同一套已验证读取路径）：
  - `useSyncExternalStore(subscribeLedger, ledgerSnapshotValue, ledgerSnapshotValue)` 订阅账本快照；
  - 挂载时 `void readLocalTransactions()` 触发本地读取（页面刷新后自动填充）。
- 计算发生在渲染期（纯、便宜、同步），账本任何变化（新增/编辑/删除）都会重渲染。
- `useMemo` 依赖键：`[all, span.start, span.end, today, windowDays, maxDays, coverage, scale]` —— 传入稳定原始值即可；`span` 对象本身不作为依赖（只看 start/end）。
- `today` 必须是**设备日历日**（与 `rangeForPreset` 同约定），不得用 UTC 日期。
- 本 hook **只走原币路径**：不折算、不读 FX 聚合；跨币种/综合模式是后续冻结批次。

## 7. 真实数据示例（来源：`apps/web/src/lib/s4b.analysisData.test.ts`，可直接对答案例）

### 示例 A：A13 7 天窗口 + 历史补读（首个可见点就有完整窗口）

输入：仅一笔支出 `2026-10-01`、`amountCents = 70_000`（700.00 元）；`span = { start: "2026-10-07", end: "2026-10-10" }`；`today = 2026-10-27`；`windowDays = 7`；`coverage = "local-ledger"`。

结果：

- `historyDays = 6`，`points` 键依次 `2026-10-07`、`2026-10-08`、`2026-10-09`；
- 首点 `average = { numeratorMinor: "70000", denominatorDays: 7 }`（即 100.00 元/天），`averageScaledMinor = "100000000"`；
- 第 2 点（10-08）：窗口 `10-02..10-08` 无交易但是**已确认的零**，`average = { numeratorMinor: "0", denominatorDays: 7 }`；
- `complete = true`，`unavailableReason = null`，`observedDays = 3`、`computablePoints = 3`、`missingHistoryPoints = 0`。

### 示例 B：A14 30 天窗口

输入：一笔 `2026-10-01`、`30_000` 分；`span = { start: "2026-10-30", end: "2026-11-01" }`；`today = 2026-11-02`；`windowDays = 30`。

结果：`historyDays = 29`；首点 `average = { numeratorMinor: "30000", denominatorDays: 30 }`（10.00 元/天），`averageScaledMinor = "10000000"`；`complete = true`。

### 示例 C：B-Q20 进行中的今天被排除（真实出现状态）

输入：支出 `2026-10-20` 10_000 分、`2026-10-27` 5_000 分；`span = { start: "2026-10-20", end: "2026-10-28" }`；`today = 2026-10-27`；`windowDays = 7`。

结果：

- `todayExcluded = true`，`excludedInProgressDays = 1`；
- 最后一个可见点键 `2026-10-27`、`state = "in-progress"`：`rawMinor = null`、`average = null`、`gapReason = "window-incomplete"`（今天的 5000 **不进样本**，不是 0）；
- `unknownWindowPoints = 1`、`computablePoints = 7`（8 个可见点里只有今天这个尾点不可算）、`complete = false`；
- 首点 10-20 的窗口 `10-14..10-20` 不受影响：`average = { numeratorMinor: "10000", denominatorDays: 7 }`。

> 展示提醒：`averageScaledMinor` 是 floor 定点；权威值是 `average` 分数。tooltip 建议同时显示原始日金额与平均（用分数/定点按 `scale` 展开），不要二次舍入成“看起来更整齐”的数。

## 8. 最小集成验收建议挂载点

1. **挂载位置**：工作台/统计页的“时间趋势”卡片区（与既有月度/支出趋势卡同一栅格）。先接 **A13（7 天）单卡**，验收通过后再把 **A14（30 天）** 作为并排卡或窗口切换。
2. **数据**：账本走现有 `useLedgerStore` 路径即可；验收可用真实 W1 夹具（30 天全窗口），或直接用 §7 三个用例做组件/适配层验收。
3. **验收检查清单**：
   - 卡片渲染无控制台错误；`data-window` = 7/30 正确；
   - `sampleText` 可见，写明天数/未知窗口/缺口/进行中；
   - 出现进行中今天时，`data-excluded-today="true"` + 排除文案可见；
   - 空账本：`result === null` ⇒ 只显示 `emptyText`，不出现 `<svg>`/metrics；
   - 覆盖未知：全部点不可算、`unavailableReason` 生效，不显示“0 元平均”；
   - 已知窗口：`average` 分数与 `rawMinor` 守恒（窗口内每日原始值之和 = numeratorMinor）；
   - 与既有 stats 数据对账：原始日金额与账本一致。
4. **不要做**：不要接 FX/综合模式（未冻结路径）；不要在 UI 里重算平均或补零；不要把 `averageScaledMinor` 当权威值写回存储；不要改卡片 DOM 契约而不更新验收测试。
