## 1. 结论摘要（C-0 发现的 12 件事）

1. **账目事实源只有一个**：`Transaction` 表（账本隔离 + 软删 + 金额 BigInt + 单一币种 + 业务日期），与 A 的 §10 字段映射一致（A 文档 `S17-Agent-A-基础与分类分析.md` §10）。C 不新增第二套账目来源。
2. **34 项能力的数据状态**：当前直接支持 3 项（A08、P08、P15）；需新的只读投影 27 项；需核实字段语义 1 项（A15，零金额是否可入库）；需数据模型扩展 3 项（P05/P06/P07 分类层级）；当前不适合真实上线 0 项。**「需只读投影」不是「没数据」，而是现有公开读接口的形状不够**（见 §2.3）。
3. **分类没有父子层级**：`Category` 无 `parentId`/`level`，只有一级平铺 + `sortOrder` + `isArchived`。P05/P06/P07 在无层级时只能以**单层退化 + 显式标注「当前分类无层级」**交付，**不得按名称/备注猜层级**（owner 规格 §42.3、§6.5）。
4. **退款/撤销未建模**：`amountCents` 恒非负（`money.ts` 拒绝负数；`fx.ts` 注释明确「不擅自引入负流水」），`kind` 只有 `expense`/`income`，没有退款关联、冲销、负交易。C 的分布/箱线/散点默认按「正金额 + kind 语义」计算；任何净额/退款口径必须等所有者裁决（QC-04）。
5. **支付方式 ≠ 资金账户**：`paymentMethodId` 可空、删除时 `SetNull`，是描述性维度；不得推导账户余额/转账/负债。历史维度漂移需在口径中说明（R-04）。
6. **多币种只能逐笔折算**：`Transaction.currency` 单值；原币模式单币种 where；综合模式必须复用 `aggregateFxAsync`/`convertFx`（`FX_POLICY="minor-half-away-v1"`、7 天回退）。P16–P20 需要**逐笔 FX 诊断投影**，现有公开 API 只给聚合结果（R-07）。
7. **金额精度链路安全但分层明确**：DB `BigInt` → API JSON `number`（schema 上限 `MAX_AMOUNT_CENTS=1e12 < 2^53`）→ 分析层必须回到 `bigint`（A 的 `AnalysisEntry.amountMinor`），图表适配器才允许浮点坐标。
8. **交易 DTO 带 tags/version，但不带 `valueHistory`、`categoryIsArchived`、`author`**：C 的分析只用「当前快照」；修改历史不进入统计，只在来源说明中提及（R-13）。
9. **业务日期唯一**：`occurredLocalDate`（`@db.Date`，用户手机日历日）；`occurredAt` 不得做日/月分组，`createdAt` 不是业务日。用户闭区间 `[from,to]` 与 DB 半开 `[from, to+1d)` 的转换集中在分析层（A 的 `ResolvedPeriod`）。
10. **软删/恢复必须与统计同口径**：统计固定 `deletedAt: null`；恢复后重新出现；导入删除（`deletedByImportId`）只在 DTO 出现。来源追溯不得显示已删记录却算进统计。
11. **数据版本戳缺失**：S-01 的 `dataVersion` 目前只能是 `null`；C 的「同定义同版本结果一致」「跨卡复用缓存」缺少统一戳（QC-06）。工作台数据层/查询入口是唯一能生成它的地方，C 不自行编造。
12. **离线覆盖元信息缺失**：B 的 `coverageEnd` 由调用方传入；C 离开该合同无法判断「确认的 0」与「未知」。C-0 结论：所有 C 结果在离线态先降级为 `offline-incomplete` 占位，不把缺失当 0（QC-07）。

## 2. 数据契约核查（owner 规格 §3 的 18 项 + 能力依赖状态）

### 2.1 数据模型总览（一句话）

账本隔离的 `Transaction` 表是唯一账目事实源：金额 `BigInt` 最小单位且**非负**、币种 `char(3)`、业务日期 `occurredLocalDate @db.Date`、收/支由 `kind` 快照区分、`categoryId` 必填（一级分类）、`paymentMethodId` 可空、软删 `deletedAt`、账本与权限由 `bookId` + `BookMember` 决定；分类/支付方式/标签只归档不删除（除支付方式删除时交易侧 `SetNull`）。

**成本预算原则**（owner 规格 §45，未测量前不写虚构指标）：

- **L0 复用聚合**（`GET /stats`）：O(k)（k=分类数），不产生逐笔扫描；大多数卡片优先走这里。
- **L1 分析层轻量计算**（记录已在前端/内存）：n ≤ 5,000 时 O(n) / O(n log n)；超过阈值必须走 L2/Q1。
- **L2 只读投影**（Q1–Q5）：由服务端分页/聚合/排序；单次响应有行数上限 + cursor。
- **L3 视觉采样**：仅散点/大日历；采样结果不得写回结果对象（`renderedPointCount < totalPointCount` 必须显式）。
- **硬约束**：图表适配器不得重算金额；同一结果对象在任何尺寸下金额一致；缺失/不可计算必须有状态（不画 0）。

### 4.3 关键算法口径（草案，待 A 确认后冻结）

|---|---|---|
