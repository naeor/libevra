## 2. 做了什么（已实现并验证）

- **三态同页**：浏览 / 筛选（页内展开，草稿 + 应用；收起保留草稿并提示；撤销修改单独按钮）/ 编辑（原位半透明虚线卡片，操作菜单，撤销重做，调整行列，取消前确认）。
- **底部抽屉**：编辑时替换 Tab 栏；分析卡片（系统推荐 / 全部分析含搜索 / 我的自定义）与布局容器（Carousel / GridSplit / Spacer）；长按拖入带合法 / 非法落点预览，或「+」放到第一个空位；拖动时自动收起抽屉。
- **容器**：空容器先为页面草稿，够最少张数才一次写入布局（Carousel 2–6、GridSplit 2–4）；「编辑内部卡片」在抽屉里增删排序；浏览态 Carousel 左右滑 / 箭头 / 页点，GridSplit 按张数分格；收起为 1×1 入口（D 的 `set-presentation`）。
- **卡片**：A 的 26 项 + B 的 I06–I10、I15、I16、I19、I20 + 原分析页的 I11 / I12 / A01，全部真实账目；按卡片真实宽高选密度；金额一行自适应字号。
- **详情页**：继承所点卡片配置与生效筛选；计算方法 / 数据来源说明；返回恢复滚动、焦点、Carousel 页码。
- **保存**：按账号（游客按游客身份）存本机，D 的 `WorkbenchLocalRecordV1`；读不出时显示默认并说明，**不覆盖原记录**。
- **验证**：见 [1.17 版本记录](../../../changelog/1.17.md) 1.17.2 条（测试数、检查命令、走查清单）。

**未做 / 未验证**：真机、iOS Safari、PWA；服务器同步（`pendingSync` 恒为 true）；完整自定义卡片创建器（仅入口 + 五步说明，等所有者确认）；分享。

## 4. 编辑操作与 D 命令

| 操作 | 实现 |
|---|---|
| 移动 / 拖放 / 键盘以外的位置调整 | D `move` |
| 调整尺寸 | D `resize`（可选尺寸来自卡片目录，合法性由 D 判断） |
| 删除卡片 / Spacer | D `delete` |
| 添加卡片 / Spacer | D `insert-card` / `insert-spacer`（空位：D `findEarliestFreeAnchor`） |
| 容器收起 / 展开 | D `set-presentation`（D 记录 `expandedSize`） |
| 撤销 / 重做 | D `EditorState.history`（上限 50） |
| 改列数 | D `projectLayout` → `projectionToGeometry`（保留用户收起意图） |
| 向上紧凑 | D `compactVertically` |
| 合法性 / 落点预览 | D `validateGeometry` |

**过渡适配（D 尚无命令，D 设计稿 §6 与 D-3.2 §8 已登记为缺口）**——`apps/web/src/statsWorkbench/session.ts`：

| 函数 | 用途 | 收敛方式 |
|---|---|---|
| `insertContainer` | 插入带子卡片的容器 | 换成 D 的插入容器命令 |
| `replaceContainerChildren` | 容器内部增删排序（一次提交、一步撤销） | 换成 D 的容器内部编辑命令 |
| `removeObject`（容器分支） | 容器连同子卡片整组删除 | 换成 D 的整组删除 |
| `duplicateObject`（容器分支） | 整组深复制、全新 ID、不复制结果 | 换成 D 的复制命令 |
| `updateCard` | 配置面板提交（标题 / 家族 / 时间） | 换成 D 的配置提交命令 |

做法统一为「整份文档转换 → D 的校验器（内容 + 布局 + 几何 + 交叉引用）→ 合法才压入 D 的撤销栈，否则原样返回」。**没有自己的几何、碰撞、投影规则**。
