## 2. 做了什么（已实现并验证）

- **三态同页**：浏览 / 筛选（页内展开，草稿 + 应用；收起保留草稿并提示；撤销修改单独按钮）/ 编辑（原位半透明虚线卡片，操作菜单，撤销重做，调整行列，取消前确认）。
- **底部抽屉**：编辑时替换 Tab 栏；分析卡片（系统推荐 / 全部分析含搜索 / 我的自定义）与布局容器（Carousel / GridSplit / Spacer）；长按拖入带合法 / 非法落点预览，或「+」放到第一个空位；拖动时自动收起抽屉。
- **容器**：空容器先为页面草稿，够最少张数才一次写入布局（Carousel 2–6、GridSplit 2–4）；「编辑内部卡片」在抽屉里增删排序；浏览态 Carousel 左右滑 / 箭头 / 页点，GridSplit 按 D 的千分比分格；收起为 1×1 入口（D 的 `set-presentation`）。
- **卡片**：A 的 26 项 + B 的 I06–I10、I15、I16、I19、I20 + 原分析页的 I11 / I12 / A01；按卡片真实宽高选密度；金额一行自适应字号。
- **详情页**：继承所点卡片配置与生效筛选；计算方法 / 数据来源说明；返回恢复滚动、焦点、Carousel 页码。
- **保存**：按账号（游客按游客身份）存本机，D 的 `WorkbenchLocalRecordV1`；读不出时显示默认并说明，**不覆盖原记录**。
- **验证**：见 [1.17 版本记录](../../../changelog/1.17.md) 1.17.2 条。另在交付副本（全新克隆、离线安装依赖）上复跑：`pnpm -r typecheck`、`pnpm check:build`、web `statsWorkbench` + `pages` 30 文件 / 309 项通过。

**未做 / 未验证**：真机、iOS Safari、PWA；服务器同步（`pendingSync` 恒为 true）；完整自定义卡片创建器（仅入口 + 五步说明，等所有者确认）；分享。

## 3. 数据来源与边界（截至本提交）

- 走查用的「真实数据」= **本会话云端沙箱里新建的 Postgres 开发库**，账号 `s17owner` 由脚本经正式 API 注册，账目为脚本按固定随机种子生成的**合成数据**（约 400 天）。页面读取路径与正式环境相同（本机离线账本 + `/stats` 对照），但数据不是任何真实用户的账目。
