## 1. 授权边界与隐私约束

- 允许：本机开发/测试数据、只读查询、汇率口径核对、生成**不含个人敏感信息**的统计摘要、与已知正确结果比较。
- 禁止（Owner 2026-10-27）：修改/删除原始记录；生产库试探；上传外网；把真实账单/隐私/凭据写入源码、日志、公开测试快照；读取 `.env`/私钥/密码文件。
- 脱敏要求（建议 Lead 按此输出）：
  - 账本用匿名键（`book-a`/`book-b`），成员/用户不出现在样本里；
  - 交易/分类/支付方式用匿名键（`cat-001`、`pm-002`）或仅系统分类名（如「餐饮」「交通」）；自建分类名可替换为序号；
  - 不含备注、标签名、金额以外文本、头像、邀请信息；
  - 时间粒度保留到业务日（`occurredLocalDate`），不需要精确到时分；
  - 金额保留最小单位整数（分），不需要展示元；
  - 汇率观测只保留 `provider/base/quote/date/rate`；
  - 样本总量控制：每项 ≤ 数百行；不需要全量账本。
- C 侧记录方式：原始样本只在会话内比对；**提交进仓库的只有口径、方法与「一致/差异」结论**（不含真实金额与分类名）；若需举例，用合成数值。
