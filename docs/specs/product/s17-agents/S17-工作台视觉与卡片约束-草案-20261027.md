## 1. 总原则

1. **只用语义 token**（`index.css` `@theme`）：颜色、圆角（`--radius-card` / `--radius-field`）、字号（`text-helper`、`text-body`、`text-card-title` 等），不新增色值，七主题 × 浅 / 深自动跟随。
2. **浏览态零编辑痕迹**：没有格线、手柄、尺寸角标；编辑痕迹只在编辑态出现。
3. **布局层只给尺寸，卡片自己按真实宽高选密度**；同一结果在任何尺寸下数值一致（ACC-02），只变展示。
4. **不能假装有数据**：加载、本机补齐中、无记录、不支持、出错，各有不同的状态外观，不画成 0 或空图。

## 2. 网格

| 项 | 值 | 说明 |
|---|---|---|
| 基础列数 | 手机 2；可选 2 / 3 | 实际显示列数 = min(布局 `baseCols`, 宽度能容纳的列数)，列宽下限 104px（含 12px 间距计算）；超出时由 D 的投影重排，不写回 |
| 行高 | 7.25rem（116px） | 所有行等高；一格 = 1 列 × 1 行 |
| 间距 | 0.75rem（12px） | 行列相同 |
| 页面边距 | 1.5rem（24px）左右 | 与其它 Tab 页一致 |
| 编号 | 行优先，从 1 开始 | 与 D 的 `anchor` 一致 |

## 3. 卡片外壳（浏览态）

| 项 | 值 |
|---|---|
| 外框 | `rounded-card`、1px `border-line`、`bg-surface`；内边距 14px（≥640px 宽 16px）；悬停时边框混入 35% 品牌色 |
| 点击区 | 整卡是一个「查看详情」按钮；正文里只有可交互的图表读数区域（`.sw-interactive`）接收点击，其余点击都交给整卡 |
| 标题 | `text-helper` 中等字重，**最多 2 行**后省略；右侧 14px 右箭头（55% 不透明） |
| 副标题 | 只在卡片时间与全局筛选不同的时候出现（固定区间 / 自带窗口 / 日历截取月份）；不重复写币种 |
| 大号金额 | 一行显示，按可用宽度自动在 2xl → xl → lg → base 中选择最大的字号，仍放不下才省略；负数用支出色 |
| 焦点 | 4px `focus-ring` 外圈 |

### 3.1 密度（卡片正文实测宽高）

| 档 | 条件 | 用途 |
|---|---|---|
| expanded | 宽 ≥ 300 且高 ≥ 200 | 完整图例、坐标轴、排行全部可见项 |
| medium | 宽 ≥ 200 且高 ≥ 120 | 精简图例 |
| compact | 其它 | 只保留主数字或最少要素 |

图表高度 = 正文可用高度 − 30px（留合计行），夹在 72–260px；详情页固定 240px。

### 3.2 状态外观

| 状态 | 外观 |
|---|---|
| 本机还没读到 / 正在补齐缺失月份 | 骨架条（`role=status`），不显示 0 |
| 这段时间没有记录 | 一行说明文字，不画坐标全为 0 的空图 |
| 数据不完整 / 无法确定 | 数值下方警示色说明（A 的 `completeness`） |
| 综合折算下不支持 | 说明 +「改用原币查看」文字按钮（只在工作台出现，详情页不改筛选） |
| 未知或较新的分析编号 | 只读占位「更新应用后即可显示」，不删除配置 |
| 渲染出错 | 单卡错误边界，只影响这一张 |
| 尺寸低于卡片最小尺寸（兼容 1×1） | 提示「卡片太小」 |

## 4. 卡片尺寸约束（建议作为 W3 `ObjectSizeContract` 的首版输入）

尺寸写作「宽×高」（格）。`sizeLadder` = 可选尺寸按面积从大到小；`compatSize` 均为 1×1。

| 卡片 | 家族（第一个为默认） | 默认 | 最小 | 可选 |
|---|---|---|---|---|
| A 数字类 B01–B08、B13、B14、B16、B18、B19 | number | 1×1 | 1×1 | 1×1、2×1、1×2、2×2 |
| A 极值类 B09–B12、B15、B17、B20 | extreme | 1×1 | 1×1 | 同上 |
| I01、I02、I17 构成 | donut / ranking / table | 2×3 | 2×1 | 2×1、1×2、2×2、2×3 |
| I03、I04、I05 排行 | ranking / table | 2×2 | 2×1 | 同上 |
| B 时间序列 I06–I10、I19 | line / area / bar（I08–I10、I19 默认 bar） | 2×2 | 2×1 | 同上 |
| I11 收支趋势 | flow-bars / flow-lines | 2×2 | 2×1 | 同上 |
| I20 累计 | cumulative | 2×2 | 2×1 | 同上 |
| I15 分类趋势 | stacked / line | 2×2 | 2×2 | 2×2、2×3 |
| I16 分类占比带 | share-bands | 2×2 | 2×2 | 2×2、2×3 |
| I12 日历热力 | heatmap | 2×3 | 2×3 | 仅 2×3 |
| A01 上期比较 | comparison | 2×2 | 2×2 | 2×2、2×3 |

**甜甜圈门槛**：合计完整且至少 2 个可安全换算的部分才画环，否则自动改为排行 / 表格（不是用户选择的家族被静默替换，而是结果不满足环图前提）。

## 5. 布局容器

| 容器 | 默认 | 可选 | 子卡片 | 收缩 |
|---|---|---|---|---|
| Carousel（滑动卡片组） | 2×2 | 1×1、2×1、1×2、2×2、2×3 | 2–6 | 1×1 入口；`minFullCols` 1 |
| GridSplit（分割卡片组） | 2×2 | 2×1、2×2、2×3 | 2–4 | 1×1 入口；`minFullCols` 2 |
| Spacer（空白） | 1×1 | 1×1、2×1、1×2、2×2 | — | — |

- **Carousel 浏览态**：子卡片无独立外框（共用容器外框）；底部 28px 条：左右小箭头 + 页点（当前页为加长胶囊），`role=status` 读出「第 n 张，共 m 张」；横向滑动阈值：水平位移 > 40px 且 > 1.5 倍垂直位移，否则让给页面纵向滚动。
- **GridSplit 浏览态**：用 D 的千分比（`columnSplitPermille` / `rowSplitPermille`）排槽位，首期 2 张左右各半、3–4 张田字格（3 张时余一格空）；槽位间距 8px，每张子卡片保留自己的卡片外框。
- **1×1 收缩入口**：容器图标 + 「n 张卡片」，点开底部面板列出子卡片，可逐张进详情。
- **空容器**：只是编辑态的「待填充」草稿（实线品牌边框 + 呼吸光），抽屉切换为容器内编辑；加够最少张数才写入布局，取消即消失。

## 6. 编辑态

| 元素 | 外观 |
|---|---|
| 页头 | 顶部吸顶条：左「调整行列」（< 380px 宽只显示图标）、撤销、重做；右「取消」「完成」（主色）。底部 Tab 栏由抽屉替换 |
| 对象 | 1.5px 品牌色 45% 虚线、品牌浅底 72% 半透明、`rounded-card`；左上类型图标、右上尺寸角标（如 `2×2`）、左下名称（最多 2 行）+ 分组 / 「已收起」；**不画完整图表** |
| 选中 | 实线品牌边框 + 3px 品牌色 22% 外圈 |
| 拖动中的原对象 | 35% 不透明 |
| Spacer | 斜纹（`line` 55%）+ 弱虚线 |
| 空格引导 | 只在没有对象覆盖的格子显示：1px 弱虚线 + 画布色 60% |
| 移动目标（「移动」模式） | 品牌浅底 + 呼吸光，可点 |
| 落点预览 | 合法：2px 实线品牌色 + 柔光；不合法：2px 虚线危险色 + 危险浅底 + 原因文字 |
| 拖动提示 | 跟随指针的深色胶囊（对象名） |
| 撤销提示 | 编辑态在顶部、浏览态在底部的深色提示条，带「撤销」 |

### 6.1 手势（手机端冲突处理）

| 输入 | 规则 |
|---|---|
| 鼠标 | 按下后移动 > 5px 才开始拖动，否则是点击 |
| 触摸 | **长按 300ms** 开始拖动（轻微震动）；长按前手指移动 > 8px 视为滚动，取消拖动 |
| 拖动中 | 阻止页面跟随滚动；指针靠近滚动区上下 64px 内自动滚动 |
| 放下后 | 450ms 内的点击被吞掉，避免放下即打开菜单 |
| Esc | 取消拖动 |
| 系统长按菜单 | 编辑对象上禁用（避免 iOS / Android 长按菜单打断） |

### 6.2 底部抽屉

| 项 | 值 |
|---|---|
| 展开高度 | min(48dvh, 27rem) |
| 收起高度 | 4.5rem + 底部安全区（只留把手和标签） |
| 结构 | 把手 → 分段「分析卡片 / 布局容器」+ 收起按钮 → 分组标签（系统推荐 / 全部分析 / 我的自定义）→ 说明一行 → 两列卡片砖（图标、名称、默认尺寸、「+」） |
| 拖出 | 从抽屉长按拖到网格时抽屉自动收起，放下后恢复 |
| 收起时 | 内容保持挂载（只隐藏），保证拖动源不被卸载 |

## 7. 筛选（浏览态顶部）

- 页头：标题「分析」+ 副标题；右侧两个圆形按钮（筛选、编辑），筛选按钮在有未应用修改时带小圆点。
- 生效条件摘要：一行，可点开筛选；有未应用修改时显示警示色「有未应用的修改」标签。
- 筛选面板在页内展开（`grid-template-rows` 过渡，卡片下移），底部「撤销修改」与「应用」分开；「收起」不丢草稿。
