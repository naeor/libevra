### 0.2 判定词

| 判定 | 含义 |
|---|---|
| **一致** | 语义、字段或归属与 C 实现/回执一致，无阻塞 |
| **冲突** | 同一语义两侧给出不同定义/字段/数值，必须二选一或统一 |
| **重复** | 同一概念/结构在两处定义（含同义异名），建议保留一个 |
| **不兼容** | 缺失字段/枚举/包装形态，按当前文本无法直接对接，需补充定义 |
| **预期差异** | 因 draft 未包信封等已知原因造成的差异，冻结时按计划补齐，不算缺陷 |
