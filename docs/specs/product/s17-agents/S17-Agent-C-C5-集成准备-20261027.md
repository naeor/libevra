## 4. 组件输入与几何边界（硬规则，集成期不得违反）

1. **数学权威在 shared**：金额、占比、分位、归因、守恒一律来自 shared 结果；web 只做「结果 → 图表输入」投影与几何。
2. **几何只吃归一化 number**：`*Fraction`/`*Text` 是展示派生；几何函数不得重新计算金额/占比/分位（几何层出现 `bigint` 求和即违规）。
3. **金额文本统一**：一律 `formatMinorText(minor, decimals)`（`decimalsFor(currency)`）；大额缩写按 `C_AMOUNT_DISPLAY_TIERS_MINOR`，完整值必须可在 title/详情/数据表获得。
4. **缺失≠0**：空态/不可用/拒绝三种状态必须区分并给原因（`emptyCellText`/`unavailableReason`/`reasonText`），不得用 0 占位。
5. **折叠必须守恒**：序列 > `C_MAX_VISIBLE_SERIES`、桑基 > `C_SANKEY_MAX_LINKS`、层级表 > `C_HIERARCHY_TABLE_MAX_ROWS` 的折叠/截断必须显式标记；金额折叠须由 shared `foldRemainder` 语义完成，web 不得自行丢数据。
6. **密度不影响数值**：尺寸档位只改变布局/文本密度，同一 `analysisId` 的金额在任何尺寸下相同（S-01/图表规格硬规则）。
7. **几何纯函数可测**：无 DOM、无主题依赖；容器尺寸由 D 的布局层传入（ResizeObserver 结果）。
8. **不冻结公共接口**：C-5 期间不改 S-01/公共库入口；任何协议变化走 v2 评审。
