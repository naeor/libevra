## 2. 页面状态与作用域

| 代号 | 状态 | 说明 | 与 D 引擎的关系 |
|---|---|---|---|
| **B** | 浏览态（默认） | 标题、必要筛选摘要、漏斗/编辑入口、已保存布局上的真实分析卡片、主导航 | 使用投影结果渲染；布局只读；点击卡片进入查看/分析详情，**不进入布局编辑**【已决定】 |
| **F** | 筛选展开态 | 在当前页顶部展开筛选区，卡片因上方区域变高而自然下移；可收起并保留有效条件摘要 | **不改变网格编号/锚点/权威主布局**；页面下移不是布局 move【已决定】 |
| **E** | 外层布局编辑态 | 全部可编辑对象切成“结构编辑形态”：名称/类型图标、边界、位置/尺寸状态；提供添加、配置、复制、删除、移动/缩放 | 编辑会话（内存草稿）；命中 D-2 状态机；保存才写回【已决定】 |
| **C** | 容器内部编辑态（E 的子作用域） | 明确“正在编辑哪个容器”；子卡片清单/槽位可选、可配置、复制、删除、排序或换槽 | 新能力方向；父容器暂停拖动；不突破深度 1【方向已决定·细节待确认】 |
| **M** | 快捷菜单 | 卡片/容器上的菜单：编辑内部内容、配置、复制、删除、移动/调整尺寸入口 | 依附当前编辑作用域【方向已决定】 |
| **G** | 移动/缩放 | 拖动预览、合法位置高亮、非法位置拒绝 | 使用 D 几何/碰撞/投影判定【已决定】 |
| **P** | 配置面板 | 卡片/容器/自建卡片的配置 | 不进入财务详情、不改交易【方向已决定·细节待确认】 |

- 三态关系：**B（浏览）/F（筛选展开）/E（外层编辑）**是页面状态的三个主形态；**C 是 E 的子状态，不是第四个全局模式**（与 Codex 交互补充一致）。
- 现有 D-2 状态机 `machine.ts` 只有 `browse`/`edit` 两态；F 是页面内视图态（不进布局命令），C 后续需要新增“作用域”概念（建议以 `scope: { kind: "workbench" | "container"; containerId? }` 扩展，待 I-2 评审，不在本轮实现）。

## 4. 编辑交互规则（D 侧可判定部分）

### 4.1 拖放与合法性

- 拖动/缩放时必须显示**预览**与**合法落点高亮**；非法位置（越界、重叠、低于 `minSize`、宽度超过列数）必须**拒绝并说明原因**，不得静默丢弃对象或内容【已决定】。
- 合法/非法判定全部来自 D 的几何与投影契约（`placementFitsColumns`/`validateGeometry`/`findEarliestFreeAnchor`）；UI 不得自建碰撞或跨列迁移算法。
- 释放失败时保持原位置与原对象，不产生半提交状态。

### 4.2 触控与非拖动替代路径

- 手机端除长按拖动外，必须提供**触控友好的非拖动路径**：如点击对象 → 菜单“移动/调整尺寸” → 选择目标位置或尺寸档；添加卡片也支持“选择 → 放入”而非仅拖放【已决定】。
- 长按阈值、手柄尺寸、命中区域归 Codex/真机验证；D 只提供合法目标判定。

### 4.3 撤销、保存、取消、未保存

- 编辑会话支持撤销/重做（候选上限 50，可另行确认）；「完成」一次性提交、「取消」放弃（有改动须二次确认）、系统返回=取消；破坏性操作可撤销；中断不得部分写回【既有确认 + 所有者方向一致】。
- 保存落点、跨列写回仍待 OQ-LM-07 明确（见 OQ 差异清单 DIFF-03）；在明确前沿用 D-2 前置 M1 占位口径，不作为正式裁定。
- 筛选展开/收起、Carousel 翻页等浏览态操作**不算**编辑，不影响未保存状态。

### 4.4 容器内部编辑

- 进入 C 态后：父容器暂停拖动/缩放；子卡片操作先于父容器手势；可返回外层并保留父容器选中与本次草稿。
- 首版内部结构限制不变：容器内只放卡片，不放容器/Spacer；深度 1。
- 内部编辑命令（添加子卡、删除子卡、重排、换槽、GridSplit 比例调整）属**待扩展命令**，本轮不实现，列入 §6。

### 4.5 添加区域与自建卡片

- 添加区域两类入口见 §3 第 5 条；入库、推荐目录、拖放载荷与持久化之间只做类型路由与能力校验，不合并为同一种业务对象。
- 自建分析卡片：本轮只登记方向与差距（单一 `AnalysisReference` 不足以表达多结果组合卡），等待 A/S-03 提供组合展示合同后再设计。

## 5. 容器与手势

| 手势/交互 | 浏览态 B | 编辑态 E | 容器内部 C |
|---|---|---|---|
| 页面纵向滚动 | 正常滚动 | 正常滚动（拖动时自动滚动） | 正常滚动 |
| 容器内横向滑动 | Carousel 切页；与页面纵滚先判方向 | 不切页（暂停浏览手势） | 子卡片操作优先 |
| 图表读数/点选 | 先处理读数/选中，显式入口再追溯 | 不处理财务交互 | 子卡片内的读数按 C 规则 |
| 卡片点击 | 打开详情 | 打开快捷菜单 | 打开子卡片菜单/配置 |
| 布局拖动 | 不响应 | 拖动对象 | 父容器不拖动 |
| 展开入口 | 无法完整展示的容器显示展开入口（覆盖层/详情视图） | 仍可打开；编辑态标明被收缩 | 打开后返回原作用域 |

- 手势冲突原则【已决定】：浏览与编辑行为分开；图表、容器横滑、页面纵滚、布局操作不能同时响应同一手势；具体阈值/方向判定与真机验证归 Codex（布局规格 Q-13 原则）。
- 展开入口不得改变容器外层网格位置/尺寸；打开/关闭恢复原作用域与状态（全部子卡片可访问、可进各自详情、返回保留滚动/Carousel 页）。容器完整查看最终形态（独立页/全屏覆盖/自适应）仍待所有者（OQ-LM-05 / OQ-UI-12）。

5. 空容器草稿模型（先建后填；OQ-UI-10）或放宽校验的评审；
