## 2. 原始风险与研究目标的去向（G-01…G-21）

G 项来自 Agent 的调查，不等于所有者批准。这里保留风险本身和目标；“已写入规格”不冒充已经实现或实测通过。

| 原风险编号 | 原问题与保留的判断入口 |
|---|---|
| G-01、G-19 | 游客转账号和引用映射不能按名称猜测；现有文件交换边界按配置 §11，扩展自动迁移再立项 |
| G-02、G-06、G-21 | 注销/清理要覆盖配置；PWA 可能新旧客户端并存；恢复副本不能误覆盖。已有清理、兼容和 CAS 规则见配置 §4.2、§4.5、§11 |
| G-03、G-12、G-13 | 自定义标题可能含私密信息，未来公开分享涉及内容审核与数据处理清单；分享立项前确认，当前不开放分享码 |
| G-04 | 按记账人分析涉及作者数据和权限，保留成员维度/P21 候选，不因工作台完成自动实现 |
| G-05 | 早期“分享/导入需联网”的边界只适用于当时公开分享研究；现有本地文件交换按配置 §11，不用旧结论禁用已交付的离线能力 |
| G-07、G-08 | 自定义标题与语言分开；同屏卡片使用可解释的一致取数上下文。按卡片 §4.1、§4.5 与总需求 §4.2 |
| G-09、G-10 | 图片/打印等属于另行范围；编辑操作要有拖动以外的可访问路径。按总需求非目标及布局 §6.3、TC-24 |
| G-11、G-14、G-15 | 容量/并发、跨午夜 today、冷启动汇率、视觉与合成数据矩阵需证据；现行性能基线和专题测试为准，不复用旧未验证数值 |
| G-16、G-17 | 共享成员与管理员不能扩大数据访问；转账分类要按明示统计语义处理，不能自动猜测排除。按 ACC-12、卡片 §8.5、能力目录 FL-02 |
