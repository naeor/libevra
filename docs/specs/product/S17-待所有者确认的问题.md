### Q-02 · 工作台的作用域：每用户一套、每账本一套，还是混合
**背景**：分类 / 标签 / 支付方式是账本级对象；个人账本与家庭账本的分析诉求可能不同。
**选项**：A 每用户一套；B 每用户每账本一套；C 混合——布局方案是用户级命名资产，“当前使用哪个方案”和引用绑定按（用户，账本）记录。
**推荐**：C；若想首版从简，选 A，但数据结构保留“绑定表”的位置，之后升级到 C 无需改写已有配置。
**不答复的后果**：W2 的配置 schema 无法冻结。
**涉及**：配置与分享 §3.2。

### Q-03 · 个人配置存哪里：本地、服务端，还是本地优先 + 同步
**背景**：需求要求跨设备保持一致，但语言 / 主题目前是设备级（S16-E 的 D-15 尚未决定是否账号化）；分享本身必须有服务端存储。
**选项**：a 仅设备本地（不满足跨设备）；b 账号服务端（需新表 + 迁移）；c 本地优先 + 服务端同步。
**推荐**：c；并**与 D-15 一并决定**，避免两套同步机制。W5 之前可先本地保存。
**不答复的后果**：W6 的迁移与同步范围无法确定；不影响 W1–W5。
**涉及**：配置与分享 §3.4。

## 2. P1 · 架构冻结之前（W2 结束前）

### Q-07 · 周起始日
周一 / 周日 / 随语言（中文区域默认周一？）。影响周趋势（AN-A06）与星期分布的归属。**推荐**：周一，并在设置中不提供切换（首版），卡片说明里写明。涉及能力目录 D-03。

### Q-08 · 跨设备布局方案
A 单一布局自动响应；B 按设备尺寸分别保存；C 共同分析配置 + 布局档案（按列数）。**推荐**：数据结构按 C 设计，首版只启用一个档案（行为接近 A）。涉及配置与分享 §5。

### Q-09 · 网格：占格记法、行高、空洞 vs 紧凑
记法 α `宽×高`（推荐）还是 β `行×列`；行高固定值还是等于列宽；摆放策略 A 垂直紧凑（推荐首版）/ B 允许空洞 / C 推挤。涉及布局规格 §5.2–§5.4。

### Q-10 · 列数策略
默认列数、手机最大可选列数、`minCol`、边距 / 间距。例如 `minCol=110` 时 390 宽手机可三列；`130` 时只能两列。**推荐**：手机默认两列；是否允许三列由原型可读性测试决定。涉及布局规格 §5.1。

### Q-11 · 卡片时间筛选与模式的覆盖
卡片是否允许“固定自己的时间范围”（推荐允许，但标题处必须标明）；是否允许按卡片覆盖原币 / 综合模式（**推荐首版不允许**，因为该开关是设备级偏好，覆盖会同屏混合两套完整性规则）。涉及图表与卡片 §4.4。

### Q-12 · 容器首期范围、嵌套与比例
首期自由分割用对齐式 `GridSplit`（推荐）还是直接做任意二叉分割树；嵌套深度（推荐首期容器内不放容器）；容器宽高比约束（如 1:2）只是候选，**是否采用、数值多少**。涉及布局规格 §8。

### Q-13 · 手势冲突方案
抽屉横向滑动 vs 图表内横向拖动读数 vs 页面滚动 vs 编辑拖动。选项：图表读数需长按激活（推荐）；抽屉只在边缘 / 指示条区域响应滑动；其它。Safari pointer capture 行为尚未验证，需 W5 前真机 spike。涉及图表与卡片 §7.7、布局规格 §8.3。

### Q-14 · 分享识别码与分享规则
(1) 码形态：短码易读（有枚举风险，需限速）还是长随机令牌（≥128 bit，抗枚举但难输入）；(2) 作者匿名（推荐默认匿名）；(3) 用户自定义卡片标题是否可随分享导出（推荐默认不导出）；(4) 是否支持撤销 / 过期（推荐支持撤销）；(5) 作者注销后分享项删除还是匿名保留（推荐删除）；(6) 是否统计导入次数（推荐不统计）；(7) 模板名称 / 描述的审核与举报机制。涉及配置与分享 §6.4。**公开分享上线前必须有对应隐私文本**（见 G-13）。

### Q-15 · 导入时引用缺失与限额
导入后分类 / 支付方式 / 标签引用无法对应时，用户重新选择（推荐）还是自动按名称绑定（不推荐）；导入限额（总字节、卡片数、容器数、深度）采用候选值还是调整。涉及配置与分享 §6.5、§7。

### Q-16 · 详情页内改筛选能否另存
详情页内修改时间 / 币种，默认只影响详情页本身（推荐）。是否提供“应用到卡片”或“另存为新卡片”。涉及图表与卡片 §8.3。

### Q-17 · 预设模板的来源与更新
内置模板随应用版本发布（推荐）还是服务端下发；“从未编辑过布局的用户随版本自动获得新默认，编辑过的保持自己的并可选择查看新默认”（推荐）是否同意；模板中的“多币种观察”不得静默改设备级开关（推荐）。涉及布局规格 §9。

### Q-18 · 综合折算是否成为分析页默认
目前综合模式默认关闭、设备本地显示（S16-D）。工作台上线后是否仍保持默认关闭，或对有外币账目的用户给出引导。**推荐**：保持默认关闭，由“多币种观察”模板引导开启。涉及总需求规格 §3、S16-D。
