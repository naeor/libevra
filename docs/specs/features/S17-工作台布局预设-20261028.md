# S17 分析工作台：布局预设（1.17.12，2026-10-28）

> 最后核对: `s17/next-presets` / 2026-10-28（1.17.12，仅本地）。
> 性质：功能与验收说明。执行状态只写 [STATUS](../../STATUS.md)；版本记录见 [changelog/1.17](../../changelog/1.17.md)。
> 不改 Agent D 布局文档 schema、不改分析计算与汇率折算引擎、无 API / 数据库改动。卡片读法与相对时间窗口见 [自定义卡片指标与展示能力 §9](S17-自定义卡片指标与展示能力-20261028.md)。

## 1. 是什么

- **布局预设管理整张工作台**（有哪些卡片、放在哪、多大、横向滑动抽屉里有什么、各卡片看哪段时间）。**卡片内容模板 T1–T8 管理单张卡片内部**怎么排。两者不混用：预设页的说明按钮写明这一点。
- 入口：编辑工作台时，底部工具栏标题栏右侧的「预设」（次要样式，不用切到「布局容器」）。点开是「布局预设」页：一页、上下两条横向滑轨——「系统预设」与「我的预设」。
- **先预览、再应用**：点任何预设先进入预览（按当前账本真实计算的完整工作台）；点「应用这个预设」才替换编辑会话里的工作台，作为**一步撤销**；仍要点编辑栏「完成」才保存工作台。没确认就返回，编辑状态不变。预览里可以「先保存当前布局」，存完回到同一个预览。

## 2. 页面

| 区域 | 内容 |
|---|---|
| 标题栏 | 「布局预设」+ 说明按钮（按需展开一段说明）+「完成」 |
| 系统预设 | 新手（嫩芽图标）/ 进阶（上升曲线）/ 专业（散点网络）三张卡：名称、一句定位、布局缩略图（按真实布局文档画格子，抽屉画页码点）、「N 行 · N 张卡片」、「预览」。品牌绿 `--color-brand` |
| 我的预设 | 第一张永远是「＋ 添加自定义预设」（满 10 个或本机存储只读时禁用并写明原因）；每个预设：名称、说明、缩略图、更新日期、「预览」、「⋯」（预览 / 应用、重命名、更新、删除）；损坏或来自更新版本的条目只读显示、只能删除 |
| 预览 | 返回、「预览 · 名称」、实时工作台、底部固定栏：替换提示、（保存过筛选时）「同时使用保存时的筛选条件」、「先保存当前布局」、「应用这个预设」 |

- 手机：两条滑轨横滑、按卡片吸附（`scroll-snap` mandatory），还有内容的一侧淡出。桌面（可悬停的指针）：滑轨两端出现左右按钮。宽屏（≥ 768px）：三套系统预设并排，不再横滑。
- 状态反馈只有一行（读屏 `role="status"`）：已保存 / 已重命名 / 已更新 / 已删除，或真实错误（满 10 个、名称为空或超长、存储写入失败、本机记录来自更新版本）。

## 3. 三套系统预设

4 列逻辑网格按 2:1 映射到工作台的 2 列主网格：C1–4 = 整行（2 列），C1–2 / C3–4 = 半行（1 列），行数不变（新手 13 行、进阶 14 行、专业 16 行，测试守护）。所有模块都是**已有分析**的卡片（单项或组合卡片），用真实数据计算；预设本身不含任何数字。下表「模块」列里有模块名的卡片，标题按应用时的界面语言写入（与自定义卡片一致，之后切换语言不改写）；写着分析名（如「支出分类」）的卡片用分析自身名称，随界面语言变化。1.17.23 起模块名按[分析卡片命名检查](../../changelog/1.17.md)统一（去掉口语化、写死时间的名称），已应用过预设的工作台保留应用时写入的旧标题，不自动改写。

### 3.0 系统默认工作台 = 新手（1.17.23）

- **没有保存过工作台的账号（包括新账号）显示新手预设**，第一张是「支出分类」。默认工作台不写进存储，每次按当前代码与界面语言生成；对象 ID 固定为 `preset-beginner-*`（应用预设时才换新 ID），这些卡片不算「我的自定义」。
- **旧版默认「日常总览」的一次性迁移**：保存过的工作台若与旧版默认**完全一致**（对象 ID `default-*`、每张卡片与排布都相同，只可能来自旧版「恢复默认」后点「完成」），视为没有自定义，改为 `workspace: null`（跟随系统默认）。服务器侧是 Prisma 迁移 `20261030120000_workbench_legacy_default_to_beginner`（只改这一种行，`version + 1`、旧配置留在 `previous_configuration`，由 `_prisma_migrations` 保证只执行一次，重放不再匹配）；客户端用同一份冻结文档（`@libellum/shared/workbench/legacyDefault`）识别本机记录（备份到 `<键>:legacy-default` 后移除）并在同步比较时按同一口径归一，迁移前后、多设备之间不误报冲突、不把旧版默认装回本机。任何一处不同的布局、我的预设、其它账号一律不动。
- 「恢复默认工作台」换成新手布局；恢复后没再改动就点「完成」，删掉自己的记录跟随系统默认，不再另存一份副本（以后系统默认再调整时不会再次「停在旧默认」）。

## 4. 横向滑动抽屉（Carousel）

原「滑动卡片组」改名「横向滑动抽屉」，仍是 D 的 `carousel` 容器（2–6 张、同一位置左右切换、只切页不聚合、切页不写回布局）。1.17.12 改进：

- **跟手**：手指左右滑动时卡片跟着移动，松手按「快速一甩看方向、慢慢拖过 30% 翻页」吸附到相邻一页或弹回；首尾页再拉有阻力。先判方向：横向位移明显大于纵向才认领，纵向照常滚动页面（`touch-action: pan-y`）。速度按整次触摸平均（复用 `transitionPhysics.flickFromDrag` 与同一个一甩门槛）。拖动中不触发 React 渲染，只写 CSS 变量。`carouselGesture.ts` + 测试。
- **克制的位置指示**：页码点放在卡片标题行右侧（不再另占一行底栏，给图表多 28px），点可直接跳页。
- **桌面**：鼠标悬停时两侧出现上一张 / 下一张；焦点在抽屉里时左右方向键翻页。
- 只渲染当前页与相邻两页。编辑态仍显示为带图标的「横向滑动抽屉 · N 张卡片」结构块；从「布局容器」添加的方式不变。
- 抽屉本身没有名称：D 的容器节点没有标题字段，不改 schema（1.17.12 曾为抽屉准备的名称文案从未在界面使用，1.17.23 删除）。

## 5. 我的预设：保存什么、存在哪

- 保存的是**当前工作台的两份文档快照**（内容文档 + 布局文档，经 D 正式管线校验），即：卡片类型与身份、槽位、指标与展示形式、卡片内容模板、外层位置与尺寸、抽屉结构、每张卡片的时间策略（跟随顶部 / 相对窗口 / 固定区间）；可选再保存当前筛选条件（时间、币种与统计方式、维度筛选，即地址栏参数串，默认不勾选）。**不保存账目、金额或任何计算结果**；应用后按当前账本重新计算。
- 本机、按账号：`libevra.stats-workbench-presets:v1:<账号作用域>`，记录 `{ v: 1, userId, items }`；与工作台同一前缀，「清除本机全部数据」会一并清掉。最多 10 个，名称 1–20 字，说明 ≤ 60 字。跨设备同步属于 S17-W6，本轮没有。
- 保存是副本：之后改工作台**不会**改动已保存的预设；要改只能明确点「更新」（确认后用当前工作台覆盖；原来保存过筛选的，筛选也换成当前的）。
- 删除只删预设本身，不动工作台、卡片定义与账本。
- 读取：每条预设单独过 D 的迁移链与校验；单条损坏或来自更新版本 → 只读保留、只能删除；整份记录来自更新版本 / 损坏 → 本机不写（不覆盖）。
- 应用：对象 ID 全部重新生成（布局对象 ID 永不复用），整份替换为一步撤销；勾选「同时使用保存时的筛选条件」时，生效筛选一起换成保存的那一组。

## 6. 兼容

- 不改 D 的布局 schema、`chart.options.composition` 形状与工作台存储；相对窗口写在 `chart.options.window`（旧版本忽略、按顶部筛选显示）。
- 已保存的工作台不会因升级被改写：预设只在用户确认应用、再点「完成」时才写工作台。旧单项卡片、组合卡片、已有布局照常读写。
