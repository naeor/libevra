# 账本权限分级 · 设计决定（1.19.56）

> 最后修改：2026-11-10 14:59（UTC+08:00）

所有者 2026-11-10 决定，取代原来“可编辑 / 仅查看”两档。本页是账本成员权限的现行规则；系统管理员（后台）见[管理员与权限边界](../product/管理员与权限边界-设计决定.md)，两者无关。

## 1. 角色

每本账有**一位管理员**，其他成员从低到高分三档：**只读**、**记账**、**编辑全部**。

| 操作 | 只读 | 记账 | 编辑全部 | 管理员 |
|---|---|---|---|---|
| 查看账目、分析、编辑历史，发留言 | ✓ | ✓ | ✓ | ✓ |
| 导出（与查看同一权限） | ✓ | ✓ | ✓ | ✓ |
| 记账：手动、文字、语音、拍照，账单导入（导入是一种记账方式） | | ✓ | ✓ | ✓ |
| 修改 / 删除 / 恢复**自己记的**账目，给它们加附件 | | ✓ | ✓ | ✓ |
| 修改 / 删除 / 恢复**别人记的**账目 | | | ✓ | ✓ |
| **新增**分类、标签、支付方式 | | ✓ | ✓ | ✓ |
| **修改**（改名、归档、删除、调整层级）分类、标签、支付方式；改账本名 | | | ✓ | ✓ |
| 邀请他人（站内邀请、分享链接），权限不高于自己 | ✓ | ✓ | ✓ | ✓ |
| 修改其他成员的权限、移出成员、设置“只有管理员能邀请” | | | | ✓ |

- **自己记的账目** = 账目的创建者（`Transaction.userId`，随账目下发为 `recorderId`）。别人修改不改变它，与“修改了你创建的账目”提醒同一个创建者。
- **管理员** = `Book.managedByUserId`（S13-H 的管理权位置），默认是创建者；没有记录时退回创建者，只认当前仍是成员的人。管理员本人固定为“编辑全部”，不能被改权限、不能被移出（原来保护创建者的规则改为保护管理员）。管理员退出时仍按 S13-H 交给最早加入的“编辑全部”成员。
- **邀请**：默认所有成员都能邀请，被邀请的人权限不能高于邀请人（只读只能邀请只读）。管理员可打开“只有管理员能邀请”（`Book.inviteAdminOnly`），打开后其他成员不能再邀请。邀请在**被接受时**再核对一次邀请人的授权：邀请人已退出、被降到低于邀请的权限，或“只有管理员能邀请”已打开而他不是管理员，未接受的站内邀请与分享链接都随之失效（分享链接答 `share_link_invalid`，站内邀请答 `invite_no_longer_valid`）。
- **分享链接的撤销**：生成它的人、管理员与“编辑全部”的成员可以撤销。
- **附件**：记账成员只能给自己记的账目添加附件，只能删除 / 恢复自己上传的附件；上传者已不在账本里时，“编辑全部”的成员可以处理。
- **冲突“以服务器为准”**：记账成员只处理自己记的账目上的冲突。
- **迁移**：现有“可编辑”成员成为“编辑全部”，“仅查看”成员成为“只读”，不改任何既有行；新增枚举值 `recorder` 与 `books.invite_admin_only`（迁移 `20261110120000_ledger_role_tiers`，共 68 项）。

## 2. 实现位置

- 服务器（唯一的判断）：`apps/api/src/ledger/access.ts`（`ROLE_RANK`、`canRecord` / `canEditAll` / `canEditEntry`、`requireBookForRecord`、`requireEntryEditable`、`requireEditAll`、`bookAdminId` / `requireBookAdmin`、`inviteProblem` / `requireInvite`）；`app.ts` 记账强度的守卫 `createRequireBook(..., { write: "record" })`；路由里的逐笔判断在 `routes/transactions.ts`、`routes/classification.ts`、`routes/attachments.ts`、`routes/share.ts`、`routes/books.ts`（含 `PATCH /books/invite-policy`）、`collab/members.ts`、`collab/respond.ts`、`collab/share.ts`。
- 界面（只决定显示哪些按钮）：`apps/web/src/lib/permissions.ts`；成员管理 `MemberList`（管理员给其他成员选择三档、“只有管理员能邀请他人”开关）、邀请 `LedgerInvitePage` 与分享 `ShareSection`（只列出不高于自己的权限）、账目详情（不能改的账目不显示修改 / 删除，并说明是谁记的）、批量操作（别人记的账目逐笔报“只能修改自己记的账目”）、分类 / 标签 / 支付方式管理（记账成员只显示新增）。
- 错误码：`book_read_only`（只读）、`book_edit_all_required`、`entry_not_yours`、`book_admin_required`、`admin_role_fixed`、`admin_cannot_be_removed`、`invite_role_too_high`、`invite_admin_only`、`invite_not_allowed`、`invite_no_longer_valid`、`share_link_not_yours`。
