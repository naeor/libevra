## 1. 结论摘要

- 自定义单指标卡片可选指标 **26 → 50 项**（A 26 + S17-B 24）；展示方式按指标给出兼容的 **15 个图表家族**（数字 / 极值 / 环形 / 排行条 / 表格 / 折线 / 面积 / 柱状 / 流向柱 / 流向线 / 堆叠 / 份额带 / 累计 / 日历热力 / 对比）。
- 本轮修复三类缺口：
  1. **已实现但未接入**：S17-B 第二批 12 项分析（I13、I14、A02、A03、A04、A05、A12、A13、A14、A18、A19、A20）此前有派生计算与图表组件，但未登记卡片、未进入模拟与自定义卡；本轮全部接入 `CARD_TYPES` 与 `AdvancedCardView`。
  2. **图表展示单一**：自定义卡「展示方式」此前对 A 卡只暴露 `number` / `extreme`，B 卡只有少数 family；本轮按能力目录给出每项兼容家族，卡片可任选兼容项。
  3. **缺数据与缺汇率的静默风险**：区间内无账目、样本不足、综合折算一笔都没折出时，新卡一律文字说明，不画 0、不出现「没有记录」误述。
- 84 项规划能力中：**50 项已接入可用**（26 A + 24 B）；**34 项 C 未接入**（计算与草案适配器已有，缺卡片层与部分专用图表组件）。见 §2。

## 3. 图表家族与可用指标

`apps/web/src/statsWorkbench/catalog.ts` 的 `ChartFamily` 共 15 种，`FORMAL_CHART_FAMILIES` 映射到正式编号：

| 展示 | family | 正式编号 | 典型指标 |
|---|---|---|---|
| 数值卡 | `number` | CF-A01 | A12 平均每笔与频次、A02/A03/A05 增长率、A20 收入稳定性、B 类 scalar |
| 极值卡 | `extreme` | CF-A02 | 最大单笔、最大分类等 record-extreme |
| 环形图 | `donut` | CF-A03 | 分类占比、收支构成 |
| 排行条 | `ranking` | CF-A04 | 分类排行、收入来源构成 |
| 表格 | `table` | CF-A07 | 明细表、原币构成 |
| 折线 | `line` | CF-B01 | 每日支出趋势、移动平均、分类历史趋势、季节性比较、异常标记 |
| 面积 | `area` | CF-B02 | 支出趋势（面积）、每日支出波动 |
| 柱状 | `bar` | CF-B03 | 收支趋势（柱状）、星期消费规律、多个月份比较 |
| 流向柱 / 流向线 | `flow-bars` / `flow-lines` | CF-B04 / CF-B01 | 收支流向 |
| 堆叠 | `stacked` | CF-B05 | 分类堆叠 |
| 份额带 | `share-bands` | CF-B06 | 分类份额随时间 |
| 累计 | `cumulative` | CF-B11 | 累计支出 |
| 日历热力 | `heatmap` | CF-B08 | 日历热力 |
| 对比 | `comparison` | CF-B10 | 上期/同比/多月比较 |

每张卡片的兼容 family 由 `CardType.families` 决定；自定义卡与工作台卡片都只允许在 `families` 内选择（`familyOf` 对不兼容值回退第一项）。

## 4. 自定义卡片接入路径（不绕过 G-12a）

- `apps/web/src/statsWorkbench/customCards.ts`：
  - A 26 项：走 `validateAnalysisParams({analysisId, params:{}}).status === "valid"`（G-12a 正式白名单）。
  - B/legacy 24 项：`LEGACY_CUSTOMIZABLE_IDS` 显式集合（无布局参数、无 `params` 语义），只作为「单指标 + 时间政策」的只读配置，不伪造协议登记。
  - `CUSTOM_CARD_TYPES` = 两者并集，现 **50 项**。
- `createCustomCard` 生成的卡片只含 `analysis{analysisId, params:{}}`、`chart.chartFamily`、`title{kind:"custom",text}`、`rangePolicy`（`inherit` 或 `pinned` + 日期），**不写金额、汇率、账本身份**。
- 弹窗 UI 结构（`Sheets.tsx` 的 `CustomCardSheet`）本轮**不改**：指标下拉仍渲染 `CUSTOM_CARD_TYPES`，展示方式 chips 仍渲染所选指标的 `families`；下一轮由所有者草图决定分组与布局。

## 5. 本轮修复内容（按文件）

- `catalog.ts`：`CARD_TYPES` 38 → 50，新增 12 个 S17-B 类型与 family/尺寸；沿用 `S21/S22/S23` 与 `NUMBER_SIZES/CHART_SIZES`。
- `fxPolicy.ts`：新增 12 条 `FX_CARD_POLICIES`（`FX_CARD_POLICIES` 与 `CARD_TYPES` 一一对应，`fxCards.test.tsx` 守护）。series 类按缺汇率方向；比较/数字类按 `undetermined` 不宣称完整。
- `advancedCards.tsx`（新增，约 300 行）：`ADVANCED_CARD_IDS` + `AdvancedCardView`；读 `scope.entries`（W5 筛选后、综合折算后的目标币种账目）与卡片范围，调用 `analysisData.ts` 的已有派生函数，把结果交给现成图表组件；不重算金额/汇率。空数据、样本不足、缺汇率分别给文字说明；`combined && entries.length===0 && missingCount>0` 时显示 `states.fxNothingKnown`（不是「没有记录」）。
- `cards.tsx`：`TimeView` 内新增 `ADVANCED_CARD_IDS` 分发到 `AdvancedCardView` 并传 `fx` 上下文（原币与综合折算两条路径共用）。
- `customCards.ts`：新增 `LEGACY_CUSTOMIZABLE_IDS` 并调整 `CUSTOM_CARD_TYPES`（26→50）。
- i18n `zh-CN/en-US`：`cards` 新增 12 条 title/desc；新增 `advanced` 段（星期前缀、均值、波动带、原始/平均、月份标签、异常标签、稳定/样本不足、无比较基数、支出/收入等）。
- 修复的实现问题：
  1. `derivePeriodComparison` 的 A02/A03 需要 `current: analysisSpan(...)`（`month-over-month` / `year-over-year`），A05（`month-to-date`）可省略；此前漏传导致 `RangeError: current span is required`；
  2. `MonthBar` 没有 `amountMinor`，用 `valueMinor` 字符串；
  3. `Ratio` 的字段是 `bigint`，`ratioPercentText` 需要 `BigInt(...)`；
  4. 空月份键必须用 `YYYY-MM`（`deriveMultiMonthComparison` 的 `isMonthKey`），不是 `YYYY-MM-01`；
  5. 区间内一笔账目都没有时预先返回文字，不给 0 折线。
