## 公告正文（中文）

**标题**：多层级分类、工作台同步与吸顶栏

**摘要**：分类升级为可嵌套的多层级结构，并新增层级结构与层级桑基分析；工作台布局与个人预设开始按账号同步，支持配置文件导入导出；分析、账本、我的页共用可收缩吸顶栏，底部选中提示与主题按钮一并修正。

### 新增功能

1. 分类支持多层级：可以在分类的「更多」菜单里编辑、新建子分类或移动整棵子树，最多 64 层；旧分类与交易的 ID 保持不变，同级不允许重名、不同分支可以有同名分类。
2. 新增「分类层级结构」（P05）与「分类层级桑基图」（P07）两个分析卡片，正式可选指标增加到 83 项。
3. 工作台布局与个人预设按账号同步；首次同步、离线与冲突都有明确选择，不会静默覆盖。
4. 工作台与预设可以导出为 JSON 文件，也可以从文件导入；导入前会逐项校验并预览，适合备份或带到另一台设备。
5. 账号数据导出包含个人工作台配置；注销账号时会清理本机与云端的同步数据。

### 调整及优化

1. 分析、账本、我的三个页面共用可收缩吸顶栏，向下滚动时跟随手势收缩，返回顶部自动展开。
2. 分析页编辑体验调整：编辑工具栏移到屏幕下方抽屉，统计控制区收成一行，常用操作更顺手。
3. 工作台布局预设上线：系统预设与「我的预设」，可预览后再应用。
4. 自定义卡片可选指标从 50 项扩展到 81 项（正式指标合计 83 项），底部 Tab 选中的圆形浅色底与主题细节同步修正。

### 问题修复

1. 修复分析页底部「分析」Tab 不显示选中态的问题。
2. 修复浅色主题下明细页顶部圆形操作按钮失去背景的问题。
3. 修复多层级分类的边界问题与层级桑基图的守恒问题，确保父分类聚合与账目金额一致。
4. 修复同步冲突时可能静默覆盖的问题，现在会保留恢复副本并让用户选择。
5. 修复注销账号后本机残留同步数据的问题。
6. 导入 CSV 时，分类改为同时按收支方向与分类路径匹配；没有「类型」列的旧文件如果分类与金额符号推断出的方向不一致，会明确报错并指出行号，不再导入成方向错位的账目。

### 注意事项

1. 本次升级会自动执行数据库迁移（62、63），无需手动操作；迁移只向前，不影响已有账目分类。
2. 如果之后需要把服务退回 1.17.11，已创建的多层级分类与工作台配置数据会保留；旧版本界面不展示层级与同步能力，账目与账本不受影响。
3. 分类层级最多支持 64 层；旧客户端（1.17.11）导入新导出文件时会丢失层级信息，跨版本导入会降级为根分类。
4. 工作台同步有频率限制，高频拖动时可能短暂重试；本机数据不会丢。
5. iPhone Safari / PWA 真机尚未验收，移动端触摸体验可能仍有差异。
6. 升级期间服务会短暂重启，通常几秒内恢复。
