## 四、生产发布步骤

1. 解锁 SSH：`Start-Service ssh-agent` 已启动；`ssh-add "$env:USERPROFILE\.ssh\libevra_server"`（输入私钥口令），`ssh libevra "echo ok"` 验证。
2. `scp %TEMP%\libevra-1.16.19-release.tar.gz ubuntu@43.161.227.152:/tmp/`，服务器校验 SHA-256。
3. 快照现网代码 `sudo cp -a /srv/libevra /srv/libevra.pre-1.16.19-20261026`，建证据目录 `/srv/libevra-release-1.16.19-20261026/`。
4. `cd /srv/libevra && ./deploy/backup.sh --keep 7`，确认 `restoreOk: true`。
5. 记录回滚镜像（当前 1.16.18 的 api/web image id），打 tag `rollback-1.16.18-20261026`。
6. 解包归档到 `/srv/libevra`（tar 1604 条目），确认 `deploy/docker-compose.release-1.16.19.yml` 与 `version.ts` = 1.16.19。
7. `sudo docker compose -f deploy/docker-compose.prod.yml -f deploy/docker-compose.release-1.16.19.yml build api web`，确认镜像 tag。
8. `... up --no-deps migrate`（预期 58 migrations、无新迁移、exit 0）。
9. `... up -d --no-deps api web`；等待健康检查。
10. 检查 `https://libevra.com/api/v1/health`（`1.16.19`/`database up`）、`/healthz`、首页 200、资源哈希更新、Web 文案 chunk 含去句号的题注且不含带句号版本；更新 `/srv/libevra/.last-deployed`、`.deployed-commit`（`5ac553b`）。
11. 发布后把 `main` fast-forward 到发布 commit，并更新 `docs/archive/releases/1.16.19-头像题注去句号-发布记录-20261026.md`、STATUS/索引。
