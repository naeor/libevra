## 1. 结论

- 自定义卡片升级为**组合卡片**：一张工作台卡片可放 1–8 个数字 / 图表槽位（数字 ≤ 6、图表 ≤ 4），按卡片内容模板 T1–T8 排布，在工作台里仍是**一张**卡片（一个 objectId），统一拖动、缩放、撤销与保存。
- 新建与编辑共用一个面板：五类目录（数字指标 / 趋势与时间 / 构成与排行 / 分布与关系 / 高级与综合）+ 搜索、多选、每项展示形式、自动推荐模板、真实像素实时预览与尺寸检查，确认后才加入工作台。

验收中发现并当场修正的问题：

1. **预览与卡片里的折线被截断**（所有者截图反馈）：根因是旧收支折线组件固定 190px 高，与格子高度无关；预览与工作台使用同一组件、同一像素，所以两边都截断。修正为图表按正文高度绘制，并对 81 项指标的全部展示形式做组合小格 / 单项卡片的全量测量（首轮 42 + 37 处超出 → 0），详见 [changelog 1.17.10](../../changelog/1.17.md)。
2. **右列 1×1 组合卡片加内容后保存失败**：原锚点放不下 2×1 → 改为同一行行首插入并顺延，仍是一步撤销；编辑器在保存失败时给出说明。
3. **桌面宽度下「¥14,222.41」显示成「¥14,222....」**：金额缩字号的判断留了 1px 余量 → 改为严格判断，并加一级 sm。320 / 390 宽各数字模板与尺寸下数字列最窄约 90px，可完整显示到 ¥123,456.78。

验收过程中创建的 5 张自定义卡片留在所有者本机工作台（浏览器本机存储，不在数据库），可在「编辑工作台」里删除。
