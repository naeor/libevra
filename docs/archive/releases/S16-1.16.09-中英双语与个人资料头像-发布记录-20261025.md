## 1. 发布范围

- **中英双语界面（S16-G）**：3,154 条界面文案 × 2 种语言；268 个服务器错误码；209 条 shared 原文（139 条精确匹配 + 70 条模式）；15 篇更新/重大公告英文。入口在「设置 → 显示与数据 → 语言」与登录/注册/找回页右上角；默认跟随浏览器语言，选择保存在当前设备；语言只影响展示，不修改用户数据。
- **个人资料与头像**：`/profile` 默认只读、`?edit=1` 编辑；一次保存一个字段、旧值原子更新，冲突返回 409 并保留输入；八款可选头像（基础系列初绽、新芽、太阳、弦月、晨星、海浪、咖啡 + 特典系列倒悬），用于「我的」、资料页与协作成员；历史头像 ID 继续按旧 SVG 渲染。
- **1.16.08 之后的修复**：英文界面排版与日期格式、按钮/长单词溢出；服务器错误按错误码本地化；编辑历史服务器事件值英文显示；校验失败显示具体原因；更新中心与 1.16.08 公告对齐；冲突页币种不再写死人民币；文档编号 S16-C → S16-G 订正。
- **整合来源**：本地集成分支 `a1a2a91`（父提交含主工作区资料/头像快照 `b9c8946`、i18n 验收修复 `b8c806d`）；六个 worktree 的 HEAD 与 1,844 份改动已备份到 `_backups/integration/20261025-074012` 并校验哈希，旧工作区不删除。

## 3. 构建产物与分包（2026-10-25）

本轮把构建产物拆成「入口 + 语言资源 + vendor」三组，入口不再包含语言包与库代码：

| 产物 | 大小 | gzip |
|---|---|---|
| `assets/index-*.js`（应用入口） | 893.68 kB | 230.66 kB |
| `assets/i18n-resources-*.js`（中英语言包，启动即预载） | 351.32 kB | 110.71 kB |
| `assets/vendor-react-*.js` | 210.61 kB | 65.68 kB |
| `assets/vendor-*.js`（共享运行时） | 104.51 kB | 30.67 kB |
| `assets/vendor-i18n-*.js` | 55.50 kB | 18.28 kB |
| `assets/vendor-query-*.js` / `vendor-router-*.js` | 41.04 / 38.58 kB | 12.13 / 13.89 kB |
| `assets/index-*.css` | 86.11 kB | 16.19 kB |

拆分前入口为单文件 `1,696.88 kB`（gzip 480.96 kB）；拆分后入口 gzip 约 231 kB，首次加载总 JS gzip 与拆分前基本持平（约 482 kB）。**没有做按语言或按路由的懒加载**：离线优先的 PWA 不能保证「第一次离线打开英文界面」时语言 chunk 已缓存，因此语言包仍随首屏预载，由 Service Worker 首次使用时缓存；vendor 分包用于提升回访缓存命中。

- **真机 / Safari**：iPhone Safari 安全区、软键盘、手势与中英切换未验收；1.16.08 也仍未做真机复验。
- **英文文案**：已有 AI 起草的全量审校初稿（[S16-G 英文审校与默认账本名](S16-G-英文审校与默认账本名-20261025.md)），**不等同于母语审校**；品牌标语英文、语音仅普通话说明等仍待所有者决定。默认账本名已按请求语言创建（中文 `我的账本` / 英文 `My Ledger`），不再列为待定项。
- **法律文本**：正文目前仍以中文版本为准，英文译本审核中，不能宣称英文版具有法律效力。
- **S15-D**：离线/同步真机综合验收仍独立未完成；不得把本次发布当作 S16 整体完成。
- **对比度债务**：森林绿浅色主按钮白字约 3.37:1、焦点环约 1.08:1 等历史债务仍登记在案（S16-C-06），未在本轮修复。
