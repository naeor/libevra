> 状态：**已发布生产**（2026-10-26 10:21 CST；部署 commit `44c70f21ff346ef3268b65877992f32ca323beb0`）。版本 `1.16.18`；上一版 `1.16.16`（`fd316e6`，57 迁移）；**本次新增第 58 号迁移**（57 → 58）。
> 目标：把本地已验收的 1.16.17（头像选择页 UI 优化）与 1.16.18（品牌主标语、留言引用、留言顺序）一并发布到生产。

## 1. 范围

- 品牌主标语：中文「记账，按你的方式」/ 英文 “Bookkeeping, your way.”（`books.space.slogan`、`settings.preview.slogan` 中英各一处）。
- 共享账本留言引用（可选）：账目 / 修改历史两类引用；入口 A（记账成功页「就这笔留言」胶囊 + 就地留言面板）、入口 B（留言输入框旁引用按钮 + 两栏选择面板）；引用卡片、取消引用、目标删除/无权降级、跨设备读取；服务端快照由服务端重读写入，权限沿用账本成员身份。
- 留言顺序与默认位置：最新一条在最下面，进入留言页默认停在最下方；协作页卡片显示最新两条。
- 头像选择页（1.16.17）：预览文字与头像统一居中、题注限宽换行、特典按解锁状态动态排序、未解锁头像降饱和 + 小锁、锁定提示「尚未解锁，暂不可使用」、禁用保存按钮对比度、底部保存栏安全区。
- 升级兼容修复：旧版本缓存的留言缺少 `reference` 字段时不再打掉协作页/留言页（persister `buster` v2 + `messageReference()` 归一化）。
- 应用内公告 1.16.18（新增功能 / 调整及优化 / 问题修复 / 注意事项，中英双语）。
- 不包含：S16-D 汇率、补领 UI、非必要外观功能（已延后）。

## 5. 发布步骤（生产）

1. 推送 `release/s16-1.16.05` 与 `main`（owner 已当次批准）。
2. 生成源码归档（`git archive HEAD | gzip`，附 SHA-256），上传到 `/srv/libevra-1.16.18-release.tar.gz`，服务器复核 SHA-256。
3. 快照当前源码 `/srv/libevra.pre-1.16.18-20261026`。
4. 生产备份：`./backup.sh --keep 7`，核对 `last-local.json` 的 `restoreOk=true`。
5. 记录回滚镜像：把当前 `deploy-api`/`deploy-web` 容器镜像分别打 tag `libevra-api:rollback-1.16.16-20261026`、`libevra-web:rollback-1.16.16-20261026`。
6. 解包归档到 `/srv/libevra`（保留 `deploy/.env`），构建 `libevra-rc-api/web:1.16.18-20261026`。
7. 运行 `migrate` 服务（应用 58），确认 `_prisma_migrations` = 58。
8. `docker compose -f docker-compose.prod.yml -f docker-compose.release-1.16.18.yml up -d --no-deps migrate api web`。
9. 记录 `.last-deployed=1.16.18`、`.deployed-commit=<commit>`。
