本地构建标记为 `1.16.04`，用于区分候选；生产没有更新，也未联网复查。未修改数据库 schema、迁移、业务数据、金额或财务规则。

预览通过独立 Vite 中间件提供**虚构的登录会话和样例 API**。使用完整 App、原 AuthProvider、RequireAuth、ConsentGate、原查询与币种保存 hook，没有替换页面的权限逻辑。样例会话呈现管理员入口仅供布局验证，不授予任何真实账号权限。每个 `/api` 请求都在代理前处理或拒绝，不连真实开发 API、数据库或生产。

唯一允许的样例写入是原 `PATCH /auth/me` 路径的默认币种，写到本工作区 `preview-artifacts/fixture-state.json`。已经执行 CNY → USD，刷新/重入后仍选 USD，再恢复 CNY；没有改真实账号。请求日志只记录 method/route，不记录 Cookie、密码或用户数据。真实登录/会话服务端认证、真实数据库持久化未在本轮重验。

## 5. 未覆盖与待确认

1. **绿色深色 R1 仍未通过所有者视觉验收**；本轮只是允许在实际页面切换试用。新设置分组、外观控件、浅深色整体效果仍待所有者确认。
2. Safari/iOS、OLED 黑位、安全区、真实系统外观设置切换、慢网冷启动逐帧闪烁未做真机验收。系统双向变化由注入的 MediaQuery 事件测试，不能写成已操作真实系统设置。
3. 任意用户标签自动前景、浅色全局旧焦点环/旧白字债务、图表稳定分类映射、全站状态回归仍是后续项。B1 的标签 MutationObserver 原型没有带入应用。
4. 六套新色盘、账号级主题同步、PWA manifest、部署均不在本轮。只开放已有绿色映射。
5. 本轮没有改动币种的后端实现；实际生产账号的 PATCH 持久化未重验，证据仅覆盖原前端路径到隔离样例 API 的往返。

这份记录只陈述本地实现和验证范围，不将模拟登录、测试通过或 R1 本地试用视为正式发布或视觉批准。
