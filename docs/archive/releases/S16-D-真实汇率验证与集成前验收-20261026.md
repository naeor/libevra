## 3. 兼容性、覆盖和许可

[Frankfurter 官方 v2 文档](https://frankfurter.dev/)的 provider 路径、`from/to/base/quotes` 参数及逐条 `date/base/quote/rate` 列表均已实测。v1 使用另一种对象协议。仅查询固定 ECB 来源，不自动使用 blended、其它提供方或其它日期来拼接缺失币种。

本次默认混合返回 CNY `7.8196`，直接 ECB 与官方 CSV 是 `7.8212`；混合展开内容中标为 ECB 的贡献值是 `7.8154`。本轮无法判定其内部聚合/历史版本差异的具体原因，不能把它称为本地计算错误，也不能声称已解释清楚。官方原始值支持继续采用直接 ECB 路径。

[许可页面](https://frankfurter.dev/license/)区分 MIT 软件与提供方数据；免费访问或软件开源不代替上游数据权利。[ECB 条款](https://www.ecb.europa.eu/services/using-our-site/disclaimer/html/index.en.html)要求准确呈现、注明来源、说明派生计算等条件；付费文档还需告知原信息免费可得。数据允许依条款缓存/使用，正式 UI/导出必须保留来源与参考性质；不是成交或银行结算汇率。ECB 工作日发布，休市/缺币种是正常覆盖边界。没有购买服务或认定免费代表无限并发。

## 4. 精度与金额验证

使用独立 Python Decimal（精度 80 位、ROUND_HALF_UP）从响应原始十进制字面量生成 [108 组参照](../../../apps/api/src/fx/fixtures/live-20261026/oracle.json)，覆盖三个日期样本、六币种全部 36 个方向，包含 JPY 0 位、同币种、早期 CNY 缺失。BigInt 引擎逐项一致，没有“看起来差不多”的容差放行。

Node JSON source reviver 保留上游数字原文，没有先将汇率转成 double。2024-05-15 的 USD→CNY 精确桥接为 `7.8212 / 1.0832 = 7.2204579025…`，直接 USD 基准 API 报 `7.2205`。差值 `0.0000420974…` 小于该报价半末位 `0.00005`，是上游有限小数舍入。两者不能作为无限精度相同数；本系统始终从原 EUR 参考值计算，不再截断交叉汇率。

100 USD 按此规则显示 722.05 CNY；JPY 按自身零小数位处理。无法折算的早期 CNY 明确返回缺失，综合统计只含成功小计、定位信息和 `complete=false`，百分比分母为 null。真实样本在线/离线的金额一致；待复核状态与完整性分别表达。

## 5. 修复内容

- 适配器忽略区间起点之前的合法旧锚点，但不扩大七日窗口；未来数据、非法币种/数值和冲突仍拒绝。只有旧锚点时返回缺失。
- 取消“下载超过 30 天就失效”的默认做法；新增独立 review 元数据和汇总待复核计数。保留正值/日期/来源/修订校验，未批准的数据不会因此自动变成可靠值。
- 增加分批可取消聚合，逐笔金额、分类/月桶、原币汇总、缺项和警告与同步接口完全一致；作用域或请求代次变化会拒绝旧响应，clear 也会使在途结果失效。
- 公共 kv 缓存增加 Web Locks 写锁（支持时）、有界等待/读写、损坏条目恢复和写失败明确状态，避免 IndexedDB 永不返回拖住折算。迟到写仍按原队列顺序结束，不触碰账目数据。
- 增加显式联网采集器、真实响应回归、独立 Decimal 参照生成器、主线兼容审查工具。正常测试不联网。

## 6. 参数建议（工程建议，未作为正式产品规则批准）

| 参数 | 建议及依据 |
|---|---|
| 历史回退 | 暂保留七日硬上限，允许配置为 0–7 天。真实周末回退 2 日，圣诞回退 1 日；不足以证明七日适用于所有停市，超窗继续明确缺失，不延长或猜测 |
| 近期复核 | 交易日期最近七天内，建议 24 小时；有利于补上尚未发布日和可能修订，不做后台无限扫历史 |
| 较早历史 | 建议每 30 天按需核对一次；逾期只标 `needsReview`。可靠历史观察离线继续可用，不把缓存新鲜度当财务有效期 |
| 异常跳变 | 保留可配置 2 倍作为粗防线，不宣称能识别全部异常。采样窗口内相邻值最大倍数约 1.009716，不足以校准正式统计阈值；无比较基线时不能发现所有异常，告警/人工复核仍待运维设计 |

已知修订通过内容版本与存储冲突规则处理，结果缓存随版本变化失效。核对失败仍返回明确错误，未悄悄切换来源。上述复核配置不是到期自动删除历史数据的政策。
