## 4. 本轮实现（代码）

1. `apps/web/src/statsWorkbench/filters.ts`：`WorkbenchFilters` 增加 `categoryIds` / `paymentMethodIds` / `tagIds`；URL 参数 `category` / `payment` / `tag`；`null` = 不限、显式空值 = 空集；`normalizeIds` 去重、长度上限 64、最多 50 个（G-12a）。新增 `filterIds`、`matchesWorkbenchFilters`、`filterWorkbenchEntries`、`filterKey`、`toggleFilterId`、`hasDimensionFilters`。
2. `scope.tsx`：`unfilteredEntries` 与 `entries` 分离；`useWorkbenchScope` 暴露过滤谓词 `filterWorkbenchEntries` 与 `filterKey`；`ledgerCurrencies` 取未筛选账目（币种候选不随筛选收窄）。
3. `lib/fxView.ts`：`useFxRange` 支持 `filter` / `filterKey`，**在进入逐笔折算前过滤**；缺汇率影响范围与 `sourceEntries` 均随筛选变化。
4. `cards.tsx`：`RangeCardBody` 对当前区间与上期比较都应用过滤；A 层调用传入真实 `ResolvedFilters`；`results.ts` 的 `metadata().source.filters` 回写真实条件（不再硬编码 null）。
5. `compute.ts`：`analysisEntries` 增加由 `tags[]` 派生的 `tagIds`；`agentAResult` / `fxAgentAResult` 支持可选 `filters`（协议 `null` 视为「不限」，不当作空集）。
6. `FilterPanel.tsx`：新增分类 / 支付方式 / 标签三组多选 chips，每组有「全部」，空集时显示红色提示「没有选择任何项：这个维度下不会显示任何账目。」；沿用草稿 / 应用 / 撤销 / 收起语义，摘要行追加维度计数。
7. i18n（zh/en）：`filter.category`、`filter.paymentMethod`、`filter.tag`、`filter.all`、`filter.emptySelection`、`summary.*Count` 等镜像键。

## 5. 语义与正确性要点

- 维间 AND、维内 IN(OR)；标签「任一命中」（`entry.tags` 与所选集合有交集），不重复计数。
- 分类 id 一定存在（系统分类也带 categoryId）；支付方式可为 null，null 不匹配任何所选支付方式。
- 空集与「不限」严格区分：`null` ≠ `[]`。URL 写回时空集写成 `category=`，从而刷新后仍是空集而不是回到不限。
- 综合折算顺序为「先筛后折」：筛选作用于进入 `projectFx` 的 `sourceEntries`，再用逐笔历史汇率折算；不改原交易金额、保持 minor unit/bigint 精度。
- 账本权限不因筛选变化；筛选条件只描述「看哪一部分账目」，不写回任何金额。
- 筛选唯一权威仍是 **URL**；布局文档、编辑会话不受筛选影响。

## 7. 综合折算与完整性

- `fxProjection` 输入过滤后的 `sourceEntries`；`converted` / `all` / `missing` / `missingByScope` 随筛选变化。筛选后只含 1 笔缺汇率时，完整性提示基于 1 笔而不是整账本。
- 1.17.6 的离线读取上限（单月约 50,000 笔、不静默截断）保持不变；`sourceComplete=false` 仍经既有链路传递到工作台「数据不完整」提示。
- 逐笔折算 50,000 条上限（`FX_MAX_DETAIL_ENTRIES`）保持原语义：超限时明确提示 `entry-limit`，不截断、不伪造完整。
