## 独立回滚

- 应用：使用原 `docker-compose.release-1.17.15.yml`，只 `up -d --no-deps api web`；不运行旧迁移、不删除卷。恢复版本/提交标记后检查 API、Web 与数据库健康。原镜像和源码归档保留。
- 运维：安装前保存带时间戳的原脚本、文件清单、SHA-256、属主与模式；在无正在运行备份且持有内部锁的窗口切换完整脚本集合。失败则恢复旧文件及其原权限，新增 helper 不被旧脚本引用。
- 不改 timer 时间、不重新引入外层 flock。仅替换 Shell 文件不需要 systemd daemon-reload；实际 unit 若有必要变更必须另行记录。
- COS 下载 / 解密 / 内容级恢复演练需要独立恢复身份，本轮不获取该身份；每日远端元数据校验不等同于远端内容恢复通过。
