# archive/releases · 发布与验收记录（历史，只读）

> 这里放每个版本的**生产发布记录**、**发布准备**（2026-10-29 起不再单独放在 `ops/`）和阶段 / 版本的**本地验收记录**。
> 它们是“当时发生了什么”的证据，**不是当前状态**（当前状态只看 [STATUS](../../STATUS.md)）。AI 默认不读本目录；需要某个版本的证据时按文件名定向查。

## 命名

- 生产发布：`<版本>-<主题>-生产发布-<日期>.md`（2026-10-29 起，发布准备、执行与回滚写在**同一份**里）
- 历史发布准备：`<版本>-发布准备.md`（1.16.09–1.17.15，原在 `ops/`，2026-10-29 移入，正文未改）
- 本地验收：只在阶段收尾或所有者要求时写；普通本地版本只写 changelog 条目
