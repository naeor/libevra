## 1. 结论

- 所有者在 **蜜金黄** 主题下反馈的两个问题均已修复：明细页顶部三枚圆形操作按钮恢复清晰容器（奶油色底 + 深色图标）；分析页底部「分析」Tab 恢复当前主题选中色。
- 顺带检查并修复了全部七套色盘 × 浅 / 深模式在明细、分析、账本、我的四页的页头按钮、筛选 / 编辑圆钮与底部 Tab 选中态；无 4.5:1 以下对比度。
- 底部 Tab 选中项新增极浅主题色**圆形底**：圆心取图标+文字整块的视觉中心（不是图标中心或文字中心），直径刚好罩住内容且不碰底栏上下边；未选中项保持 muted，导航结构与文案不变。
- 仅本地修改与验收，未部署生产、未改变版本号（1.17.12 仍为本地未发布）。

## 2. 根因与修复

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 蜜金黄明细页顶部三枚圆形按钮只剩图标 | `index.css` 的浅色黄 / 红 / 紫共用规则把页头内所有 `bg-on-brand/*` 背景改成 `transparent`；黄盘 `on-brand` 是深色，圆形按钮因此失去容器 | 黄盘单独改用 `brand-soft` 奶油底（hover / active 向 `brand` 混合加深）；红 / 紫移出透明规则，恢复默认白色 20% 半透明圆底 |
| 分析页底部「分析」Tab 不显示选中色 | `StatsPage` 传给 `BottomNav` 的 `active` 是 `stats`（无前导斜杠），导航用 `tab.to === active` 与 `/stats` 比较恒不命中 | `StatsPage` 改为传 `/stats`，与明细 `/`、记账 `/add`、账本 `/ledger`、我的 `/me` 一致 |
| 底部 Tab 选中与未选中区分偏弱 | 选中态仅文字颜色变化（`text-brand-dark` / `text-muted`） | 选中项在图标+文字后加 `bg-brand-soft` 的浅色**圆形底**（圆心取两者整块视觉中心，直径 52px 罩住 24×43 内容，上下不碰底栏）；未选中仍为 muted |
| 森林绿浅色主题选中文字对比度不足 | `brand-dark`（#447d63）在 `brand-soft`（#edf5f0）上只有 4.34:1，其余非绿色盘均 ≥4.5:1 | 只对浅色森林绿的选中 Tab 文字补一级更深绿（#3f745b → 4.90:1），写入 `index.css` 的独立钩子规则；不修改主题 Token，不新增色盘变量 |
