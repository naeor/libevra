## 5. 行为与浅色影响

- 外观页真实点击浅色后立即变色；刷新仍为浅色，再选深色、返回显示与数据并跨页，深色保持。`theme.ts` 和 prepaint 与基线文件一致；首屏脚本 12 种模式 / 系统 / 可用与不可用色盘组合及存储拒绝验证通过。
- 系统监听 / 手选不被系统覆盖由既有控制器测试覆盖；本轮未实际修改操作系统模式，不能冒充 OS 层验证。
- 默认币种的读取、保存与语义未改，二级页文件对比一致。本轮没有重复修改虚构账号币种来代替原验收。
- 浅色 `@theme` 完全一致，新视觉 CSS 只在 dark 分支生效；标签原色不变，新增局部前景仅在 R2 深色消费。浅色截图中品牌、海浪、布局与控件保持原风格；没有声称跨版本全屏像素逐点相同（版本文字和时间本就会变）。
- 明细和海浪的几何 / 触摸 / 滚轮 / 物理文件保持原样，相关测试通过。普通浏览器滚动采集**未触发明细的真实 wheel 手势输入**，不能把 `p=0` 的图称作收束态；该图按普通滚动命名。开始页面的真实「展开账本列表」操作已检查。

## 6. 对比度与未解决项

37 组 Token 配对检查通过：A 的文字、按钮、输入边界、焦点、财务 / 分类色、热力及海浪；B 的两种混合表面文字。任意用户色最大黑白前景测试覆盖约 2,119 个遍历样本及两种代表标签。[11 页实际渲染审计](../../../preview-artifacts/r2-rendered-contrast.json)读取 174 个可见文字节点，包含祖先透明度与纯色背景叠加，没有低于对应 4.5:1 / 大字 3:1 目标的节点。原始读取见 [颜色层数据](../../../preview-artifacts/r2-rendered-text.json)。这不是整站所有状态的 WCAG 认证。

已处理 R2 深色的品牌按钮前景、输入边界、焦点、五档热力数字与任意标签白字债务；普通阅读 / 图例与状态文字更清晰。装饰线和网格无需硬提到文字标准。分类仍依赖名称 / 金额 / 标记形状；没有改分类映射或财务语义。

仍需所有者判断与后续验证：

1. A 是否足够保留品牌感，B 的轻微头部色相是否值得保留；海浪末层亮度、危险按钮视觉权重与输入焦点粗细仍是主观验收点。
2. 浅色品牌白字约 3.37:1、旧焦点与热力数字债务按本轮浅色保持要求未改；R1 债务保留作对照。
3. 未完成真实手机触摸、Safari / PWA / OLED、安全区、原生日期弹出控件的跨平台检查；浏览器主题 `color-scheme` 保留，但不能保证每个平台原生弹层一致。
4. 语音 / 拍照 / 文件导入采集了真实入口，粘贴识别与共享核对表单有实际样例；未录音、未调用 OCR / AI、未执行文件导入，尚未逐一采集所有识别中、OCR 多笔概览及异常分支。没有改识别业务来制造结果。
5. 渲染对比度审计限可见文字与纯色背景；未把渐变像素、阴影、禁用态或视口外文字算成已全面通过。B 的头部用解析后的混合颜色另检；完整动画中间帧仍需实际手势体验。
6. 图表按排名分配分类色的既有稳定性问题仍未改，按原规范留后续工作；另外六色未制作。
