## 4. 离线历史读取上限修复（1.17.6）

### 4.1 根因

旧实现位于纯客户端：`apps/web/src/lib/offline/fill.ts` 中 `FILL_PAGE_SIZE = 100`、`MAX_FILL_PAGES = 40`，即每月最多读取 4,000 笔。服务端没有这个限制（分页 API 单页上限 100，cursor 可一直取到末页）。真正的问题是：达到 40 页上限后与「正常取完」不可区分，循环结束仍无条件 `storeMonth()` 并把该月计入完成——**把 4,000 笔当成整月写入权威本地账本**；下载管理只有「已下载 / 未下载」两态，离线提示也照常显示完成。S17 分析走 `fx-month-coverage` 回执链，缺回执会被判为来源不完整（这条链本身不静默），但下载管理与明细页本地读取仍会静默少算。

### 4.2 改动

- 新增 `apps/web/src/lib/offline/fillCoverage.ts`（无 React 依赖，纯函数 + 状态存取）：
  - `FILL_MONTH_ENTRY_LIMIT = 50_000`（**临时上限，不是永久规格**）、`FILL_PAGE_SIZE = 100`、`MAX_FILL_PAGES = ceil(limit / pageSize) = 500`；
  - `collectMonthPages(fetchPage, { onPage, shouldStop, maxPages })`：只有最后一页 `nextCursor === null` 才 `complete = true`；到页数上限仍非 null → `complete = false`；
  - 「未完整月份」状态存于 scoped key `offline-fill-partial-months`（`{ entries, limit, at }`），提供 `readPartialMonths` / `recordPartialMonth` / `forgetPartialMonth` / `forgetAllPartialMonths`，写入串行化。
- `fill.ts`：改用 `collectMonthPages`；取回不完整时只记录 partial 并打印「停止（单月上限）」，**不再写本地账本**；已记录的触顶月份在下次启动时跳过（仍可显式 `refresh` 强制重试）。
- `downloadManager.ts`：`MonthRow.state` 增加 `"partial"`；`monthRows(..., count, partial)` 接受 partial 映射，未完整月份显示为 partial 且条目数为已取回数。
- `DownloadManagerPage` / `MonthDownloadPage` / `OfflineStatus`：显示「未完整」状态与说明；「删除全部」同时清理 partial 记录；部分月份在下载管理中可单独重试或删除。
- i18n 中英文新增 6 个 key（`status.partialMonths`、`downloads.rowPartial`、`downloads.partialNotice`、`month.partial`、`month.partialNotice`、`month.partialHint`）。

### 4.3 不静默截断（本轮最重要的验收）

- 某月超过约 50,000 笔时：只读取到上限，**不写入本地账本**，并在 `offline-fill-partial-months` 记录「已取回数量 / 上限 / 时间」；
- 下载管理、单月下载页、离线状态条显式显示「未完整」，不会显示为「已下载」；
- S17 分析工作台依赖的 `fx-month-coverage` 回执不因部分读取而补写，离线分析来源完整性继续为「不完整」，页面显示「数据不完整，以下只是已知部分」；
- 依赖该月的统计不会被标记为完整来源；不存在「页面正常但金额少算」的静默路径。

### 4.4 两个 50,000 的区分

| 限制 | 位置 | 本轮是否修改 |
|---|---|---|
| A 离线历史读取 / 月 | `apps/web/src/lib/offline/fillCoverage.ts`（原 `fill.ts` 4,000） | **改为 50,000** |
| B S17 分析范围单次读取 | `apps/web/src/lib/analysisRange.ts`（100,000 行） | 未改，超限仍显式报错 |
| C 综合折算逐笔投影 / 次 | `packages/shared/src/analysis/fx.ts` 等（50,000） | 未改，超限仍显式说明 |

分析范围可跨月，即使每月都不超 A，整个范围仍可能超过 B / C 容量——本轮没有改变 B / C 的行为，也没有宣称「支持任意数量」。

### 7.3 版本识别方法（给所有者）

1. 看页面「软件更新 / 设置」中的**用户可见版本**（本轮 `1.17.06`）；
