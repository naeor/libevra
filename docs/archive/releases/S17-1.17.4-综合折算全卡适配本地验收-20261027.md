# S17 · 1.17.4 综合折算全卡适配本地验收（2026-10-27）

> 最后核对: 分支 `s17/fx-combined-1.17.04`（基线 `s17/integration-claude @ 7e52675`）/ 2026-10-27；用户可见版本 `1.17.04`（内部 SemVer `1.17.4`）。**仅本地：未 push、未部署、无数据库迁移（仍 60）。** 构建与集成状态统一见 [STATUS](../../STATUS.md)；当前生效的逐卡口径见[综合折算支持清单](../../specs/product/s17-agents/S17-分析卡片综合折算支持清单-20261027.md)。

这份记录回答：1.17.3 之后「综合折算」是否真的覆盖了分析工作台目录里的全部 38 张卡片，以及证据是什么。**结论：38 / 38 张卡片在综合折算下都有真实、经过测试的结果；缺汇率时按卡片口径诚实降级；没有提高任何资源上限；没有修改冻结协议。** 1.17.3 时只有 7 张卡片开放综合折算，其余 31 张显示「综合折算下暂不支持这张卡片」。

## 1. 接管时的状态与根因

- 接管时 `s17/integration-claude` 实际指向 `7e52675`（其祖先 `b0644db` 是 1.17.3 接管复验提交；STATUS 所述「快进到 `b0644db`」之后又追加了 STATUS 记录提交 `7e52675`，二者不矛盾）。开发在该基线的源码副本上进行，交付为叠加在它之上的新分支，**没有改动 `s17/integration-claude`**。
- 接管现场（事后可再次验证的事实）：基线里分析卡片只有 7 张开放综合折算（总支出 / 总收入 / 差额与支出、收入的构成与排行），其余 31 张显示「综合折算下暂不支持这张卡片」；基线没有逐笔折算到工作台的适配层，B 时间引擎没有「某天金额未知」的表达。其他 S17 工作树（`deepseek/s17-orchestrator` 等）里没有综合折算适配代码；主工作区只做了只读检索，**未改动**其受保护的未提交内容。基线 `packages/shared/src/analysis/advanced/fxProjection.ts` 是 Agent C 的 P17–P20 币种构成 / 诊断草稿投影（不进包入口），用途不同，本次未复用、未修改。
- 根因：综合折算只向工作台提供**聚合**结果（总额、分类小计），而 31 张卡片需要**逐笔**折算后的账目（极值、中位数、趋势、热力、构成占比……）；时间引擎没有「这个日子的金额未知」，缺汇率只能被当 0 或被丢弃。
- 做法：不改 31 个标志，而是补全这条数据链（见支持清单 §2）：逐笔投影 → 按卡片口径的缺汇率策略 → 现有 A / B 引擎原样复用。

### 4.3 独立金额复算（混币种）

浏览器探针里的期望值**不取自应用代码**：`s17-fx-combined-lib.mjs` 的 `convertMinor` 用 BigInt 有理数实现 `target = round(amount × 10^dT × r_T ÷ (10^dS × r_S))`（半入，每笔在其发生日的汇率上折算一次），汇率取自 API 公共汇率端点。核对的数字包括（目标 CNY，汇率恒定场景）：总支出 ¥3,831.99、总收入 ¥6,440.00、差额 ¥2,608.01；日均 = 总支出 ÷ 26 天（半入）；最大单笔 ¥3,200.00（10-20 购物）、最小单笔 ¥6.00（10-02 交通）；分类「餐饮 / 交通 / 购物 / 房租」；汇率逐日变化场景下 I01 分类 ¥250.55 / ¥31.00 / ¥3,244.56 / ¥300.00 与独立复算一致；目标币种 USD 时总支出 $598.76。缺汇率场景（10-02 整天无汇率）：B01 小计 ¥3,747.01，另有 2 笔未计入，不是总额。

## 5. 发现与限制（需要所有者知道）

1. **本机历史镜像每月最多取回约 4,000 笔**（`lib/offline/fill.ts`：每页 100 × 最多 40 页）。既有行为，与折算无关，两种模式一致；个人记账几乎不触发，但它使「5 万笔逐笔超限」无法在真实浏览器里通过正常同步复现，所以超限路径由「改写常量为 10」的浏览器测试 + 单元测试覆盖。**未改动该上限，是否调整需另行决定。**
2. **B16「有支出的分类数」单位文案**显示「4 笔」（既有文案问题，原币模式相同），本次未改。
3. **A01 沿用 Number 口径的 `computeStats`**，由投影的安全整数守卫保护；改为 BigInt 全程需改既有统计函数，未做。
4. **「B 类卡片不提示镜像不全」**为既有行为（与折算无关）。
