# S16-E-10 / E-11 设置页状态与跨标签同步核对（2026-10-25）

> 范围：S16-E 设置体系的**错误 / 离线 / 空状态可感知性**（E-10）与**跨标签页偏好同步**（E-11）。
> 基线：本地 `1.16.14` / 生产 `1.16.08`；仅本机开发环境，不涉及部署与生产数据。

## 1. 目标与判定标准

- **E-10**：每个设置项的成功 / 失败 / 离线状态都能被用户感知；交互控件都有可访问名；
  「后续开放」必须读起来像事实，不能是假开关。
- **E-11**：在另一个标签页修改主题 / 语言后，当前标签页应实时跟随，并且**不得把收到的值再写回存储**
  （避免两个标签页互相覆盖的抖动）。

## 3. 核对中发现并修复的确定性缺陷

**离线保存被静默挂起（已修复）。** `useUpdatePreferences` 用的是 TanStack Query 默认的
`networkMode: "online"`：离线时 mutation **不会发出、不会失败、一直 pending**。界面表现是
「所有币种按钮变灰，但没有任何说明」；恢复网络后它又会自己提交一次用户以为没生效的修改。
偏好是服务器状态，离线无法真正保存，因此改为 `networkMode: "always"`（`apps/web/src/lib/queries.ts`），
让失败如实显示——离线点击后提示「当前处于离线状态，无法与服务器同步。请恢复网络后重试。」，
选中项不变、按钮恢复可点。

核对脚本自身另修了两处，均**不属于产品缺陷**：① 顶部离线横幅也是 `role=status`，不能作为
「保存失败」的判定条件，改用卡片内 `bg-danger-soft` 错误框定位；② 夹具账号默认币种可能被上一轮
中断的提交留在 USD，脚本开头先通过 API 归一到 CNY 再取断言基线。

## 4. E-11 跨标签页同步

现状（均为浏览器运行时注册的 `storage` 监听器）：

- 主题：`apps/web/src/lib/theme.ts` 监听 `THEME_STORAGE_KEY`；`key === null`（存储被清空）时同样恢复默认。
- 语言：`apps/web/src/lib/languageRuntime.ts` 监听 `LANGUAGE_STORAGE_KEY`。

新增单元测试 `apps/web/src/lib/crossTabSync.test.ts`（4 项，全过）：深色主题跨标签应用且不回写；
`key=null` 清空后退回默认且不回写；语言跨标签切换后 `<html lang>` 立即跟随且不回写；无关存储键不影响语言。

**未做 / 边界**：真实双标签浏览器 E2E 未做（双 target 成本高且易 flaky，本轮先用单测锁定逻辑，
列待验收）；账户级语言 / 主题同步依赖 S16-E-02 / E-03 的产品决策，尚未实现。
