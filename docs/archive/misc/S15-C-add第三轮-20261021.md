## 1. 七块改动

1. **统一文字与布局**：区域标题仍为 `text-helper text-muted`；金额卡、分类行、时间行、更多选项行的字号/颜色/对齐按现有 token 收敛；金额标题不再带右侧提示，时间卡去掉 `divide-y` 后仍是独立一行。未改全站设计系统（S16）。
2. **币种入口**：金额下方独立的「币种」行删除；金额框右侧 `CNY` 变成品牌绿按钮（`aria-haspopup="dialog"`、44px 触控区、`⌄`），点它打开币种面板；点金额仍直接编辑。左侧符号改用 `currencySymbol()`，与右侧代码同步（实测 USD → `$` / `USD`）。`CURRENCIES`、`decimalsFor`、`parseAmountInput` 与保存语义均未改。
3. **统一下拉**：新增 `ChoiceSheet`（`fixed z-40` 遮罩 + `fixed bottom-0 z-50` 面板、`max-h-[calc(100dvh-24px)]`、列表 `overflow-y-auto overscroll-contain`、`dialog/listbox/option`、品牌绿选中 + 对勾、Escape/遮罩/点选关闭、打开聚焦当前项、关闭焦点归还）。分类选择保持页面内展开列表；导入页面见 §2。
4. **删除冗余说明**：「点按即可修改」「不选也可以保存，会记入『暂无分类』」删除，测试反向断言。分类默认值/缺失行为未变。
5. **更多选项摘要**：三项全空 → `支付方式、备注、标签`；选了支付方式 → 实际名称（默认的「其他」也算有效值，实测显示「其他」）；有备注 → `有备注`；有标签 → `N 个标签`；` · ` 连接。展开后控件与保存读取不变。
6. **底部保存条**：不靠提高 + 的 z-index。`EntrySaveBar` 由 `sticky bottom-0` 改为 `sticky bottom-5`，20px 留白落在条外；表单在 `/add` 内 `flex flex-1 flex-col` + 弹性空白，`TabPage` 用既有 `className` 入口传 `min-h-full pb-0!`，内容短于一屏也贴底，长内容滚到底不再突然抬升 96px。软键盘逻辑保留（键盘打开时内联 `bottom` 直接取 inset）。
7. **未做**：其它页面的原生 select 未动，见 §4。
