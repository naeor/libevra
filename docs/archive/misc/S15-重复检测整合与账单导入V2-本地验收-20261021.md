## 1. 本轮范围

1. **S15-E4/E5**：把手动、语音、拍照 OCR、OCR 批量、CSV 导入、账本导入、游客本地等入口统一到同一套重复检测核心与设置；
   新增明细页即时检测、账本设置里的全账本检查、E3“不是同一笔”关系抑制；删除 Python 旧判重与 OCR 0.85 商户相似度旧口径。
2. **账单导入 V2**：`/import` 支持按内容识别微信 XLSX、支付宝 CSV、BOA PDF、Libevra CSV；服务端预览/复核/提交、前端统一核对与批量入账、
   身份去重与内容疑似重复两层、结果可追溯、失败可重试。
3. **兼容修复**：旧 `POST /api/v1/transactions/duplicates` 保留响应结构，但内部走统一核心；升级前客户端只发 `occurredLocalDate + HH:mm` 时，
   按该条交易自己的时区还原绝对时刻，不猜服务器时区。

## 2. 统一重复检测验收

- 规则：同账本、同收支方向、金额最小单位与币种完全相同、真实 epoch 时间差 ≤ 窗口（默认 60 秒）；分类/支付方式仅双方都有值时比较，
  单边缺失不排除；时间必须带偏移 ISO，只有日期时按弱依据提醒；关闭提醒只抑制 UI，不影响幂等。
- 设置：`localStorage` 按用户隔离、版本化、损坏可恢复；设置只在本设备生效，**本轮不跨设备同步**（明确不做，不当作已完成）。
- 入口矩阵与分块全账本检查见 E4/E5 实现说明 §4/§5；关系表迁移只在本机开发库/测试库应用（52），生产仍 51。
- UI 冒烟（本机 Chrome headless + 本地测试账号，数据只在本机开发库）：
  - 账本设置 → 数据管理 → 重复账目检测：对账本历史分块检查，找到 1 组同额（123.45）相差 20 秒的记录；
  - 组内“确认不是同一笔”写入 E3 关系，结果被抑制；管理页显示有效关系，撤销后恢复提醒；
  - 明细页“更多 → 重复账目检测”只查当前这一笔，找到同一组；
  - 新增页保存时出现“这笔账好像已经记过了”的轻提醒，取消后不写入；
  - 所有入口不自动删除/合并，勾选变化不改动已有账目。

## 3. 账单导入 V2 验收

### 3.1 真实样本（只在本机私有目录，不入仓库/测试夹具/日志）

| 样本 | 解析结果 | 金额/方向/日期 | 提交结果 |
|---|---|---|---|
| 微信 XLSX | 12 笔（8 支出 / 4 收入） | 日期 2026-09-22 … 2026-10-16；Excel serial 与共享字符串正确 | UI 提交 12 笔；同一文件再次导入 12 笔全部 `identityDuplicate`，新增 0 |
| 支付宝 CSV | 48 笔 = 46 支出 + 1 不计收支 + 1 交易关闭 | GB18030、尾部制表符、长单号处理正确；后两类默认不选中 | 临时 E2E 提交 46 笔；不计收支/关闭没有一律当支出 |
| BOA PDF | 108 笔（存入 14 / ATM 借记 83 / 其他 11） | 8 页、跨页续表、`MM/DD/YY` 过账日；全部 `timePrecision=day`，不补 12:00 | 临时 E2E 提交 108 笔；三段合计与期初+存入−支出=期末一致，`reconciliation.ok=true` |

- UI 三份文件均能完成“选择 → 预览 → 核对页”，显示读到/可导入/已排除/疑似重复；微信样本已通过 UI 完成一次真实提交。
- 支付宝/BOA 的完整提交由临时 E2E 覆盖（测试文件用完已删除，不入库）。
- BOA 描述里出现第二个日期的 21 行：若与过账日不同，给逐笔“可能是消费日期，请核对”的警告；不改写候选日期、不编造时间。
- 判重：文件内与历史都走 E2 核心；身份重复不允许勾选、不选中；疑似重复只提示，不自动取消；E3 已确认关系由服务端抑制。
- 重试/重复点击：同一文件再次导入不新增账目；提交失败保留预览可重试。

## 5. 已知限制（不得当作已完成）

1. **未发布**：远端未 push，生产未部署；生产仍是 1.15.01 和旧 CSV 导入入口，E3 的 52 号迁移未上生产。
2. **E6 专项验收/真机未做**：18 个功能场景 + 安全清单、320/375/390 真实视觉、真实手机触控与安全区、真实账号跨设备/离线导入未验。
3. **BOA 双日期未落库**：只有过账日期；描述里的第二日期仅警告。要按消费日/入账日分别判重需扩数据模型（新迁移，需批准）。
4. **扫描版 PDF 不支持**：只支持带文本层的 PDF；抽不出文本明确报错，不做 OCR 猜测。
5. **预览缓存**：服务端内存 TTL 30 分钟；刷新核对页回到选文件态；CSV 内容判重仍在写入后按 `importRef` 检查。
6. **设置不跨设备**：仍是 localStorage、按用户隔离；本轮明确不做跨设备同步。
7. **商户匹配**：`Transaction` 没有商户字段，商户维度实际主要对 OCR 候选生效；备注/标签维度对正式账目生效。
