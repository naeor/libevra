## 2. S15-B（OCR 多笔）成果

**做了什么**

1. **页面类型分类器 + 可扩展版式注册表**（`layouts.py`）：`single-detail` / `transaction-list` / `unknown`；unknown 强制用户选择、不擅自定数量；判定依据可解释（关键词 + 结构信号）。**已验证版式**：微信单笔详情、支付宝单笔详情（合成样本）。**未验证**（缺真实样本，已如实标注）：微信/支付宝交易列表、BOA 列表、银行转账详情、通用列表。
2. **多笔提取**（`multi_extract.py`）：列表按几何行切分，一张图输出多笔独立候选；细节页复用 `extract.py`；**多数字列（Amount + Balance）返回"金额待确认"而不是猜**；缺失字段 = None + 类型化 issue；提供自定义抽取器扩展点。
3. **字段标准化**（`normalize.py`）：正负号、币种符号/代码、缺失年份（**不补**，可传 `reference_year` 并标 `year_inferred`）、Pending/Posted、退款/转账。
4. **重复检测接口**（`dedupe.py`）：同图内 / 跨图 / 与已有账目 三个纯函数 + 组合接口；**只标记分组，不删除、不合并、不接 DB**。
5. **概览页候选原型**（Web）：`lib/ocrOverview.ts` + `components/ocr/OcrOverview.tsx` + `pages/OcrOverviewPage.tsx` + 路由 `/ocr/overview`；横向卡片展示金额/币种/方向/日期/商户/分类/标签/账户/问题状态；**只读**、点击进详情占位、筛选、默认预选、统一确认**仅回调**（不写账本、不绕过保存/锁/幂等）。
6. **端到端预览脚本**（`multi_preview.py`）：对 3 张合成样本跑真实 RapidOCR，识别正确。

**关键文件**：`apps/ocr/{model,normalize,layouts,multi_extract,dedupe,overview,multi_preview}.py`、`apps/ocr/tests/*`、`apps/web/src/lib/ocrOverview*.ts`、`apps/web/src/components/ocr/OcrOverview.tsx`、`apps/web/src/pages/OcrOverviewPage.tsx`、`apps/web/src/App.tsx`、`docs/specs/product/S13-E-新页面点击树.md`（67→68）、`docs/archive/misc/S15-B-夜间开发交接-20261020.md`
