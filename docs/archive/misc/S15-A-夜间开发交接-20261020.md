## 6. base 切换生产步骤（候选，需所有者批准后自己执行）

> 现网行为**不会**因为本分支代码变化而改变：生产部署 `.env` 显式写着 `LIBELLUM_WHISPER_MODEL=small`，
> 代码默认值只在 env 缺失时生效。

1. 先确认现状：`ssh` 上服务器看 `/srv/libevra/deploy/.env` 是否有 `LIBELLUM_WHISPER_MODEL=small`。
2. 切换：把该行改成 `base`，用既有发布流程重建 `api` 容器（env 变更需要重建容器，`restart` 不够）；
   首次语音请求会把 `ggml-base.bin`（约 148 MB）下载到 `api-data` 卷，启动日志的 ready 行应显示
   `"model": "base"`、`"threads": 2`。
3. 验证：发一次真实语音请求，看 API 日志的 `voice transcription timing`（decodeMs/vadMs/inferMs/totalMs）
   与 `/api/v1/health`；确认普通记账 API 延迟不受影响。
4. 回退：把 env 改回 `small` 并重建 `api`；`ggml-small.bin` 仍在卷里，无需重新下载。
5. ⚠️ **未验证**：服务器到模型下载源的网络可达性。若不能联网，需预置模型文件到卷里并用
   `LIBELLUM_WHISPER_MODEL_PATH` 指向本地路径（`service.py` 已支持）。
6. 生产切换属于 L4：需所有者当次批准；本次**没有** ssh、`git archive`、上传、部署或改任何 `.env`。
