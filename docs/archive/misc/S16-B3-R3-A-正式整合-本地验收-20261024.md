## 3. 正式接入方式

### 3.1 主题选择

继续使用 S16-B0 的 `apps/web/src/lib/theme.ts` 与首屏 prepaint 契约：

- `data-theme-mode="light|dark"`：解析后的实际模式；
- `data-theme-palette="green"`：当前唯一开放色盘；
- `data-theme-preference="light|dark|system"`：用户的字面选择；
- 存储键：`libevra.theme`。

**正式映射**：绿色 + 深色 → R3-A；绿色 + 浅色 → 原 `@theme` 浅色值；跟随系统按系统外观解析。刷新、导航、重新打开由同一契约恢复，首屏 prepaint 在 CSS 绘制前设置属性与 `color-scheme`。

### 3.2 CSS 位置

- 浅色默认值：`apps/web/src/index.css` 的 `@theme`（未改值）。
- 深色安全回退：`html[data-theme-mode="dark"]`。
- 正式绿色映射：`html[data-theme-mode="dark"][data-theme-palette="green"]`。
- 两个深色块的品牌值都统一为 R3-A，避免缺少 `data-theme-palette` 时回退到旧的中性品牌值。
- 移除了旧的 B1 深色覆盖与 R3 预览 `data-design-variant` 依赖；`index.css` 不再通过设计预览属性提供正式颜色。

## 5. Hover 修复

R3 候选共有问题：次级按钮使用 `hover:bg-brand-soft/70`，而 `brand-soft` 与 `surface` 只差约 1.05–1.13:1，hover 反馈偏弱。

本轮处理：

- 13 处、11 个使用该 hover 类的组件统一改为 **`hover:bg-brand/20`**。
- 效果：默认仍是 low-key 的 `brand-soft` 浅底；hover 时在表面色上叠 20% `brand`，产生可感知但不刺眼的品牌色变化。
- 未新增独立 hover token，避免与现有 50 个 token 的职责重复。
- 主按钮继续使用 `bg-brand` → `bg-brand-dark`；用户已有 `on-brand` 前景，对比度通过。
- 焦点环使用 R3-A `focus-ring`；输入框边界使用 `line-strong`。disabled 仅降低不透明度，未新增语义色。
