## 1. 本轮范围

只做“以后设计一套新主题只需定义色盘及变体”的基础：

- 保留现有 19 个 token 名称/默认值，新增角色、财务、图表、海浪与玻璃 token（共 50 个）。
- 建立 `mode = light|dark|system` 与 `palette = green|red|orange|yellow|cyan|blue|purple` 两个独立维度，组件不写主题分支。
- 把固定白字/白底迁移到 `on-*` / 语义表面；保留 QR、用户标签、开关旋钮等必要例外。
- 图表/海浪字面量迁移到 CSS 变量；标签分类色与图表分类色解耦。
- 扩展颜色守卫与对比度测试；更新规范/路线图/STATUS/索引。
- 图表分类稳定映射**只写设计与测试方案**，不改变现有按金额排名的图表表现。

**不做**：深色值、七套色盘 HEX、设置页 UI、prepaint 脚本、数据库、生产部署、历史金额/业务规则。

## 2. 已完成

### 2.1 CSS token（50 个）

`apps/web/src/index.css` 的 `@theme`：

- 旧 19 个：`category-ink`、`canvas`、`surface`、`ink`、`muted`、`line`、`brand`、`brand-dark`、`brand-soft`、`accent-ink`、`chart-rule`、`danger`、`danger-dark`、`danger-soft`、`warn`、`warn-dark`、`warn-soft`、`overlay-soft`、`overlay`。
- 新增 31 个：
  - 前景：`on-brand`、`on-danger`、`on-warn`、`on-ink`、`on-heat`、`on-tag`、`control-knob`；
  - 交互：`focus-ring`、`line-strong`；
  - 财务：`data-expense`、`data-income`、`data-transfer`；
  - 图表：`chart-1…8`；
  - 热力：`chart-heat-0…4`；
  - 海浪：`ocean-1…4`、`on-ocean`；
  - 玻璃：`glass-highlight`。

默认值保持浅色绿外观；已迁移组件在默认主题下解析出的颜色与旧字面量相同。

### 2.2 主题运行时

`apps/web/src/lib/theme.ts`：

- `THEME_MODES = light|dark|system`、`THEME_PALETTES = green|red|orange|yellow|cyan|blue|purple`；
- `parseThemePreference()` 对损坏 JSON/未知值按半维度回退；
- `readThemePreference()` / `persistThemePreference()`：设备级 key `libevra.theme`；
- `resolveThemeMode()` 把 system 解析为 light/dark；
- `applyThemePreference()` 写 `data-theme-mode` / `data-theme-palette` / `data-theme-preference`；
- `watchSystemTheme()` 监听系统外观；
- 10 个单元测试通过。

**尚未接线**：没有调用者、没有 prepaint、没有深色/色盘值块；设置页 `appearance` 仍是占位。

### 2.3 固定白色迁移

已迁移：页头、主按钮、危险确认、墨色提示条、同步/撤销条、热力深格、半透明页头/录音/骨架、标签选中态、白色控件表面。

保留例外：

- `QrCodeView.tsx` 的 `bg-white`：扫码可靠性要求绝对黑白；
- 用户标签选中文字：用 `on-tag`，但标签底色仍是用户数据；
- `SettingsCard.tsx` 开关旋钮：`control-knob`，不跟随 surface 变暗；
- 用户标签原色、二维码、明细玻璃高光不参与主题化。

### 2.4 图表/海浪/标签解耦

- `apps/web/src/lib/chart/theme.ts`：分类/热力/财务颜色改为 `var(--color-chart-*)`、`var(--color-chart-heat-*)`、`var(--color-data-*)`。
- `OceanBackdrop.tsx`：四层填充改为 `var(--color-ocean-*)`；路径/层数/动画未改。
- `ManagePages.tsx` 不再直接引用图表调色板；标签色源在 `lib/tagColors.ts`，避免主题化图表影响用户标签。

### 2.5 守卫与测试

- `colors.test.ts`：hex/rgb 守卫保留；新增 Tailwind 内置色类名守卫；QR `bg-white` 是唯一固定色类名例外；守卫例外收敛为 3 个（`index.css`、`tagColors.ts`、`QrCodeView.tsx`）。
- `tokens.test.ts`：旧 19 token 默认值、新增 token 存在、文字/状态/边框对比度、已知焦点环/热力债务。测试 5 个。
- `chartTheme.test.ts`：导出必须是 CSS 变量。
- `theme.test.ts`：偏好/回退/系统监听 10 个。
- `tabHeader.test.ts`：页头用 `on-brand`。

## 3. 未完成/未覆盖

1. **深色值、七套色盘、设置页切换、prepaint/首屏无闪烁**：按路线图留给后续 S16-B 切片/Codex。
2. **图表分类稳定映射**：仅设计与测试方案，尚未实现/接线；现有图表行为未变。
3. **焦点环 `#edf5f0` 对 canvas 约 1.08:1**、**`on-heat` 白字在 heat-3 约 2.37:1 / heat-4 约 4.07:1**、**输入框 `line` 边界约 1.2:1**：当前默认视觉保持不变，作为 P0 设计债务记录；`line-strong` 已提供 3:1 的值但尚未应用到输入框。
4. **`on-brand` 白对品牌绿 3.37:1**：按钮/大字可用，正文小字不达 AA；由 Codex 决定深字/加深绿色。
5. **视觉回归**：默认值等值替换 + 组件测试/生产构建通过；无头浏览器在无登录态下只能看到登录骨架，**未完成真实登录态逐页截图/像素差分**，不作为视觉通过证据。
6. 未改数据库、历史金额、财务规则、生产环境；未 push/merge/deploy。

## 5. 下一阶段建议顺序

1. Codex 交付默认绿深色色阶 → 接 `[data-theme-mode="dark"]` + 对比度测试。
2. 设置页接入主题偏好 + prepaint 脚本，验证无首屏闪烁。
3. 默认绿深色全页面回归；然后单色盘试点。
4. 图表稳定映射纯函数/测试 → 所有者确认后接线。
5. 焦点环/输入边界/热力前景/标签自动前景作为独立可验收项。
