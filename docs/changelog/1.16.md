## 1.16.03 · S16 UX Writing（本地候选）

- **分批修改**：删除恢复/法律状态/错误反馈；设置与账号邀请/历史/明细工具；OCR 与文件/账本导入。覆盖 27 个文案实现文件，不批量替换清单的全部 3,700 项。逐批决定、前后对照、保留项及验收见 [S16 文案验收记录](../archive/releases/S16-UX-Writing-本地验收-20261023.md)。
- **已确认事实**：单笔、批量及导入移除的账目可经编辑历史逐笔恢复，需账本存在及编辑权限；批量删除无一键撤销。法律页只声明正式文本尚未提供。清空待同步操作不再声称“不发送请求/只取消颜色”，明确停止提交本机待同步修改和删除，并请求按服务器版本处理冲突。均只改展示，不改执行路径。
- **保护与暂缓**：不改财务、数据库、权限及海浪；不改历史公告正文与真实法律文本。历史金额因缺少事件发生时币种，按所有者确认暂缓，不能用当前币种猜算。
- **验证**：类型检查、全量 1990 项测试（shared 326 / API 559 / Web 1105，含字号守卫）、生产构建通过。真实 Chrome 隔离模拟数据覆盖 38 页面 × 5 宽度，以及删除确认、文件失败与匿名账号流程；详见验收记录。没有写真实业务数据或上传。文档总检查仍受既有 `_review/tmp/index-partial.md` 的 73 个失效相对链接阻断，本轮文档单独校验。

## 1.16.02 · 个人资料局部回调与账号编号复制（本地候选）

- **调整**：昵称、用户名、账号编号、注册时间恢复紧凑左右排版，灰色名称、深色值；取消逐项解释和分享说明，不显示常驻复制按钮。恢复码入口保留，删除技术解释，安全提醒保留。共享 `FactRow` 的其他页面不受这次回调影响。
- **复制**：点击账号编号（44px 触控高度）打开底部原生模态面板，面板内复制；明确成功/手动复制反馈，编号始终可选。打开 260ms、关闭 180ms，快速反向关闭从当前动画位置收回；减少动态设置下不动画。Escape/遮罩/关闭按钮可关闭，焦点及页面滚动恢复。
- **技术边界**：复用 `copyText`，仅新增可选复制容器参数，默认仍为 body。原生模态 dialog 会阻止其外部文本域获得焦点，故本面板把临时复制域放到自身内部；其余调用者路径不变。异步复制结果不跨越面板重新打开的会话。
- **浏览器验证**：320/375/390/430/1440px 隔离模拟账号，检查布局、编号复制参数、成功/失败状态、焦点、滚动恢复、快速关闭、减少动态和恢复码导航；未访问生产，未改真实账号或业务数据。系统剪贴板写入由测试替身捕获，未改动用户系统剪贴板；真机 Safari 待所有者验收。
- **检查结果**：全项目类型检查、Web 1100 项测试、生产构建、`check:status` 及 `git diff --check` 通过。旧文案测试中“必须显示账号分享说明”的断言随本次产品裁决更新；恢复码安全提醒断言继续保留。文档总检查仍有下文记录的原有临时副本链接问题，本次未处理该文件。

## 1.16.01 · S16 文字层级与排版（本地候选）

- **改了什么**：字段及设置项名称复用 `text-card-title`（14px/500），与灰绿色解释区分；功能分区保留 16px/600。资料、账本详情、设置、录入及导出等通过共享组件或局部角色修正生效。说明未缩小；多行正文行高 23→24px，辅助说明保持 12px/20px。
- **阅读顺序**：币种快选先显示控件，再显示规则；阅读类分节以 16px 标题、正文和段落间距组织。账号编号继续等宽，时间、金额及结果计数使用等宽数字；OCR 完成页突出累计数量及本批结果。信息图标归入 11px 微文字，删除两项过期任意字号豁免。
- **保留**：海浪及明细页动态标题、金额专用字号、图表密度、底部导航、输入框至少 16px、所有权限/财务/数据处理规则。公告首页沿用此前确认的固定高度预览和省略号；不增加绿色背景，不修改真实发布公告数据。
- **设计依据与浏览器验收**：见 [文字语义规范 §13.8](../specs/design/文字语义与排版规范.md#138-s16-真实页面文字层级优化2026-10-23)。截图与测量使用独立浏览器上下文、模拟用户及账本；没有访问生产、提交真实账目或修改本地业务数据库。真机 Safari、实际录音/识别和跨设备同步不在这次排版验收中。
