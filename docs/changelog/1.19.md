## 1.19.53 · 明细与分析共用筛选、筛选保留、返回转场与材质收尾（2026-11-09，已发布生产）

- 改动前建立 `s19-round4-before-20261109`（= `4e813d84`，1.19.52）。按所有者使用 1.19.52 时发现的问题逐项处理；切换账本整页重新载入、保存 / 导入 / 同步 / 权限判断与金额计算均未改动。
- **筛选会保留，明细与分析默认共用**：筛选（月份 / 全部时间 / 日期范围与分类、标签、支付方式、币种、附件）改为保存在本机、按账号与账本分开（`lib/ledgerFilter.ts`），刷新页面、切 Tab、记一笔回来、从账目返回都不再变回当月。新增开关“明细与分析使用同一筛选”（默认开，本机偏好），在记账偏好与两页的筛选面板里都能改：打开时分析统计的就是明细当前筛选出的账目，在任一页改动两边一起变；关闭后分析从当时的条件复制一份自己的。分析里“全部时间”与超过 400 天的范围按最近 400 天计算（分析既有口径），摘要写明。旧链接、卡片详情“去明细看”与布局预设带来的条件读入后从地址栏移除。统计方式与币种仍是分析自己的设置。
- **分析的筛选改为明细同款面板**：分析页漏斗打开的是与明细相同的筛选面板（手机从底部弹出半屏，宽屏弹出框），条件、选项与“重置 / 查看结果”一致；原工作台内联筛选面板不再用于分析页。分析增加币种与附件条件，支付方式支持“未指定”。
- **明细收起态的漏斗**：明细收起到账目列表时，月份前出现与分析筛选相同的漏斗图标（16px，与右侧四个工具图标对齐），随收起后半程长出；A / B1 / B2 位于月份的玻璃底面里，C / Original 在绿色顶栏上；有其它筛选条件时始终显示。
- **当前账本胶囊**：账本名字号按文字语义规范改为字段值的 14px（`text-body`），原来继承按钮的 16px；胶囊高度不变。
- **返回转场**：个人资料返回“我的”原来是 push 到 /me，直接跳过去；现在上一条历史就是“我的”时用 -1 回去，播放默认返回转场。审查后同样处理：头像页返回个人资料、下载管理“更多”返回、保存账目修改 / 删除账目后回到明细（账目收回到那一行）、从明细打开的展示卡片编辑器保存、“进行服务器同步”回到明细；账号安全子页按声明的来路返回时也改用 -1（原来是 push，转场方向是“前进”）。云端 Chromium 遍历“我的 / 设置 / 账号安全 / 账本 / 账本设置 / 明细更多 / 下载管理 / 软件更新”的所有子页，进入与返回都有转场；没有来路的深链仍直接前往。
- **按下不再盖掉材质**：B2 点“+”后整颗变成纯深绿，原因是触屏点一下会粘住 `:hover`，而悬停与按下都把材质换成了纯色。现在按下是在原材质上叠一层同色调暗化（渐变、高光与亮边保留），悬停只给能悬停的指针；主按钮、浅底按钮、记一笔入口卡与顶部工具同样处理，组件与分析工作台里手写的悬停样式也只在能悬停的设备上生效。“+”展开时只有图标旋转，反光不随之转动。
- **页面背景与 Safari 工具栏颜色**：贴着屏幕上下缘的不透明画布色块会让 iPhone Safari 把工具栏染成灰色。头像页保存栏、账目编辑保存栏、明细批量操作栏与留言输入区改为底部操作区材质；留言页整页透明显露壁纸、顶栏为栏材质；“历史记录已存到本机”等设备提示条改为栏材质；外观页“明暗”三选一改为分段轨道，风格卡与玻璃效果三档改为交互卡材质；展示卡片编辑器的指标选项同样处理；头像选中圈不再用画布色做间隙。云端 Chromium 逐页扫描 52 个页面（B2 / A / B1），剩余的不透明块只有输入表面、状态提示与按设计为实体的 A 风格卡片。
- **头像页“页面无法显示”**：用局域网 http 地址打开开发服务器时，`crypto.randomUUID` 不存在（只在 HTTPS 与 localhost 提供），选另一个头像（未保存的修改开始被保护）即抛错崩溃。改用本仓库的 `uuidV7`；同样的写法还出现在附件、文字识别批次、拍照附件批次与账本导入编号，一并替换。正式环境（HTTPS）不受影响。
- **账本页说明**：单人账本的副标题从“单人账本”改为“目前只有你一位成员，邀请他人后可以一起记账。”（英文同步）。
- **更新公告**：新增 1.19.53 普通公告（中英文，不弹窗）：明细与分析默认共用筛选、筛选保留、分析使用同款筛选面板；记账键盘与确认栏、胶囊与海浪、新风格材质、返回转场与每日一次的本机提示；注明分析最多统计 400 天。
- **生产发布**：2026-11-10 05:20 CST 切换完成，源码 `2046c53a`（1.19.50–1.19.52 一并进入生产）；发布前备份隔离恢复 58 表通过，`/health` 1.19.53，主要页面 200，行数与迁移不变，CI 通过。所有者睡前把部署私钥载入本机 ssh-agent 并运行任务窗口，Claude 逐个下发任务完成推送与部署。过程与回滚见[生产发布记录](../archive/releases/1.19.53-明细与分析共用筛选-生产发布-20261110.md)。
- **部署覆盖**：新增 `deploy/docker-compose.release-1.19.53.yml`（`libevra-rc-api/web:1.19.53-20261110`，relay 保持 `1.14.19-20261019`）。无新迁移（仍 67 项），无 API 业务代码变化。

- **记账时选中水滴移到“+”后面**：进入手动、文本、语音、拍照、导入任一记账页时，底栏的选中指示（B1 / B2 的玻璃胶囊、A 的 DepthGlide 胶囊）用与主 Tab 之间相同的移动动画滑到“+”正后方，到达前淡出、被“+”挡住；回到主 Tab 时从“+”后面滑回并淡入；此时主 Tab 都不显示选中。C 与 Original 本来是静止的选中圆，进入记账页时只是不再标在原 Tab 上。（`BottomNav` 的 `data-entry-current`、`s19/tabIndicator.ts`、`s19/motion/aTabs.ts`）
- **“历史记录已存到本机”每个自然日只提示一次**：打开 App 时自动补齐离线月份的进度与完成提示，按本机自然日只显示一次（设备键 `libevra.offline-fill-notice-day`）；同一天再次自动下载照常在后台进行，只是不再显示。手动下载（下载管理里的月份、下载全部）照常显示；下载未完成 / 中断、流量网络暂停的说明与其他提示不受影响。

- **搜索键**：点“取消”收起搜索后不再残留选中圈（原来的 `:focus-within` 常亮背景去掉；只有键盘 Esc 收起时把焦点交回搜索键并显示键盘焦点环）；按下态与同排的排序圆键一致（Original / C 白色 30%，A / B1 / B2 用 `--s19-tool-active`）。

- **当前账本胶囊的“管理全部账本”**：改为单独的胶囊小按钮（`CapsuleButton`），并补上进入账本空间的海浪——原来点击时账本面板还开着，协调器在有弹层时不播放海浪；现在先同步关闭面板再导航。Original、电脑版与减少动态效果照旧直接进入。
- **语义迁移（记账工作区专项审查剩余项）**：手写输入控件声明 `field`（手动记账分类 / 时间、核对表单、文字与语音输入框、OCR 单笔核对、账单行内编辑与下拉、更多选项备注；外观不变）；录音面板改为 `ActionCard`；拍照“单张 / 批量”改为选择卡（`ActionCard` + `aria-pressed`，以标题命名的选择组；Original 仍是品牌框浅底）；导入目标账本提示改为 `StatusMessage`；更多选项外框声明展示材质（保持字段圆角），支付方式与标签胶囊补上 `aria-pressed`（标签颜色仍按用户设置）；语音识别结果、OCR 单笔核对与账单行的静态标签改为 `Badge`；OCR 概览的状态 / 来源 / 方向筛选、“筛选”开关与账单导入筛选行改为 `CapsuleButton`（新增 `size="compact"` 辅助字号，互斥筛选用 `aria-pressed`）。标准胶囊补上基础选中外观（Original / 深色：品牌浅底 + 细框；S19 浅色手机：胶囊材质 + 统一选中描边），C 的胶囊 / 工具与记账胶囊补一圈细线（纸面上白底叠白底原来看不出边界）。原来专用的 `[data-entry-more]` 规则随之删除。

## 1.19.51 · 记账工作区材质、键盘与专注型核对（2026-11-09，仅本机）

- 改动前建立 `s19-entry-workspace-before-20261109`（= 改动前的主目录 HEAD）。依据当天的记账工作区专项审查（手动、文字、语音、拍照、导入及其核对页；审查表与证据在被忽略的 `Claude outputs/s19-entry-audit-20261109/`）和所有者的决定实施。金额解析、保存、去重、导入锁、权限判断均未改动。
- **专注型核对让底栏让位（修两处遮挡）**：`/scan` 单张核对的“确认并保存”与 `/import` 核对的确认条原来被常驻五入口底栏盖住，透过玻璃看得见、点下去却落在 Tab 上。按所有者补充的方案，这两个步骤与 `/paste/review`、`/voice/review`、`/ocr/overview` 同一语义：`PersistentNavContext.useFocusTask` 让常驻底栏隐藏（万一仍在画面上则灰色、`inert`、不可点），确认栏占用底栏原来的位置，InnerPage 不再为底栏留尾部空间；取消、保存成功、改为手动记账、返回与浏览器返回都会恢复底栏。选图、选文件、识别中、保存成功与导入完成仍是普通记账工作区，底栏照常显示。没有把确认栏统一抬到底栏上方。导入核对与批量识别概览的固定确认条尾部留白移到附件区之后（原来放在列表末尾，附件区说明滚到底仍停在确认条后面）。
