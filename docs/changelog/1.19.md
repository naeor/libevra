## 1.19.39 · B1 / B2 光照收尾：去掉独立光斑、反射依附浪沿缓慢移动、B2 1 号玻璃更清透（2026-11-08，仅本机）

- 范围：只改浅色 B1 / B2 的光照细节（`s19/oceanPainter.ts`、`OceanMaterial.tsx`、`ocean-material.css`）。A、C 在相同输入下与 1.19.38 逐像素一致；波形、横向游动、分层纵向转场、Logo 时机、Original / 深色与页面结构不变。本轮之后结束海浪材质迭代。
- 删除独立漂浮的光斑：B1 釉层画布上的左上柔光箱像（顶部那道模糊的"疤痕"）连同釉层画布一并移除，B1 只剩一张画布；B2 的玻璃表面柔光箱反射与两片漂移透射光斑移除。浪沿反射保留：B1 约 1px 细亮边与肩部局部釉光；B2 晶亮线、斜面折光与片内导光、汇聚亮线、吸收线与绿色投影不变。
- 反射依附浪沿缓慢移动：一个很宽的光照窗口，中心在 0.5 ± 0.2 页宽（总行程 40%），18 秒一个来回，正弦往返、两端自然减速，纵向不动。移动的只是浪沿上已有反射的明暗分布（B1 肩部釉光 0.75–1.25 倍；B2 导光 / 汇聚亮线 0.78–1.28 倍、晶亮线 0.8–1.2 倍，平均不变），没有光斑在画面里游走；静止时浪沿都在 Logo 下方。仍是逐列 alpha 与渐变色标，没有新增预渲染图、裁切或叠层。
- 停留增强取代"光源升起"：反射在移动中与刚到达时为 78%，完全展开且四层静止约 0.9 秒后，用约 0.7 秒平滑升到 100%（实测 B2 高光能量在 1.0–1.7 秒间平滑上升约 14%，无闪动）；拖动或上滑时约 0.25 秒内、且在 2% 行程内回到 78%。转场中不再完全关灯。
- B2 1 号（最上层）玻璃：`--oc-tint-1` 改为 `oklch(from ocean-1 l−.065 c×1.24 h)`（原 `l−.11 c×1.15`），页面上看到的 1 号区域 OKLCH 明度 +4.0%、彩度 +3.0%，色相变化 < 0.3°，其余三带不变。内部细节：每带的预渲染填充加入极低对比度的厚薄起伏（两个不成倍数的低频分量，基本沿 x 方向，每带相位与方向不同；ΔL 约 ±0.01，变薄处的提亮多于变厚处的压暗），只在贴近细看时察觉；不加焦散、白雾、暗条或背景，`GLASS_UNDULATION = 0` 一处即可关闭。
- 验证：s19 与海浪相关 97 项测试、Web 类型与生产构建通过；全量 Web 测试仅云端不完整副本缺文件的 4 个用例无法运行。Chromium 固定时钟检查欢迎态四个光照相位、停留增强时序、点击上滑中途与列表态。绘制基准（Chromium 软件渲染，3 倍屏，每帧中位数）：B2 静止 21.9→14.8ms、移动 13.1→13.0ms；B1 静止 5.7→6.1ms（噪声内），移动 3.1→5.4ms（转场中保留弱化釉光，仍低于静止帧）。本轮云端没有 WebKit，未测。iPhone Safari 实机观感与帧率仍待所有者确认。仅本机，无上传或部署。

## 1.19.38 · B1 / B2 光源时机、B2 透射光漂移、大字退场与新 UI 出现时机（2026-11-08，仅本机）

- 光源只在完全展开后出现（B1 / B2）：主进度为 0 且四层都静止后，"阳光"约 1.6 秒缓慢升起（B1 釉面柔光箱像与局部釉光；B2 透射光斑、玻璃表面反射、随光源走的汇聚亮线 / 片内导光 / 绿色投影）。一旦离开（拖动或上滑）先以约 0.12 秒熄灭，且在走过 2% 行程前一定熄灭——光先消失，海浪再动；转场中与列表态没有光源和对应反射（B2 的玻璃边缘保留弱化的基础亮线）。阳光关闭时跳过这些绘制，转场中每帧开销反而更低。B1 的瓷体、边缘细亮边、阴影不变；静止且有光时与 1.19.37 逐像素一致。
- B2 透射光随环境光源缓慢左右来回（约 18 秒一个来回，±14% 页宽，上下 ±0.8% 页高）；斜面汇聚亮线、片内导光与绿色投影的强弱跟着光源位置移动。两片光斑都在 Logo 下方，漂移全程落在 Logo 区域的强度 < 1%（600–844px 高度核算）；光斑略增强（欢迎态中心 ΔL* 约 +3～+5）。光斑仍是预渲染小图，逐帧只填"光斑外框 ∩ 本带"的多边形，不裁切整带。
- 列表内容（新 UI）跟随 4 号层的实际进度：4 号落后（上行）或领先（下行）主进度时，`.space-content` 按落差 × 1.12 向下让出（CSS 用同一个 `--p` 与 JS 写入的 `--q4` 计算，不与布局错帧；只在两者不等时启用 transform，静止时为 0）。于是上滑时内容稍晚出现、稍快到位，整体时长不变，快速上滑也不再被 4 号浪盖住；下拉时内容先让开。A / B1 / B2 / C 都使用分层转场，因此都生效；Original 与深色不变。
- B2 中央大字：退场改由 4 号玻璃（上行最后离开的一层）的覆盖决定，不再在主进度约一半时因"内容将到"提前变淡；兜底条件改用列表内容含落差的真实上沿，进入大字下缘 30px 内才淡出、6px 前完全消失，不与账本按钮等内容重叠。
- 验证：s19 与海浪相关 97 项测试（新增内容落差与"大字不与内容重叠"的网格检查）、Web 类型通过；Chromium 固定时钟检查欢迎（光源漂移）、点击 / 快速上滑、下拉、光源升起与熄灭；A / C 与 1.19.37 在相同输入下逐像素一致。WebKit（Linux 软件渲染）：转场中 B1 / B2 帧间隔较 1.19.37 明显下降（光源关闭），静止有光时 B2 约 +10%。iPhone Safari 实机仍待确认。仅本机，无上传或部署。

## 1.19.37 · B1 釉面反射与 B2 玻璃透射精修（2026-11-08，仅本机）

- 范围：只改开始页面浅色 B1 / B2 的材质绘制（`s19/oceanPainter.ts`，`OceanMaterial.tsx` 只多传一个进度参数）。A、C、Original 与深色不变（相同输入下与 1.19.36 逐像素一致）；波形、横向游动、分层转场、Logo 节奏与页面结构不变。依据 Adobe PBR Guide（粗糙度与微表面、Fresnel、吸收与散射）、KHR_materials_clearcoat / transmission / volume。
- B1（瓷体 + 透明釉层的二维近似）：删除与 1 号浪沿同形、横穿画面的长弧线（它复制了浪沿起伏，像多出一条海浪）。改为左上方柔光箱在釉面上的像：有长度和宽度的柔和反射（约页宽 45%、核心约 25–30px、峰值 0.16），短轴方向中心集中、边缘清楚、几乎无拖尾，长轴轻微弯曲但不随浪沿起伏；固定在环境里、只落在 1 号瓷片上，避开静止时的 Logo，上滑时 Logo 从它下面经过，收成顶栏前随 1 号层进度淡出。边缘高光与表面反射分开：边缘只保留约 1px 的细亮边（掠射角 Fresnel）；原先与浪沿平行的连续釉光线改为只在朝向光源的弧段出现的局部反光，亮度沿 x 由渐变色标连续给出（无分段台阶），Glazed 窄而亮、Satin 宽而暗、能量相近。无白色大面叠层、无光晕。
- B2：保留边缘亮线与汇聚亮线，斜面内侧吸收线放宽减淡，使边缘到内部连续过渡。新增两片固定在环境里的透射光斑（宽高斯，边缘不可察觉），按每一带透过的玻璃层数用透射率 T 染色、衰减（Beer–Lambert 式：层数越多越暗越绿，不往上盖白），同一片光跨过各层交界时连续变化；实测欢迎态光斑中心 ΔL* 约 +2.6～+4.0。片内导光与下方亮线随浪沿局部弯曲 ±25% 变化（内凹处汇聚、外凸处发散）。玻璃表面加一片很淡的柔光箱反射（峰值 0.065，透明玻璃仍会反射）。透光与光斑预渲染为每带一张静态图，逐帧仍是一次填充，没有新增裁切或叠层。
- 未新增 filter、backdrop-filter、mask、混合模式或背景图；环境光斑与反射为静态预渲染图，只随尺寸 / 主题重画。WebKit（Linux 软件渲染）帧间隔与 1.19.36 在噪声范围内一致。验证：s19 与海浪相关 99 项测试、Web 类型与生产构建通过；Chromium 固定时钟检查欢迎 / 上滑 / 列表态与逐帧运动。iPhone Safari 实机观感与帧率尚待所有者确认。仅本机，无上传或部署。
