## 1.17.3 · 分析工作台第二阶段优化（2026-10-27，仅本地）

- **改了什么**：时间筛选统一为自定义、近 7/30/90 天、近一年，时间和币种均为单行横向滚动；自定义日期按需展开，400 天上限明确拒绝。分析工作台独立于明细页汇率显示偏好，登录用户默认折算至账号默认币种；复用 S16-D 聚合和缺汇率记录入口。编辑态按正式图表家族映射图标、放大图标标题。D 引擎提供占位插入让位、等尺寸交换、不同尺寸保序重排及稳定起始快照预览，容器/配置操作改走正式命令。单分析自定义卡片打通创建、保存、加入工作台、重新配置及复制；复杂多指标编排尚未完成。
- **为什么**：根据所有者实际体验补全原有 `/stats` 工作台，保留 K4 三态、抽屉和容器方向；不建立第二套分析或布局实现。
- **可靠性**：本机记录经 D 迁移链及序列化往返检查；保留损坏原文，较新格式只读，拒绝已落盘的过期标签页版本（localStorage 无原子 CAS，不代表同时写入安全）。账号身份变化销毁编辑会话。B/FX 公共结果元数据开始复用 A 的九态语义，但原生载荷与完整冻结形状的适配仍未收口；未增加迁移、API 或服务器同步。
- **怎么验证**：新功能与既有回归分别记录在[第二阶段本地验收](../archive/releases/S17-1.17.3-第二阶段本地验收-20261027.md)。包含本机浏览器 320px 筛选、真实鼠标拖放和自定义卡片保存重读；真机、Safari/PWA、多设备及完整 K4 13 项复验未宣称通过。

## 1.17.2 · 「分析」Tab 改为模块化财务分析工作台（2026-10-27，仅本地受保护分支）

- **改了什么**：点底部「分析」直接进入工作台（不另开页面、不保留第二入口）。三种状态在同一页切换：浏览（筛选摘要、筛选与编辑按钮、按保存的布局显示真实数据卡片，点卡片进详情）；筛选（面板在页内展开、卡片下移；时间 7/30/90/365 天、本月、上月、指定月份、自定义；原币 / 综合折算与币种；「应用」才生效，「收起」保留草稿并标「有未应用的修改」，「撤销修改」单独一个按钮）；编辑（原位半透明虚线卡片，点卡片出操作菜单：配置 / 移动 / 调整尺寸 / 复制 / 删除，容器另有「编辑内部卡片」「收起为 1×1」；撤销 / 重做；「调整行列」；取消有未保存修改时先确认）。编辑时底部 Tab 栏换成可展开的卡片抽屉（分析卡片：系统推荐 / 全部分析 / 我的自定义；布局容器：滑动卡片组 Carousel、分割卡片组 GridSplit、空白 Spacer），长按拖入有合法 / 不合法落点预览，或点「+」放到第一个空位；空容器先作为草稿，加够最少张数才写入布局。新增卡片详情页 `/stats/cards/:objectId`，继承所点卡片的配置与生效筛选，返回时恢复滚动位置、焦点与滑动组页码。
- **为什么**：S17 所有者要求把模块化工作台做进正式分析页，而不是另一个 Demo；草图三态 + 抽屉为结构依据。
- **数据与安全边界**：不新增财务计算——卡片只组合 Agent A 的 `assemble`、Agent B 的 `derive*` 与原分析页 `computeStats`，原币模式先按币种过滤（不跨币种相加）；综合折算沿用 S16-D 汇率引擎，只开放有权威综合结果的 7 张卡片（总支出 / 总收入 / 收支差额 / 支出与收入分类构成 / 支出与收入排行），其余明确提示「暂不支持」并可一键改用原币。本机缺月份时先按月补齐再显示，不把缺数据显示成 0。布局用 Agent D 的文档类型、命令、几何校验、投影与紧凑；按账号存在本机（游客按游客身份），不存金额 / 交易 / 账本 ID，未做服务器同步（`pendingSync` 恒为 true）。无数据库迁移、无 API 改动（随 A 分支带入的 T2 只读分析端点本页未使用）。
- **怎么验证**：web 178 文件 / 1,669 项、shared 1,176 项通过（新增工作台 31 项）；`pnpm -r typecheck`、`pnpm check:build`、`pnpm check:docs`、`pnpm check:status` 通过。真实路由 `/stats` 上用种子账号逐项走查（Playwright，390×844 触屏 / 320×640 英文 / 桌面鼠标）：筛选草稿与应用、编辑菜单、尺寸、拖放（触屏长按、自动滚动、非法落点提示）、抽屉添加卡片与容器、容器内部编辑、复制 / 删除 / 撤销、改列数、紧凑、保存后刷新仍在、详情与返回、七主题 × 浅 / 深、综合折算、游客模式。**未做**：真机 / iOS Safari / PWA、服务器同步、完整自定义卡片创建器（只保留入口与说明，待所有者确认）。
- 交接与协议差异见 [分析页工作台集成交接](../specs/product/s17-agents/S17-分析页工作台集成-交接-20261027.md)。
