## 1.17.24 · 宽工作区明细行恢复简洁、iPad 长按拖动「闪一下就复原」修复（2026-10-30，本地）

- **依据**：所有者 2026-10-30 对 1.17.23 的意见：宽工作区明细一行内容过多；iPad Safari 长按浮起后手指一动，整屏闪一下回到原状（约九成概率，一次成功后不再出现）；个别账目手指一动拖动状态即消失（仅一次）。电脑上鼠标拖动几乎都成功。
- **宽工作区明细行**：去掉 1.17.20 加的「支付方式」「时间」两列，宽工作区里一行只显示图标、分类与备注、金额；手机与窄工作区仍是原来的两行（第二行时间 · 支付方式）。
- **拖动闪烁（Bug A）**：原因判断为拖动开始那一刻给按着的那一行所在的滚动区加 `filter: blur()`、给工作区加 `scale()`——iPad Safari 的滚动区背后是系统滚动视图，手势进行中改变它或祖先的合成方式，系统会把这次触摸当作被打断，页面收到 `pointercancel`，拖动取消、模糊撤回，看起来就是「闪一下」。现在模糊改由工作区上方新加的一层遮罩用 `backdrop-filter` 实现，工作区与滚动区在拖动中不再有 `transform` / `filter` / `opacity` 变化，描边用 `box-shadow`。另加两层保险：浮起后若指针仍被系统掐断（`pointercancel` / 失去指针捕获），触屏改由常驻的触摸事件（`touchmove` / `touchend`）继续推进拖动与落点，系统真正取消触摸（`touchcancel`）或移动已不可取消时才放弃；窗口 `resize` 只有尺寸真的变化才取消拖动（Safari 地址栏收放会发出不改尺寸的 resize）。视觉与第三轮相同（两区模糊、落点描边、右上角「取消」）。
- **个别账目无法拖动（Bug B）**：无法复现，按可能原因预防：关闭 Safari 对电话号码、日期、地址、邮箱的自动识别（`format-detection`；备注里的这类文字会被变成链接，长按时系统的链接手势与拖动争同一次触摸）；上面的触摸事件后备与 resize 判断同样覆盖「刚开始移动就被取消」。
- **验证**：Web 全量 2145、`pnpm check:build` 等结果见交付回复。本地 Chromium（CDP 触摸）：正常长按拖入辅助区；拖动中注入 `pointercancel` 并屏蔽之后的指针事件 → 仍由触摸事件完成并在辅助区打开；浮起后、移动前注入 `pointercancel` → 同样完成；系统 `touchcancel` → 取消、两区不变；拖动中工作区 `transform: none`、滚动区 `filter: none`、被按住的行始终在 DOM 中；鼠标拖动、第二 / 三轮拖动与「取消」区域回归通过；1280 宽单区明细行只剩三项。**所有者 2026-10-30 在 iPad 上确认两个拖动问题都已修好**（Chromium 不会因合成层变化掐断触摸，只能真机确认）。

## 1.17.22 · S18 多工作区·第三轮：跟随模式下返回不再变独立、拖动更稳、右上角「取消」区域（2026-10-30，本地）

- **依据**：所有者 2026-10-30 iPad 录屏与第三轮意见（版本号按所有者「无关紧要」的说法暂沿用 1.17.x）。
- **跟随模式下「返回」**：原因是记账详情的返回在没有可后退的历史时打开上级页（明细，一次新的导航），外壳把它当成用户主动打开新页面而切到独立。现在页面的返回（页头返回、`useGoBack`、辅助区浮层的返回）先告诉外壳「这是返回」；返回不触发自动独立。跟随模式下返回后辅助区与主区显示同一页同一本账时，辅助区回到默认空白页并保持跟随；返回到别的页面也保持跟随。真正打开新页面时自动独立的规则不变。
- **辅助区浮层**：去掉「这里浏览过」与「设为主工作区」；返回键放到左侧，「辅助工作区 / 当前页 · 账本」居中，收起在右侧。
- **拖动在 iPad 上「闪一下就失败」**：原因是阻止滚动的 `touchmove` 监听在长按开始时才加上，iOS 对手势进行中新加的非被动监听不生效，浮起后手指一动就被当成滚动、拖动被取消。改为入口挂载时就常驻一个非被动监听（只在浮起后才阻止滚动，平时不影响滑动）。
- **右上角「取消」区域**：拖动开始时在屏幕右上角出现红色圆角「取消」，移上去加深并提示「松手取消」，松手什么都不打开；预览卡片贴近屏幕边缘时往里收，贴近顶部时改到手指下方，不被裁掉也不盖住「取消」。拖到侧栏等非工作区处松手仍是取消。
- **快速滑动时顶部偶尔闪一下**：录屏里是记账详情的大标题区在快速上滑时短暂下移、露出上方空白；原因是 iOS 合成线程先滚动、主线程稍后才更新标题区上方的占位高度，中间一两帧露出占位的白底。占位改成与标题区同色（深色主题透明），这一两帧不再出现白色断层；根本的时序差没有改变，需 iPad 复核。
- **验证**：落点单测增加「落在取消区域松手什么都不打开」；Web 全量测试（仅既有 `UserAvatar` 素材断言失败，与本次无关）、`pnpm check:build`、`check:docs`、`check:status`；本地 Chromium 走查：跟随模式下在辅助区打开记账详情再返回 → 仍为跟随、辅助区回到空白页；浮层布局；1180×820 双区与 820×1180 单区拖到「取消」松手两区不变；第二轮的拖入辅助区 / 主区 / 新建辅助区、长按菜单、品牌回到明细回归通过。iPad 真机的长按拖动与快速滑动闪烁未验证。

## 1.17.21 · S18 多工作区·第二轮：两个工作区各看一本账、辅助区导航按钮、拖到指定工作区打开（2026-10-30，本地）

- **依据**：所有者 2026-10-30 第二轮修改意见（功能正确优先，其次视觉；不重做结构）。本次未收到新的 iPad Safari 截图，视觉按文字意见与本地走查调整。
