# Libevra S19 导航优化实施简报

本次交付对应 **1.19.01**，完成设置入口、当前账本选择与账目详情返回逻辑的局部调整。所有者于 2026-11-07 实测反馈「整体没什么问题」，本次导航优化已验收。未上传 Git 或部署服务器。

## 本次完成

| 范围 | 调整内容 |
|---|---|
| 设置目录 | 手机设置首页直接显示「外观」「语言」，并展示当前选项。旧「显示与数据」地址仍可访问，但不再作为正常入口。 |
| 记账偏好 | 汇率折算移入记账偏好，复用原设置组件，仍按账号保存；隐藏尚未开放的配置项。 |
| 当前账本 | 手机明细、分析页点击当前账本名称即可打开选择面板，标记当前账本，并提供「管理全部账本」。 |
| 账本切换 | 复用既有激活机制，切换后保留功能页及通用筛选，移除原账本的分类、标签、支付方式等对象筛选。Pad 的查看与激活边界保持不变。 |
| 账目返回 | 编辑记录、明细及分析来源账目进入详情时携带明确来源；返回优先消耗当前详情历史记录，避免相互跳转。刷新、无效来源及深链接使用校验和默认返回目标。 |
| 上下文保留 | 明细返回保留月份条件；分析来源账目列表返回后保持展开；Pad 辅助区返回自己的历史，不复制主区来源。 |
| 局部入口 | 「我的账本」功能入口改为「当前账本详情」，区分查看其他账本与切换当前账本；桌面「明细更多」归属明细导航。 |

五个移动端主入口、桌面与 Pad 导航体系、保存完成后的跳转行为均保持原样。本次未引入 A/B/C 视觉实验样式，未修改账目结构、金额计算、权限规则或数据库。

## 返回安全措施

来源仅由已知阅读入口生成，不无条件复制上一页的来源状态。能够确认前一条历史时执行后退；无法确认时使用替换导航，避免新增往返记录。详情加载失败或账目已删除时也使用同一返回规则。

原有连续返回保底未移除。实际代码规则为 **10 秒内连续返回 4 次**，与任务描述中的「三次」有差异，本次保留既有实现。
