> 路由：`/`（明细）、`/transactions/:id`（交易详情，编辑为页内状态）。
> 代码入口（相对 `apps/web/src/`）：`components/ledger/LedgerEntryRow.tsx`、`SelectionBar.tsx`、`BatchActionBar.tsx`、`BatchEditSheet.tsx`、`DetailTools.tsx`、`components/MonthPicker.tsx`、`pages/EntryDetailPage.tsx`、`components/UndoProvider.tsx` / `UndoBar.tsx`、`components/ConfirmDialog.tsx`。

## 1. 决定状态

- 宽屏「列表 + 详情并排」、桌面高密度表格与批量操作：**C-07【设计候选】**；页面具体结构：O-09【待所有者草图】。
- 已实施：宽工作区里的明细行只保留图标 / 分类·备注 / 金额三列（1.17.24）。
- **保留既有设计**：明细摘要随原生滚动收缩的交互不改（附录 A.5）。

## 2. 不依赖布局决定、可直接执行的电脑端要求

**账目行**

- 整行悬停浅底高亮；整行都是点击目标（没有死区）；不缩放、不抬起。
- 焦点环包住整行；批量模式下「焦点」与「选中」外观不同（现有 `aria-pressed` 只在批量模式出现，保持）。
- 金额右对齐、`tabular-nums`、永不截断；冲突 / 待同步 / 已删除行的现有底色（`bg-warn-soft`、`bg-brand-soft`、`bg-danger-soft`）在悬停时仍可辨认。
- 分类、备注、商户文字可以被选中复制——**注意**：行本身是 `<button>`，按钮内文字在多数浏览器里拖选困难；需要复制时以详情页为准，不为此改行结构。

**链接语义**

- 1.18.10 起，中键 / Ctrl(⌘)+点击账目行在新标签页打开详情（`entryNewTabPath`：多选、冲突、未同步、外部账本里的账目不参与，点击照旧）。
- 行本身仍是 `<button>`：浏览器右键菜单里没有「在新标签页打开」，行内文字也难以拖选。改为真实 `<a href>` 会牵动批量模式、拖动到工作区、读屏文案，属【候选】，作为单独任务提出。

**选择与批量**

- 在现有批量模式内按 [selection-and-dnd.md](../references/selection-and-dnd.md) §1 支持 Ctrl/⌘+点击、Shift+点击连选、Ctrl/⌘+A（范围文字沿用 `SelectionBar`）、Esc 退出。
- 「不在批量模式时 Ctrl/⌘+点击直接进入批量模式」是新入口，属【候选】。
- 批量删除走确认 + 撤销；批量编辑涉及金额 / 日期时检查不得降级。

**右键菜单【候选】**

- 见 [context-menu.md](../references/context-menu.md) §7「账目行」一行；确认前只保留现有的拖动 / 长按行为。

**键盘【候选，需把列表改为组合控件】**

- ↑↓ 在行间移动（一个 Tab 停靠点）、Enter 打开、Space 在批量模式下切换、Delete 删除所选（确认 / 撤销）、Home / End 首尾。
- 未改为组合控件前：每行可 Tab 到达、Enter 打开即可，不要半套方向键。

**月份、收支与筛选**

- `MonthPicker` 的方向键、Esc 关闭保持；筛选面板点击打开、Esc 关闭、焦点回到筛选按钮；筛选生效时有明显标识与一键清除。
- 月份与筛选状态尽量可深链，刷新、后退不丢（工程决定，先提出）。

**交易详情 `/transactions/:id`**

- 编辑态：Esc 放弃（有改动先确认）、Ctrl/⌘+Enter 保存属【候选】；IME 组字时 Enter 不提交。
- 删除：沿用确认弹窗 + 跨页面撤销条；撤销条在电脑端不遮挡详情主要内容，焦点在其上时不自动消失。
- 金额大号显示的边界检查（U06）在宽屏同样要做。

## 3. 验证要点

- 1366×768 与 1920×1080，单区与双区（明细在辅助区时的窄宽度）。
- 长备注、超大金额、外币、冲突行、离线待同步行的悬停与焦点外观。
- 只用键盘从明细打开一笔账、编辑、保存、删除、撤销。
