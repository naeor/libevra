# 页面规范 · 分析工作台

> 路由：`/stats`（浏览 / 布局编辑同页）、`/stats/cards/:objectId`（卡片详情）。
> 代码入口（相对 `apps/web/src/`）：`pages/StatsPage.tsx`、`statsWorkbench/Grid.tsx`、`statsWorkbench/dnd.ts`、`statsWorkbench/Drawer.tsx`、`statsWorkbench/CardEditor.tsx`、`statsWorkbench/editOrigins.ts`、`statsWorkbench/columns.ts`、`statsWorkbench/statsWorkbench.css`、`statsWorkbench/ui.tsx`（`FitAmount`）、`components/charts/`；shared `analysis/layout/responsive.ts`。
> 规格：[S17 工作台布局与格式模板规格](../../../../docs/specs/design/S17-工作台布局与格式模板规格.md)、[S17 图表与卡片规格](../../../../docs/specs/design/S17-图表与卡片规格.md)、S18-B 附录 B（硬约束）。

## 1. 决定状态

- 已实施：按容器宽度自动选列（最多 8 列）、阅读顺序重排、列数专属布局；手动列数滑条只在编辑器「调整行列」里，主 / 辅工作区各记一份、只存本机（1.18.01）。
- 宽屏更多卡片、桌面常驻筛选区 / 属性面板：**C-08【设计候选】**。
- **硬约束（附录 B）**：派生布局不写回权威；每次从权威布局重算；视口高度不参与投影；卡片内部密度归 S17 卡片规格，不自定像素；**禁止 `transform: scale` 缩放文字，金额不截断**。

## 2. 电脑端要求

**浏览态卡片**

- 可点开详情的卡片：整卡悬停反馈 + 焦点环；卡片内独立控件（轮播箭头、切换）在卡片之上可单独点击。
- 悬停露出的控件沿用现有模式：`@media (hover: hover) and (pointer: fine)` 下显示轮播箭头，`:focus-visible` 时也显示；触控下靠滑动（现有）。
- 右键菜单【候选】：见 [context-menu.md](../references/context-menu.md) §7「分析卡片（浏览态）」。
- 不给每张卡片加悬停动画（模板化表现）；悬停只改底色或边框。

**图表读数**

- 鼠标：悬停显示十字线 / 高亮点与读数；读数浮层不遮住被读的数据点，碰到卡片边缘翻转，但可以超出卡片、不超出视口。
- 键盘：可聚焦图表后用 ←→ 逐点读数（已登记 U11：部分系列图有 slider，旧趋势图主要依赖指针——统一属 S18 输入适配）。
- 触控：沿用现有手指拖动读数。
- 读数数字 `tabular-nums`、按区域格式化；图例与读数不只靠颜色区分系列。

**布局编辑态**

- 拖动沿用 `dnd.ts`；「点击移动」是非拖动替代，保持并让它键盘可用。
- 编辑器已有撤销历史（`editOrigins.ts`，超过 50 步不丢）：Ctrl/⌘+Z、Ctrl+Y / ⇧⌘Z 只在编辑态生效、焦点不在输入框时生效——属【候选 C-06】，但风险低、价值高，建议优先请所有者确认。
- 选中卡片后 Delete 移除、方向键移动属【候选】，都必须进同一撤销历史。
- Esc：先关闭打开的抽屉 / 菜单，再询问是否放弃未保存的编辑；不能一次 Esc 丢掉全部改动。
- 卡片抽屉、自定义卡片面板的焦点问题（U04）与键盘避让（U07）按已登记问题处理。
- 编辑中把工作区缩得很窄时格子可能窄于 104px（已登记待所有者）：不要自行加最小宽度规则。

**筛选**

- 点击展开 / 收起，Esc 收起并回到筛选按钮；筛选生效时有明显标识（已登记 U13：收起时同步卸载有塌缩风险）。
- 宽屏常驻筛选区属 C-08，不自行改成常驻。

**卡片详情 `/stats/cards/:objectId`**

- 来源账单列表沿用 [entries.md](entries.md) 的行规则；「分析 → 来源账单 → 详情 → 返回」要回到原滚动位置（附录 A.5 第 6 条）。

## 3. 验证要点

- 双工作区下分析在主区 / 辅助区各一次，拖动分隔条时列数变化不写回保存的布局。
- 只用键盘：浏览卡片 → 打开详情 → 返回；编辑态移动一张卡片并撤销。
- 1920×1080 与 2560×1440 下 8 列时卡片内金额完整、无 `transform: scale`。
