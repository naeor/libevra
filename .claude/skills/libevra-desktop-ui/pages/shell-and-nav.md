# 页面规范 · 外壳、全局侧栏与多工作区

> 代码入口（相对 `apps/web/src/`）：`workspace/WorkspaceShell.tsx`、`workspace/GlobalRail.tsx`、`workspace/RailEntryMenu.tsx`、`workspace/ShellControls.tsx`（分隔条、跟随 / 独立胶囊）、`workspace/SecondaryNav.tsx`、`workspace/navDrag.ts`、`workspace/openDrag.tsx`、`components/BottomNav.tsx`、`components/Layouts.tsx`。
> 决定状态以 [S18-B §10.5](../../../../docs/specs/design/S18-B-跨设备自适应布局与交互-设计讨论记录-20261027.md) 为准；当前行为以 changelog 与代码为准。

> **先辨认外壳**：本页的 `workspace/*` 指平板双工作区；独立电脑版入口是 `desktop/DesktopShell.tsx`、`DesktopNav.tsx`、`DesktopSplit.tsx`、`DesktopPopover.tsx`。两者的侧栏、分栏和账本切换不能混用。

## 1. 已批准（可依此实现与修缺陷）

以下条目适用于**平板双工作区外壳**：

- 左侧全局侧栏 + 主工作区 + 可选辅助工作区；横屏左右、竖屏上下；默认 55:45，拖动范围 30%–70%，越界松手收起，收起原主区则辅助区晋升。
- 侧栏左上角品牌 + 收起按钮：展开时点品牌 = 主工作区回到明细；紧凑时点标志 = 展开侧栏。紧凑侧栏只有图标。
- 侧栏里醒目的绿色「记一笔」，点开是五种记账方式（不常驻、不变成导航页）。
- 两个工作区各看一本账；可导航入口长按 / 拖动到指定工作区打开；辅助区导航是其内部右下角按钮 + 浮层。

**独立电脑版外壳**以 S18-B §10.5 的电脑条目为准：固定全局导航 + 主展示区 + 情境辅助栏；辅助栏可调宽度，窄窗口按页面用途改为覆盖式详情或隐藏辅助内容。`DesktopSplit` 的情境辅助栏不等同于平板的第二个独立账本工作区，不能套用 55:45、跟随 / 独立或拖入口新建工作区的规则。具体页面布局调整仍需所有者明确意见。

## 2. 电脑端交互要求

**侧栏导航入口**

- 状态齐全：悬停整项浅底、当前页 `aria-current` 明显、键盘焦点环。
- **紧凑侧栏的图标名称**：1.18.10 起品牌、主导航、「记一笔」用 `workspace/RailTip.tsx` 的自绘提示（停住约 400ms 或键盘聚焦出现、相邻连看免等待、Esc / 按下 / 滚动收起、挂在 body 上不被裁切、触摸不出现），不再用 `title`。侧栏里其它图标（如账本）新增提示时复用它。
- 右键 / Shift+F10 / 菜单键：已有「在主 / 辅助工作区打开」菜单（`openDrag.tsx`），保持；新增菜单项要过 [context-menu.md](../references/context-menu.md) §7 的确认。
- 平板 `workspace` 主导航仍是 `<button>`，已有中键 / Ctrl(⌘)+点击新标签页支持；改为真实链接属【候选】。独立电脑版 `DesktopNav` 的页面目的地已经是 router `Link`，保留原生链接能力；账本选择、记账方式和账户菜单仍用按钮打开弹出面板。

**「记一笔」与五种记账方式**

- 菜单已支持 ↑↓ / Home / End（`RailEntryMenu.tsx`），打开时焦点进入第一个可用项，Esc 关闭并回到「记一笔」按钮。
- 展开不能被侧栏、工作区或窗口边缘裁切（P-09）；侧栏紧凑时也一样。
- 游客等受限状态下的禁用项用现有 `disabledFor` 判断，**不得改动或合并**；禁用项的读屏文字沿用现有「需要账号」文案。
- 全局快捷键打开「记一笔」属【候选 C-06】，见 [keyboard-and-focus.md](../references/keyboard-and-focus.md) §7。

**分隔条**

本节及下方「跟随 / 独立胶囊、辅助区导航」描述平板双工作区。独立电脑版的情境辅助栏应按 `DesktopSplit` 自身规则处理。

- 已有 `role="separator"`、可聚焦、方向键调整（`keyboardRatio`）、`aria-valuenow`；保持。
- 鼠标悬停显示 `col-resize`（横屏）/ `row-resize`（竖屏），并加粗或高亮分隔线；拖动中不改工作区的 transform / filter / opacity（1.17.24 教训）。
- 双击分隔条恢复 55:45、键盘收起辅助区（如 Enter 或 Delete）属【候选】，现有越界收起规则不变。

**跟随 / 独立胶囊、辅助区导航**

- 胶囊是切换按钮：`aria-pressed` 或明确的状态文字，悬停 tooltip 说明两种模式差别。
- 辅助区导航浮层：点击打开（不做悬停打开）、Esc 关闭、焦点留在辅助区。

**焦点与区域**

- 侧栏是 `<nav>`，两个工作区是带名称的区域（如「主工作区」「辅助工作区」），读屏可按地标跳转；在辅助区里导航后焦点留在辅助区。
- 两个工作区的 Tab 顺序：侧栏 → 主工作区 → 辅助工作区（横屏左→右、竖屏上→下）。

**窗口变化**

- 窗口缩小到切回手机布局时，正在进行的拖动安全取消；已打开的辅助区内容不丢失（具体切换区间属 O-10【待所有者草图 / 待技术验证】）。

## 3. 不可自行决定（待所有者）

- 侧栏宽度、展开 / 紧凑切换阈值、手机横屏与折叠屏的导航形态（O-01、O-03、O-10）。
- 双侧控制区（O-08）；五种记账方式在宽屏是否常驻（已定为不常驻，改动需重新确认）。

## 4. 验证要点

- 1280×800、1366×768、1920×1080 下单区 / 双区、横 / 竖分栏；紧凑与展开侧栏。
- 只用键盘：进入侧栏 → 打开「记一笔」菜单 → Esc → 进入主工作区 → 分隔条方向键调整。
- 右键侧栏账本与导航入口：菜单位置在窗口右下角附近时不被裁切。
