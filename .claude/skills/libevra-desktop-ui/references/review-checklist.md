## D. 走查脚本（localhost:5173）

1. **只用鼠标**：悬停每个新控件、右键每个新对象、拖动每个可拖对象并按 Esc 取消一次。
2. **只用键盘**：从地址栏按 Tab 进入页面，完成主要流程；用 Shift+F10 打开菜单；用 Esc 逐层退出。
3. **触控模拟**：DevTools 设备工具栏开触控、保持桌面宽度（模拟触屏笔记本），确认没有「只能悬停」的入口。
4. **中文输入法**：在金额、备注、留言、搜索等输入框里用拼音输入，按 Enter 上屏英文字母——不得提交或发送。
5. **窗口与缩放**：拖动窗口宽高、浏览器缩放 200%；双工作区时拖动分隔条。
6. **主题与离线**：浅 / 深各一次；离线状态下打开右键菜单，确认写操作正确禁用并说明。
7. **两个标签页**：同时打开同一账本，各操作一次。

## E. 自动化写法

- Vitest：`fireEvent.contextMenu(el)`；`fireEvent.keyDown(el, { key: "F10", shiftKey: true })`；IME 用 `fireEvent.keyDown(el, { key: "Enter", isComposing: true })` 与 `keyCode: 229` 两种断言「不提交」。
- Playwright：`locator.hover()`；`locator.click({ button: "right" })`；`page.keyboard.press("Shift+F10")`；`page.emulateMedia({ reducedMotion: "reduce" })`；触控路径用 `browser.newContext({ hasTouch: true })`。媒体查询实际命中什么，以页面内 `matchMedia(...).matches` 打印为准，不要假设。
- 视口参考：1280×800、1366×768、1440×900、1536×864、1920×1080、2560×1440；外加既有的 320 / 390 与 iPad 尺寸。
