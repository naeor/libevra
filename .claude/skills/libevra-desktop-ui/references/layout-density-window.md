# 布局、密度、窗口与 Web 行为

> 上位：[SKILL.md](../SKILL.md) 规则 8、9、10。**本文件不定义任何具体页面布局**——那是所有者的决定（S18-B §8）。这里只写不依赖布局决定也成立的规则。

## 1. 已确认原则（原文：[S18-B §2、§10.1](../../../../docs/specs/design/S18-B-跨设备自适应布局与交互-设计讨论记录-20261027.md)）

- **P-01** 屏幕变大不等于组件同比例放大；多出来的空间用于更多信息、更多列、并排内容、辅助面板、效率。
- **P-02** 用 CSS px / rem / token / 视口 / 容器尺寸判断，不按物理分辨率或设备型号。
- **P-03** 核心内容区优先；空间不足时先重组外围控件，不压缩内容；不得隐藏重要财务警告或让关键操作不可达。
- **P-05** 电脑版要有键鼠优化（快捷键、右键、悬停、高密度表格、批量、行内编辑、详情面板、连续录入、筛选排序搜索）。
- **P-06** 输入能力与窗口大小分开判断。
- **P-07** 共享功能与品牌语言，不按设备型号分叉 UI。
- **P-08** 宽屏主导航方向在左侧竖向（细节以已批准结构为准）。
- **P-09** 绿色加号 / 「记一笔」是 Libevra 视觉语言，要足够醒目，展开不被裁切。
- **P-10** 派生布局不写回权威布局。
- **P-12** 具体页面布局须经所有者草图确认。

## 2. 已批准的大屏结构（S18-B §10.5，以原文为准）

**平板双工作区外壳**：

- 大屏多工作区：**左侧全局侧栏 + 主工作区 + 可选辅助工作区**；横屏左右、竖屏上下分栏，默认 55:45，可拖动 30%–70%，越界松手收起；两个工作区各看一本账；可导航入口可拖到指定工作区打开。
- 侧栏左上角是 Libevra 品牌与收起按钮；侧栏里是醒目的绿色「记一笔」，点开仍是五种记账方式（不常驻、不变成导航页）。
- 内部页面**按所在工作区的实际尺寸**响应，而不是按整个窗口。

**独立电脑版外壳**另有 S18-B §10.5 的批准条目：固定全局导航 + 主展示区 + 可调宽度情境辅助栏，窄窗口按页面用途覆盖或隐藏辅助内容；设置采用分类导航。情境辅助栏不是平板的第二个独立工作区，不套用 55:45、跟随 / 独立等规则。入口与适用范围见 [外壳与导航](../pages/shell-and-nav.md)。

已批准的外壳不代表每个内部页面的具体排布已获批准。手机横屏、折叠屏及未被所有者明确意见覆盖的页面布局，仍按 S18-B §8 处理；不要把平板规则自动推广到电脑版，也不要把讨论候选记为已批准。

## 3. 密度与尺寸【规范默认】

- **命中区**：鼠标目标不小于 24×24 CSS px（WCAG 2.5.8）；有触控能力时（`any-pointer: coarse`）保持 44px（`.touch-target` 把可点范围扩到 44px）。不要因为「是电脑」就把命中区缩到 24px 以下，也不要把桌面控件放大成手机尺寸。
- **字号不随密度缩小**：密度靠减少留白、增加列数、并排展示实现；字号用 [文字语义与排版规范](../../../../docs/specs/design/文字语义与排版规范.md) 的 token，不新造字号。
- **数字**：金额、计数、日期列用 `tabular-nums`；需要逐字读的编号用 `font-mono`；金额右对齐；**金额永不截断**（已登记 U06：`FitAmount` 缩到最小字号后仍会省略）。
- **文字行宽**：大段说明、公告正文控制在约 80 个拉丁字符 / 40 个汉字左右的舒适行宽，宽屏上不要让段落横跨整个工作区。
- **间距与圆角**：用 [布局间距与圆角规范](../../../../docs/specs/design/布局间距与圆角规范.md) 的值，不新增。

## 4. 桌面表格与列表【规范默认；是否改成表格属 C-07【设计候选】】

如果某页面经所有者确认采用桌面表格或高密度列表：

- 表头固定；横向超出时首列（可读的标识，而非内部 ID）固定，固定区加细阴影区分层级。
- 行悬停整行高亮；可选斑马纹或浅分隔线，帮助横向对行。
- 排序与筛选分开；任何筛选生效时有明显提示与一键清除。
- 每行 1–2 个常用操作可以直接显示；更多操作进「⋯」菜单与右键菜单；**不要只靠悬停露出行操作**。
- 查看 / 编辑单条记录优先用**非模态侧边面板**，让列表保持可见以便对照；少用模态弹窗和手风琴展开。
- 行内编辑只在列宽足够时做，编辑中的行外观明显不同，Esc 放弃、Enter 保存。
- 列的显示 / 隐藏 / 顺序若可调，不能只靠拖动，并显示隐藏了几列。

## 5. 窗口尺寸与滚动【规范默认】

- **连续可用**：把窗口从 320px 慢慢拖到 2560px，任何宽度都不能出现重叠、溢出、内容不可达；320 / 375 / 390 / 430 是参考宽，不是断点（附录 B 第 1 条）。
- **按容器布局**：工作区内的组件用容器宽度（容器查询、`ResizeObserver`，项目先例 `statsWorkbench/Grid.tsx` 的 `autoColumnsFor`）；窗口变化时从权威布局重新推导，不链式累积、不写回（P-10）。
- **电脑也会很矮**：1366×768 屏幕去掉浏览器栏后只有约 650px 高；粘性页头、工具栏、底部操作栏加起来不能把内容挤没（P-03）；对话框设最大高度并允许内部滚动（已登记 U05）。
- **滚动归属清楚**：每个区域只有一个滚动容器，两个工作区各自滚动；避免嵌套滚动陷阱；面板与抽屉用 `overscroll-behavior: contain`。
- **Windows 滚动条常显**：会占约 15–17px 宽度。在 macOS 上把「显示滚动条」设为「始终」来预览；内容显隐会造成宽度跳动的地方用 `scrollbar-gutter: stable`。
- **后退恢复滚动位置**；横向滚动区域支持 Shift+滚轮，并在悬停时显示箭头（项目先例：轮播箭头）。
- **缩放**：浏览器缩放 200%、Windows 显示缩放 125% / 150% 下仍可用；不禁用缩放（不在 viewport meta 里写 `maximum-scale` / `user-scalable=no`）。

## 6. Web 与 PWA 行为【规范默认】

- **链接就是链接**：导航用 `<a>` / router `Link`，支持中键、Ctrl(⌘)+点击、右键「在新标签打开」。
- **状态可深链**：筛选、月份、标签页、展开的面板尽量体现在 URL，刷新与后退不丢（工作区相关状态的 URL 设计属工程决定，先提出再做）。
- **页面标题**：`<title>` 反映当前页面，便于多个标签页、任务栏区分（双工作区时标题以哪个为准属【候选】）。
- **多标签页 / 多窗口**：电脑用户常同时开两个 Libevra 标签页。凡是改动本机存储（布局偏好、离线队列、草稿）的功能，都要验证两个标签页同时打开时不互相覆盖、不重复提交；同步冲突沿用现有机制。
- **未保存内容**：关闭标签页或窗口前，有未保存草稿时给浏览器原生提醒（`beforeunload`），沿用现有草稿保护范围，不扩大到所有页面。
- **安装为 PWA 后**：独立窗口没有地址栏和后退按钮，页面内必须有返回路径；不要依赖浏览器工具栏完成任何操作。
