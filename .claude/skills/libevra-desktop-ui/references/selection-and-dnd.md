# 选择、批量、拖放与剪贴板

> 上位：[SKILL.md](../SKILL.md) 规则 6、7。依据：Microsoft / Apple 文件管理惯例、WAI-ARIA APG Listbox / Grid、NN/g「Drag–and–Drop」「Data Tables」、WCAG 2.5.7（见 [sources.md](sources.md)）。

## 1. 选择模型

**现状**：明细的批量模式已存在（`components/ledger/SelectionBar.tsx`、`BatchActionBar.tsx`、`BatchEditSheet.tsx`、`batch.ts`）；普通状态下单击账目行 = 打开详情。**改变单击语义（如改成「单击选中、右侧面板显示」）属于页面结构决定（C-07【设计候选】），不得自行改。**

桌面惯例【规范默认，在现有批量模式内实现；作为进入批量模式的新入口属【候选】】：

| 操作 | 效果 |
|---|---|
| Ctrl/⌘+点击 | 切换该项是否选中（不影响其它项） |
| Shift+点击 | 从锚点到该项连续选中 |
| Ctrl/⌘+A（焦点在列表内） | 选中当前范围全部；**范围必须用文字写清**（现有 `SelectionBar` 已把「全选」的范围写成文字，且筛选变化会清空选择并提示——保持） |
| Space（选择模式、焦点在行上） | 切换当前行 |
| Shift+↑ / ↓ | 扩展选择 |
| Esc | 第一次关闭打开的菜单 / 面板，再按一次清空选择 / 退出选择模式 |

细则：

- **焦点 ≠ 选中**：键盘焦点框和选中底色是两种外观，可以同时出现在不同行上。
- 选中计数一直可见（「已选 N 笔」）；批量操作放在列表上方或现有粘性批量栏，不藏在悬停里。
- 危险的批量操作（删除）走确认或撤销；批量编辑金额 / 日期等属于「财务金额」相关改动，检查不得降级（AGENTS §6.1）。
- 复选框列：电脑端可以在悬停或选择模式下显示每行复选框，但键盘与触控必须另有进入选择模式的路径（【候选】）。
- 选择状态不写进 URL 以外的持久存储；刷新后丢失是可以接受的，但筛选、月份等应当可深链（见 [layout-density-window.md](layout-density-window.md) §6）。

## 2. 拖放

**现有体系（复用，不建第三套）**：

- 工作区「拖到指定工作区打开」：`workspace/navDrag.ts`、`workspace/openDrag.tsx`（鼠标拖动、触屏长按浮起、`pointercancel` 后由触摸事件续接、`resize` 只在尺寸真变时取消）。
- 工作台布局编辑：`statsWorkbench/dnd.ts`（已有「点击移动」作为非拖动替代）。
- 工作区分隔条：拖动 30%–70%，越界松手收起（O-02【已批准实施】）。

规则【规范默认】：

1. **可发现**：鼠标悬停在把手或可拖区域时显示 `grab`；把手图标不要像汉堡菜单或「⋯」，免得被当成菜单。
2. **起拖阈值**：鼠标按下后移动超过几像素才算拖动，保证单击仍然是单击；触屏用长按（现有）。
3. **拖动中的反馈**：被拖对象明显区别于其它项（阴影 / 轮廓）；可放置目标高亮并显示落点；列表重排时其它项约 100ms 平滑让位，以被拖对象**中心**越过邻项边缘为触发点。
4. **目标宽容**：放置判定区比视觉边界略大；靠近滚动容器边缘时自动滚动。
5. **取消**：Esc 取消并复原；放到无效区域 = 取消；光标在不可放置处显示 `not-allowed`。
6. **不改祖先合成层**：拖动中不给工作区或滚动容器改 `transform` / `filter` / `opacity`（1.17.24 教训：iOS 会因此打断触摸）；需要模糊或变暗时用遮罩层的 `backdrop-filter`。
7. **拖动中禁止选中文字**：对被拖元素用 `user-select: none` 与 `inert`，拖完恢复。
8. **必有替代**（WCAG 2.5.7）：每个拖放都有单指针、非拖动的方式完成——菜单项（「在辅助工作区打开」）、按钮、点击移动。
9. **键盘拖动**（推荐）：Space 抓起 → 方向键移动 → Space / Enter 放下 → Esc 取消；状态与位置用 `aria-live` 播报。
10. **撤销**：会改变数据或布局的拖放提供撤销（工作台用现有编辑历史）。

**系统文件拖入窗口**【候选，新功能】：把图片 / 账单文件从桌面拖进窗口 → 进入拍照识别或导入。必须复用现有交接与草稿保护（`lib/scanHandoff.ts` 的 `handOverForScan`、导入页流程），拖入时全窗口显示放置提示；属于导入导出类改动，检查不得降级。

## 3. 剪贴板

- 原生复制粘贴**一直可用**：不禁用粘贴（含密码、验证码框），不阻止选中文字。
- 复制按钮（`CopyButton`）给出明确反馈（「已复制」），并对键盘可用。
- **复制所选账目为表格文本**（Ctrl/⌘+C → 粘到 Excel）【候选，新功能】：属于数据导出，金额格式、币种、隐私都要定规则，检查不得降级。
- **在非输入区域粘贴文本 / 图片直接进入粘贴记账或识别**【候选，新功能】：必须经过现有草稿保护，不能静默创建账目。
