# 浮层、提示与反馈

> 上位：[SKILL.md](../SKILL.md) 规则 10。依据：WCAG 1.4.13、NN/g「Timing Guidelines for Exposing Hidden Content」、Vercel Web Interface Guidelines、Microsoft Mouse interactions（见 [sources.md](sources.md)）。

## 1. Tooltip【规范默认】

**用途**：图标按钮的名称与快捷键、侧栏收起后的入口名称、被省略文字的完整内容、图表读数。
**不用于**：完成任务必需的信息（先考虑页面内直接写出，tooltip 是最后手段）；金额（金额不该被截断，不需要靠 tooltip 补全）；仅有触屏的场景。

时序：

| 阶段 | 建议值 | 理由 |
|---|---|---|
| 首次出现延迟 | 约 300–500ms（指针停住后） | 指针路过不应弹出一串提示 |
| 组内跳过延迟 | 一个已显示后，约 300ms 内移到相邻触发点 → 立即显示、无动画 | 用户已表明意图，逐个浏览图标时不再等 |
| 隐藏 | 离开后约 100ms 宽限再隐藏 | 让指针能移到提示上（WCAG「可悬停」），也容忍轻微抖动 |

WCAG 1.4.13（自定义 tooltip、悬停卡片、悬停露出的面板都适用）：

- **可关闭**：按 Esc 关闭，不需要移动指针或焦点；
- **可悬停**：指针能移到提示内容上而不消失（提示紧贴触发点，中间不留缝）；
- **持续**：在悬停 / 焦点移开、被关闭或内容失效之前不自动消失，**不设定时消失**。

其它：

- **键盘聚焦（focus-visible）时也显示**，鼠标点击产生的焦点不显示。
- 位置不遮住触发元素本身；碰到视口边缘翻转；z-index 用现有层级。
- 文字短、不加句号；有快捷键时写成「删除（Delete）」，修饰键按平台显示。
- 图标按钮无论有没有 tooltip 都必须有 `aria-label`。
- 现成实现：紧凑侧栏的 `workspace/RailTip.tsx` 已按本节时序与 WCAG 1.4.13 实现（1.18.10）。
- **`title` 属性**：项目里大量使用（布局规范「桌面端悬停看 `title`」），可作为轻量补充；但它对键盘与触控不可达、延迟不可控，**不能承载唯一信息**。把现有 `title` 批量换成自定义 tooltip 属于 S19 范围，不要顺手全量替换。

## 2. 弹出菜单与面板【规范默认】

- 电脑端的菜单、下拉、日期 / 月份选择器**点击打开**，不做悬停打开；点击外部或 Esc 关闭，焦点回到触发按钮。
- 如果确有悬停展开的二级内容：停留 300–500ms 再展开；离开后约 500ms 宽限再收起；斜向移向子菜单时不得误关（用宽限时间或「指针朝向子菜单」三角判断）。
- 弹出内容渲染在顶层，不被工作区或卡片裁切；锚定元素滚出视口时关闭或跟随。

## 3. 对话框、底部面板与侧边面板

- **手机的底部面板（`BottomSheet`）不要原样拉满宽屏**。电脑端用居中对话框、锚定弹出层还是非模态侧边面板，属于页面结构决定（C-07 / C-09【设计候选】、O-09【待所有者草图】）。确认前保持现有组件，只做不改变布局的修正：限制最大宽度、焦点管理（U04）、最大高度与内部滚动（U05）。
- **模态对话框**【规范默认】：焦点圈定、背景 `inert`、Esc 关闭、关闭后焦点回到触发元素；Enter 对应默认的**非破坏性**按钮；破坏性确认框默认焦点在「取消」；按钮顺序沿用 `ConfirmDialog` / `ChoiceDialog` 现有约定，不按平台分叉。
- 需要对照背后列表时，优先非模态侧边面板（属布局决定，先提出）。

## 4. 反馈与状态【规范默认】

- **悬停反馈** ≤100ms；**点击反馈**立即（按下态）。
- **加载**：按钮保持原文字并加指示；加载指示延迟约 150–300ms 才出现、出现后至少显示约 300–500ms，避免闪烁。
- **乐观更新**：先更新界面，失败时回滚并说明，或提供撤销。
- **破坏性操作**：确认或撤销二选一（沿用 `ConfirmDialog`、`UndoProvider` / `UndoBar` 的现有分工）。
- **撤销条 / 提示**：电脑端不要盖住刚操作的对象；能用键盘到达；用 `aria-live="polite"` 播报；指针悬停或焦点在其上时不自动消失。
- **常驻状态不能因为宽屏而丢**：离线状态、同步状态（`OfflineStatus`、`SyncBanner`）、财务警告在电脑端同样可见（P-03）。
- **错误放在出错的地方**：表单错误贴着字段，提交时焦点移到第一个错误。

## 5. 动效【规范默认；具体时长与缓动归 S18-A / S19】

- 支持 `prefers-reduced-motion`（已登记 U09：部分减少动态规则被覆盖）。
- 只动 `transform` / `opacity`；不写 `transition: all`；动效可被用户输入打断。
- 动效按语义选择（附录 A.4：A 即时 / B 轻过渡 / C 空间连续 / D 调整）；**不自行发明新的时长与缓动参数**（附录 B 第 8 条）。
- 悬停效果不做缩放弹跳；电脑端「每张卡片都有悬停动画」是模板化的表现，克制使用。
