# Libevra S19 · 移动端视觉实验（Style Lab）

独立的静态原型，不依赖构建、不连接后端，**不属于正式应用**（未接入 `apps/web`，不影响桌面端、Pad 端与生产构建）。

## 打开方式

| 方式 | 做法 |
|---|---|
| 电脑上直接看 | 双击 `index.html`（对照页：三台手机并排，可同步操作） |
| 手机上看 | 双击 `启动StyleLab.cmd`（或 `node serve.mjs`），手机与电脑连同一 Wi-Fi，打开窗口里显示的 `http://<电脑IP>:5190/` |
| 单独打开某一套 | `a.html` / `b.html` / `c.html` / `b1.html` / `b2.html`；页面右侧的小把手可在各套间切换 |
| B1 / B2 玻璃对照 | 双击 `glass.html`（两台手机并排；场景、玻璃调试、材质分配说明） |

对照页功能：切换页面（明细 / 分析 / 账本 / 我的 / 设置 / 账目详情 / 卡片详情）、打开浮层（筛选 / 排序 / 选择账本 / 全部币种 / 记一笔 / 删除确认）、切换屏幕尺寸（320 / 375 / 390 / 430）、同步操作、无模糊回退、减少动态。顶栏「设计说明」里有三套方案的说明、与当前 UI 的变化对照和已知限制。

## 三套方案（第二轮精修）

三套的页面顺序、操作入口、账目行信息和“当前账本”说明位置都与正式版移动端一致，差异只在表面与排版：

- **A · Soft Spatial 柔和空间**：柔光背景 + 一种白色表面、两级投影（摘要卡与浮层浮起，其它卡片贴近背景）。不再使用外层“内容面”，也不在卡片里再铺一层底色。
- **B · Milky Frosted 乳白磨砂**：三类表面。Frosted 只用在底部停靠栏、Bottom Sheet、账本切换、对话框、提示、吸顶栏；Satin（不透明缎面）用于收支摘要与重点控件；Content（不透明暖白）承载账目、设置与图表。
- **C · Structured Editorial 精致排版**：正式版平面风格的精致升级。白底 + 一像素细边的轻量容器、精确对齐、克制的分隔线、等宽数字。

第一轮版本已不保留在本目录；需要对比时以对照页的“设计说明”为准。

## B1 / B2 玻璃材质专项（第三轮）

以第二轮 B 的页面结构为基础（B 本身未改动），两套共用同一套五类材质：Canvas（背景）、Content（不透明内容）、Satin（近不透明釉面）、Frosted（乳白磨砂玻璃：局部模糊、环境透色、左上光源的边缘光与内侧回光）、Accent（品牌绿强调）。两者只在“哪个组件用哪种材质”和参数上不同：

- **B1 · Ambient Frost 柔和环境磨砂**：柔和色雾背景；摘要等重点容器为 Satin，列表与设置为 Content；玻璃只给操作层（工具钮、搜索栏、分段底板、贴底导航、浮层）。滚动后顶部成为一条磨砂带，带上的控件退为浅白，不叠玻璃。
- **B2 · Layered Glass 分层透光玻璃**：清晰、未预模糊的抽象光斑背景；收支主卡、月份胶囊、悬浮底栏、设置分组等为玻璃，光斑只在玻璃内变柔并透出颜色；列表与详情字段保持 Content；顶部用无边线的渐进模糊；“+”为绿色薄玻璃。

`glass.html` 的场景：明细、滚动后、搜索展开、筛选浮层、排序浮层、设置、账目详情，以及分析 / 协作 / 我的 / 选择账本 / 记一笔 / 删除确认 / 批量选择。“乳白度”“模糊”两个滑块同时作用于两台手机，仅用于比较；“材质分配说明”里有完整的组件 × 材质表。

## 限制

记账表单、修改表单、账本空间、明细“更多”、设置子页与布局编辑只给出提示，不跳转；只做了浅色；尚未接入主题色系统。
