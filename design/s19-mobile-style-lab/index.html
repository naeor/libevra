第五轮：收敛

四套是同一款软件的四种材质表达：页面顺序、入口位置、交互语义、底栏 / “+” / 浮层 / 记一笔面板的几何关系完全一致。共享模板在 lab/ui.js（材质分配表 MAT），外观全部是 lab/theme-*.css 里的语义变量。

A · 柔和空间

Soft Spatial

  • 去掉上一轮的连续内容面，改为柔和背景空间上的独立卡片组合
  • 明细与编辑记录是标准明细行（图标 / 标题与辅助信息 / 金额），每一行是独立小卡片，上下边完全贴合；接缝只有很小的圆角缺口与细影，不用分割线
  • 摘要改为主卡 + 两张小卡；关键卡片多一档柔和阴影

B1 · 柔和环境磨砂

Ambient Frost

  • 背景加一层很淡的乳白磨砂氛围
  • 默认状态顶部标题区与正文连续；标题区收起后出现奶油玻璃顶栏（与底栏同一材质），带上的按钮是玻璃片
  • 列表、成员、日志、设置、详情改为瓷片（Satin）；选中态统一为“覆盖一层淡白玻璃片”
  • 记一笔图标、浮层小控件进入同一套玻璃 / 瓷片语言

B2 · 分层透光玻璃

Layered Glass

  • 与 B1 同一骨架：全宽底栏、居中略突出的“+”、贴底 Bottom Sheet（不再悬浮留边）
  • 顶栏 / 底栏比 B1 更轻更透
  • 摘要、次级小卡、账目分组、成员、日志、设置、详情、图表卡统一为同一档透明磨砂玻璃
  • “+”与主操作保留主题色瓷片

C · 经典精修

Classic Refined

  • 正文改为一张圆角纸面，压在主题色顶区下沿；纸面上沿带一点主题色余温，承接顶区颜色
  • 主卡不再悬浮投影，都是纸面上的白色纸片
  • “+”与底栏尺寸和其它三套一致

统一了的组件

组件统一后
底栏与“+”四套都是全宽底栏（含安全区）、上方“当前账本”说明、54px 居中“+”略突出底栏；只换材质（A 白色操作层、B1 奶油玻璃、B2 更透的玻璃、C 固定白色底栏）。
顶部工具同一尺寸、同一位置；同一风格内材质一致（B1 / B2 在玻璃顶栏上一律是玻璃片）。
月份四套都是文字按钮（B2 不再单独做玻璃胶囊）。
收支摘要A / B1 / B2 同一结构：主卡（支出 / 收入）+ 两张次级小卡，主卡与小卡同一材质档位；C 保留正式版结构。
Bottom Sheet / 对话框四套都贴底、同一圆角；主按钮（查看结果、确认）统一用强调色材质，次按钮与小控件统一用各风格的“小控件”材质。
选中态同一风格内底栏标签、分段、筛选维度用同一种选中片（B1 / B2 为淡白玻璃片，A 为柔和白片 / 浅色底，C 为主题色）。
记一笔面板位置、尺寸、开启方式一致；内部图标材质跟随风格。

保留的风格专属变体

变体理由
A 明细与编辑记录保持标准明细行；每一行是独立小卡片、上下边完全贴合，用来表达“每一笔独立、整体连续”。设置、成员这类菜单仍是一张分组卡。
C 摘要结构正式版的“一个主数字 + 一行次级数字”已经成熟，C 只精修不改结构。
C 当前账本卡右侧紧凑“切换”，替代原来过大的切换区域。
C 正文纸面解决主题色顶区与正文硬切的问题：同一平面上的遮挡，而不是悬浮。
B1 / B2 顶栏默认不加顶栏，避免把标题和下方说明硬切成两层；滚动、标题区收起后才出现磨砂玻璃顶栏承载标题、工具和月份。
B2 玻璃上的输入框输入区用高不透明度实心槽，避免输入内容与背景光斑混在一起。

还不够统一 / 后续

B2 性能信息卡片全部玻璃化后，实测（390 宽，页面顶部未滚动）明细首屏实时模糊 11 处、分析页 8 处、协作页 6 处（B1 为 6 / 5 / 3，A、C 为 0）；顶栏默认不出现后，顶部工具钮在未滚动时各自模糊，滚动收起后才并入顶栏变为不模糊的玻璃片；真机（尤其中低端 Android）需确认，必要时把账目分组退回高不透明玻璃。
A 明细行卡只用于明细、卡片来源列表和编辑记录；批量选择时的选中底色、按下态还可再细化。
深色四套仍只有方向；C 纸面、B1 磨砂氛围的深色参数需逐页调。
主题色记录类型小标记与图表暖色仍是固定色。
分析页只同步了材质；卡片详情页图表未逐个精修。
