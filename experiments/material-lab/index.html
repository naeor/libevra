测量边界与硬件

Input Delay、Processing Duration、Presentation Delay 来自 Event Timing（阈值 16ms，duration 按 8ms 取整）。没有样本不等于零延迟。INP 由本地 web-vitals 5.1.0 记录整个页面生命周期，非 Benchmark 分数。程序触发操作不产生可信 INP。

GPU 利用率、真实显存、功耗、设备温度：不支持直接读取。Canvas 提交计时不含异步 GPU 执行。缓存字节是可追踪载荷估计，不含驱动及对象开销。Heap 仅在浏览器支持时显示，不等于页面全部内存。

Chrome DevTools → Performance / Memory；Safari Web Inspector → Timelines。记录同一工作负载，注意开发者工具本身也会引入开销。
