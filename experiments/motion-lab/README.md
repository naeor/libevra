# Motion Lab · 本机转场实验

通过日常 `start-dev-lan.cmd` 提供的开发 Host 打开 `/motion-lab.html`。电脑入口：<http://localhost:5173/motion-lab.html>；手机使用同一 Wi-Fi 下该 Host 的局域网地址，路径相同。无需登录，不读取或写入业务数据。

在手机上点「全屏体验」进入完整视口，右下角「实验参数」返回控制区。支持四方案、四材质、180/200/220ms、左退、模糊与三种背景策略；默认 D + B2 + 200ms，B2 左退关闭。四条独立滑条、清透/均衡/柔和、自定义状态和恢复默认，共用 [`b2Glass.ts`](../../apps/web/src/s19/b2Glass.ts) 的预设与映射；默认均衡。参数仅本实验会话生效，刷新重置，不读写账号偏好。「切换模拟主 Tab」用于中断检查，不接入产品底栏动画。

面板保留独立 [A/B1/C 转场与 A 底栏实验入口](http://localhost:5193/)。它需要在保留的 ABC 实验工作区运行 `node experiments/abc-motion/serve.mjs`，并非日常 5173 服务自动提供。共享控制器已被主目录的开发风格呈现层引用；完整对照页仍留在实验分支，不能把“独立入口”误写成“成果全未集成”。实验仍不接管导航；主目录入口与依赖边界见 [S19 材质规范](../../docs/specs/design/S19-材质组件与动效设计系统.md)。

- **A Live DOM**：滚动页与顶底栏作为一个平面；交接后最多保留一张 inert 旧 DOM，仍有样式与动画成本。返回时用示例页面配方重建轮廓，深层背景压平为环境描述，不是像素快照。
- **B Native**：浏览器捕获合成画面做 200ms 交接，结束后释放；持续背景用来源环境描述。快照没有导出为位图，也不当永久资源使用。
- **C Ambient**：旧 DOM 模糊淡出后释放，持续背景同样来自稳定环境描述。适合作为低复杂度参考。
- **D Hybrid（仅 B2）**：只捕获透明前景，环境不再烘进新图。旧图先模糊，再从新图的半透明填充下透出，85% 时淡出并交给稳定环境；捕获期间暂停组件背景采样，避免把不透明底色再次带进前景。稳态恢复正常玻璃，页面与 C 相同。关闭交接相当于 B 对照；失败时目标 Ambient 短淡入，再失败即时显示，不转成双活 A。

四者共用页面数据、材质与参数。B2 的环境增加来源页当时可见的卡片、头像、图表几何轮廓：每条历史最多 48 个矩形，仅位置/圆角/颜色；用一张无文字 SVG 背景和浏览器滤镜柔化，不克隆旧 DOM，也不导出原生截图。B/C/D 恢复同一描述，不能精确恢复旧页像素；A 仍是保留旧 DOM 的独立对照。没有 CPU 像素模糊、截图依赖、远端 API 或同步字段。

内容滑条控制资料、列表、概览、设置和阅读卡片（含暖色卡）；操作层滑条控制顶底栏、返回钮、页码胶囊、语言分段/选中态、底部选中 Tab、加号与浮动实验按钮。滑条只调填充透明度，文字/图标保持不透明。环境滑条同时控制来源轮廓、环境颜色和 B/D 旧图透出强度；0 时隐藏承接环境。A/C 视觉材质及 B1 不消费这三项。

`BackdropStore` 以工作区、用户、账本、风格和真实 entry key 隔离。来源关系由已接受的导航明确建立，POP 恢复原条目；不按 URL 前缀猜父级，也不执行 navigate。导航仍使用产品的 `PaneHistory`。刷新/直达没有旧上下文，显示明确的默认背景。

资源边界：最多 64 份轻量描述；退出可恢复历史或替换时裁剪；最多两张实时 DOM 页面；原生最多申请一对 old/new，按两张 RGBA 下限估算超过 32 MiB 时跳过；持久位图缓存为 0。浏览器的真实纹理内存不可测，下限预算不能当作 GPU 内存硬上限。隐藏时释放旧 DOM，作用域切换清理描述，离开文档清空；只有真实当前页可交互。

「功能自检」约 25 秒，走真实浏览器历史：同页两来源、多级恢复、长页滚动、重复点击、快速反向、浏览器返回和资源释放。「3 分钟比较」只运行 B/C/D，各约 60 秒，可随时停止；每种方案保留本轮原始样本，当前样本上限 300，JSON 只下载到本机。基准期间不要切换标签页或调整参数。「逐帧检查」可在下一次 B/D 动画中暂停，拖动进度查看交接，最多 20 秒；样本不计入性能汇总，基准和功能自检会自动关闭暂停模式。

首帧指标是在提交后第一个 rAF 相对于转场请求的延迟；P95/P99 是 rAF 间隔，不能等同物理屏幕 FPS。输入开放估计取 native.ready / DOM 提交时刻，不代表实际点击响应延迟；交接帧窗口取 ready 后 40%–95%。没有 GPU 占用率、真实能耗与 Safari 真机数据。手动还应检查 B2 文字穿透、双层高光、交接终点、动态工具栏与系统返回手势，可将机型、系统及主观评价填入结果区一起导出。

真实页面：选择正式 B2 后，手机浅色主工作区的 `/me → /settings → /settings/appearance/language`、`/settings → /settings/appearance/theme` 及应用返回使用 D；浏览器未知方向 POP、刷新、深链与其它页面即时切换。透明应用前景与固定环境分开捕获，旧页不左退，不保留业务 DOM 或像素。开发诊断入口 <http://localhost:5173/me?motion=1&s19=b2> 额外显示可关闭的诊断把手；其他风格既有试点表现不变。原语言设置、原返回系统、底栏与详情动效不改。

真实试点只在内层 `PaneRouter` 接入，原生捕获回调中同步提交 React，并由目标 key 的 layout-effect 回执恢复真实滚动；不等待数据请求、不靠 `await navigate()`。恢复只做一次，后续用户滚动不会被迟到任务覆盖。原生能力失败、减少动态、键盘/视口变化均可即时切换或取消。

正式默认构建不包含 Motion Lab HTML、模拟数据、实验控制面板或入口；正式 B2 仅复用材质、参数与转场基础模块。此目录是实验运行说明与测量材料，不是长期产品规格。

原理参考：[View Transitions Level 1](https://www.w3.org/TR/css-view-transitions-1/)、[Safari 18 WebKit 说明](https://webkit.org/blog/15865/webkit-features-in-safari-18-0/)。API 支持不代表本实验已通过 iPhone 验收。
