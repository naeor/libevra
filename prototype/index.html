边界测试与实现说明

支持 Esc、浏览器返回 / 前进；动画中立即返回会从当前姿态收回。旋转或缩放后重新验证目标，不可靠时淡出。

FLIP：借鉴 First / Last 的一次性测量。没有对完整卡片做缩放反演，而是在脱离排版的空容器上动画化位移、尺寸和圆角，文字保持原尺寸。

Shared Element Transition：它是本轮的视觉机制：来源容器由唯一覆盖层接管，原卡片隐藏，返回时再交还。后方始终是真实列表。

Web Animations API：负责可取消的时间线。反向时只读一次当前姿态，取消旧动画后接续；完成后释放动画对象、覆盖层与滚动锁。无需每帧测量。

View Transition API：页面快照适合路由间的整体过渡，本轮需要玻璃透出真实 DOM、独立控制文字和中途反向，因此不把它作为前提。Safari 真机的合成性能仍待验证，不能用桌面窄屏代替。

现有协调器：PaneRouter / MotionPilot 已经负责导航提交与方向；ABC 呈现器消费回调并清理呈现副本。本轮只验证局部共享容器，后续 React 接入时复用该分工，不增设第二套路由历史。原型自己的历史只用于测试浏览器返回。

材质只读引用主工作区的 S19 令牌、material-components.css 和 material-effects.css；没有复制材质配方或业务依赖。原型必须通过本地服务打开。
